# 纯 2D 等距渲染、美术和输入细则

## 坐标体系
世界格子 `(cx, cy)` 是连续或整数逻辑 2D 坐标，所有寻路、碰撞与持久状态在**逻辑坐标**进行，不在屏幕菱形坐标上运行物理。默认 tile 宽 64px、高 32px，半宽32、半高16：

```gdscript
func cell_to_screen(c: Vector2) -> Vector2:
    return Vector2((c.x-c.y)*32.0, (c.x+c.y)*16.0)
func screen_to_cell(p: Vector2) -> Vector2:
    return Vector2(p.y/32.0 + p.x/64.0, p.y/32.0 - p.x/64.0)
```

实际开发以 `TileMapLayer.map_to_local()` / `local_to_map()` 为权威，尤其遇到 TileSet 偏移布局和 tile origin 时不能盲信公式；使用公式做算法或原型时需保持同一基点定义。负坐标通过 floor 处理而非 int 向 0 截断。地图块索引 `floori(cx / chunk_size)`，对负坐标尤需测试。

## 工程架构
```
GameRoot (Node)
 ├─ GlobalState (autoload: WorldState / SaveManager / EventBus)
 ├─ WorldSpace (Node2D)
 │   ├─ Ground (TileMapLayer: grass, road, water; isometric)
 │   ├─ Decal (TileMapLayer: debris/shadows)
 │   ├─ Collision (TileMapLayer: blocking footprints)
 │   ├─ SortedActors (Node2D: y_sort_enabled)
 │   │   ├─ Props (Sprite2D scenes with foot pivots)
 │   │   ├─ Player (CharacterBody2D / Sprite2D / Anim)
 │   │   └─ Zombies (CharacterBody2D / Sprite2D / Anim)
 │   ├─ Roofs (Sprite2D visual building units; no fade)
 │   └─ Camera2D (fixed rotation)
 └─ HUD (CanvasLayer: stats, radial slots, inventory, fade)
```
`TileMapLayer` 以大区块+多个层组合，在大地图流送中应批量入图以避免每帧大量 `set_cell`。大型装饰先离屏逻辑降频，再根据距离激活；动态对象靠脚底 `z_index` / y-sort 正确穿插，不用每帧重排数万 Sprite。

## 视觉像素规范
- 禁止向 2D sprite 应用会改变像素格的平滑拉伸；nearest、统一 PPU、整数倍放大；相机/角色绘制取整（物理可保持浮点）。
- 轮廓优先、清晰材质：屋面与墙体色块要分离，屋檐与立柱在 2D 精灵中明确；角色足底阴影帮助融入地面。
- 墙/房屋要做多个变化帧、边角软化只能通过精修像素轮廓 1–2px 台阶完成，不能通过 3D 倒角。
- 建筑拆为地基脚印、阴影、主 sprite、门/光源交互图层，外观至少正面可辨入口；室内单独制作墙沿、角墙、地板、门、家具精灵。
- 动画以明确帧图或 sprite sheet 组成；优先 8 方向人物方向帧（早期可4向占位），移动/打击关键帧同步伤害判定。

## 输入坐标
WASD 表示**屏幕**上下左右，转换为逻辑方向：
`logical_direction = normalize(Vector2(screen_dx/64 + screen_dy/32, -screen_dx/64 + screen_dy/32))`，必要时根据屏幕速度重新标定。鼠标点选：先通过 Camera2D viewport 变换得到世界屏幕坐标，再换算逻辑坐标，不直接用全屏鼠标像素数。

## 渲染测试
建立 2:1 网格截图对齐金图；对 `(0,0),(1,0),(0,1),(-1,-1)` 的投影和逆变换做单测；人物在房屋前后绕行确认脚底深度；混合 HUD 层保持不受世界相机影响。性能初期目标 60fps @ 640×360 逻辑分辨率，正式验收包含 1080p 和低配机器。
