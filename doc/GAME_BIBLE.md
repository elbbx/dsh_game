# OvercastVeil GAME BIBLE — 当前唯一有效设计源

版本 2D-ISO-01 · 2026-11-07 · 维护者：项目开发 AI（更改必须记录）。

## 1. 产品定义
单人、离线优先、末日开放世界生存探索制作游戏，杭州及周边地理结构为灵感来源，涉及丧尸、生存据点、制造、电力、神秘异常和颠倒世界。参考：《僵尸毁灭工程》的区域生存密度与威胁，《加拿大死亡之路》的**独立房间切换**，ISO-CORE 的**清晰 2D 等距像素画**。不复用任何游戏的受版权保护的素材/关卡/代码。

## 2. 强制视觉技术决定
- **2D 与固定等距**：全部地面/建筑/角色/载具/怪物/道具为 PNG/WebP 2D 像素精灵、逐帧动画、九宫格或 tile atlas。地面 2:1 菱形；世界坐标在逻辑平面；视觉不旋转相机。
- **测试基准**：每格逻辑对应 64×32px 钻石；设计分辨率 640×360；显示放大 2×/3×，nearest，整数倍缩放，脚底锚点、统一主光源左上。数字可由实机迭代但必须一致化更新。
- **像素画**：每类物体的轮廓线1-2px、材质 3–6 主色梯度、少量点状纹理，地面纹理彼此错开，透明边缘不模糊；角色约 22×38px，以 5–6 头身为目标，外轮廓清晰，动作至少 idle/walk/attack/hurt/death。
- **室外建筑**：整栋等距立面预渲染成 2D sprite（可分遮挡层，但不改变建筑透明），门口为交互对象。可见屋檐、屋顶和立面，不暴露室内。
- **室内场景**：独立 `RoomInstance` / `InteriorScene`，顶视角仍为等距，可展示局部 2D 内墙及家具；独立碰撞、敌人、声音、搜刮、楼层链接。无原版僵毁的遮屋顶机制。

## 3. 玩家可玩循环
探索街区→寻找建筑/资源→靠近门进入独立室内→小房间搜刮/遭遇丧尸→撤离→在安全处治疗/整理背包→制作工具/武器→经营据点→尝试更危险区域/裂隙→带资源返回。死亡或感染可以带来长期代价；通过多种行动路径延长生存。

## 4. 状态/成长
原 7 项基础：生命、饥饿、口渴、疲劳、SAN、体力、感染；环境附加：寒冷/健康及衣物防护。八技能（枪械/近战/潜行/生存/医疗/机械/制作/神秘学）每类最高 25；电力配套技术解锁，营养长期修正力量敏捷。感染可治疗，不设“感染即死”；死亡判定来自生命/明确致死病情。

## 5. 背包与交互
类塔科夫物品矩形占格+重量，身体分区与装备层。三个持有槽位；底部六快捷分类：远程、近战、工具、医疗、食物/饮水、光源/望远镜。快捷选择允许鼠标环形/顶部小面板；背包开启不暂停角色行动（但要解决焦点与世界输入冲突）。物品定义以 `data/items_original.json` 为原始输入，规范化后再接入。

## 6. 战斗、敌人
屏幕方向定位与 2D 命中区域/射线、枪械模组、弹道/碰撞、击退、噪声传播；怪物以 2D 精灵分帧。不以固定时段玩家视野中凭空刷怪；人口调度按区块生成、持久化死亡和迁移事件。丧尸循声寻人，失去视野会继续追踪最近线索但逐渐减速/丢失。

## 7. 世界与建筑
按杭州区域原型抽象分区：住宅、商业、工业、医疗、交通、农田、山地、水网、神秘异常。优先建立可探索小镇样板，再扩展地图；每栋建筑有唯一 instance_id、室外门锚点、内部模板、独立状态存档、楼层 portal 数据。多个楼层通过**室内独立场景或层切换**表示，不存在物理 3D 叠楼层。

## 8. 载具、电力、建造
所有载具 2D 方向帧和逻辑碰撞，驾驶屏幕方向映射等距速度/朝向，进入载具改变控制状态。电网采用 2D 图连接关系（源、负载、储能、断路），非 3D 电缆；建筑/墙体/屋顶以等距 tile 与精灵层组合，提供碰撞和逻辑房间，不做模型几何构建。

## 9. 裂隙与颠倒世界
与主世界对应的逻辑 2D 区域镜像，但内容层独立；裂隙跨空间是事务式过渡（记录回程锚点、玩家与车辆状态，出错回滚）；正常主世界丧尸不重复刷新到颠倒世界，专属克苏鲁生态和 SAN 条件单独处理。

## 10. 品质与交付
必须具备主菜单、键鼠操作、存读档、室内外双空间、拾取/战斗/敌人、生活状态、背包、制造、天气、据点、载具、地图、裂隙、任务、死亡重开、按键设置/音量设置、性能和回归测试、合法资产归档。阶段性示例原型只验证最小闭环，**不等于全部功能完成**。最终必须从零开始双击构建可玩并完成真人操作 smoke。
