# 冲突优先级与旧版迁移矩阵

## 权威顺序（由高到低）
1. **用户最新要求**：纯 2D 等距像素图、无任何 3D 模型、建筑独立切空间；单主代理持续开发并自动测试。
2. `AGENTS.md` + `doc/GAME_BIBLE.md` + 本目录 2D 技术文档。
3. `doc/modules/` 各模块 2D 适配条款。
4. `data/` 规范化数据及经检验的历史数值。
5. `reference/original_full_planning/` 原始规划，仅保留世界、配方、建筑原型等适用内容。

## 强制替换
| 原有方案 | 现在的方案 | 处理 |
|---|---|---|
| Godot 3D / GLB / Blender / 程序体素 | Godot 2D / PNG像素帧 / TileMapLayer / Sprite2D | 彻底禁止新 3D 资源 |
| 3D可转相机 / 伪3D像素后处理 | 固定2:1等距镜头，原生像素画 | 重写镜头和控制 |
| 3D建筑层级、屋顶动态透明 | 外部完整建筑→独立室内场景 | 删除透明需求 |
| NavMesh/3D坡道/多层物理几何 | 2D AStarGrid2D / 门户图 / 楼层独立地图 | 适配寻路和存档 |
| 3D载具/3D碰撞/3D建造 | 2D方向帧 + 多边形碰撞 + 精灵组装 | 重制美术 |
| 复杂高度网格矿洞 | 2D区域挖掘/逻辑地下层，只有网格状态 | 重建挖掘 |
| 27 个 Codex 对话框分模块 | 单个代理会话持续选择可验收增量 | 旧提示全部弃用 |

## 保留并转译
世界观、玩家状态、物品/配方规则、丧尸行为和人口密度、制造技能、电网、裂隙、NPC 等产品规则；建筑规划、现实户型和原图仅用于 **2D 关卡模板转译参考**，不能把旧 3D 立面图当成可直接导入的像素素材。

## 旧文档处理规范
原始 `reference` 只读且不得复制其中 3D 代码到运行时；发现冲突应在本文件记录裁决并更新新文档，而不是悄悄兼容双重方案。已有参考代码的接口与数据含义可借鉴，但底层需重新实现并通过 Godot 4.7.2 2D 验证。
