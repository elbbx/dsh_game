# M12 — 建筑外形户型与室内结构（纯 2D 适配）

## 2D 改造目标
把40个建筑原型转2D外立面像素sprite+室内TileMap模板，门入口显式定位。

## 实现接口
先阅读 `doc/GAME_BIBLE.md`、`doc/等距渲染与像素美术.md`、`doc/数据结构接口与存档.md`，再按同名原始规格提取数值与业务规则（禁用3D实现），将数据与 Godot 4.7.2 2D 场景接通。逻辑进程只操作 2D cell/space_id，Sprite2D/TileMapLayer 只做显示，场景退场时必须保存状态。把功能加入 `finished/state.json` 的依赖序列；不会要求用户手工拆分任务。

## 本模块可观察的验收
同模板不同实例搜刮不串，户型合理，不使用剖面透明。

## 配套最低测试
1. 核心规则模拟测试（合法/不合法输入、重复调用、数值边界）。
2. 实际运行场景的头less导入与scene smoke；可见行为截图/手工检视记录。
3. 离开当前世界空间→重新进入→存档→读档，确认该模块没有复位/复制。
4. 失败记录至 `finished/log.jsonl`；全部通过才将此 feature 标为 done。

## 旧设计冲突处理
凡原文涉及 3D 模型、法线、NavMesh3D、Voxel、GLB/FBX、3D 关卡、可转镜头或屋顶透明，均由 `doc/优先级与旧版迁移.md` 覆盖；保留玩法目标，不沿用技术细节。
