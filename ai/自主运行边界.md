# 连续开发与运行器说明

“持续推进”指 **在已启动且具有文件、终端、网络权限的代理执行会话内**不断执行下一增量，并将可恢复状态落盘。它不代表本压缩包本身拥有模型推理能力、无限账号额度或运行权限。

- 本包不附带账号、API Key 或无人值守守护进程。不要把密钥写入日志或脚本。
- 如果使用 Codex CLI、Gemini CLI 等，在工具授权界面允许其访问工作区，必要时开启有监督的长任务执行。不同版本 CLI 命令可能变化，应按其官方说明配置，不要自动关闭审批。
- 每次上下文重置后，把 `ai/恢复继续.md` 输入相同工作区，即可从状态恢复。`finished/state.json` 必须记录下一步具体可执行目标与未解决缺陷。
- 每项功能需自选一个最小可玩闭环，并非将功能列表派给多个 AI。
- 自动化只用于构建/测试/审计，若代理未在运行，脚本不会自发产生新代码。
