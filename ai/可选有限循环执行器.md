# 可选：有限轮 AI CLI 驱动器

本包的 `scripts/agent_driver.py` 仅为**用户手动启动后**调用已安装的本地 AI 编程 CLI 的有限轮控制器，不会自动取得代理能力。每轮同一工作区读取 `AGENTS.md` 和 `finished`，要求代理完成一个有验收的功能增量，停止/恢复全部由本地状态决定。这个驱动器不会创建多个手工模块任务，用户无需逐项派单，但每轮命令行调用的代理会话可能是独立进程。

例如，**先确认具体 CLI 支持从标准输入读取提示词**（不要把示例当成所有版本通用命令）：

```bash
python scripts/agent_driver.py --root . --cycles 1 --dry-run -- codex exec -
python scripts/agent_driver.py --root . --cycles 3 --timeout-sec 1800 -- codex exec -
```

`--` 后面的命令为用户自行安装并授权的外部工具；不同 CLI 的 stdin、权限参数与额度规则不同，使用前请对照该工具当前官方文档。该脚本不会静默自动授予 shell 全权限，不负责选择付费方案，也不保证代理达到完整游戏。`--cycles` 默认 1、最多20，避免无限重试和意外消费；用户可随时取消。输出记录到 `finished/reports/agent_run_*.log`。缺少 Godot 时真实引擎测试会标 `SKIP`；代理仍需自行配置 Godot 并在此之后补测。
