# 给 AI 编程工具的第一条消息（全文复制）

你现在接管本地工作区 `OvercastVeil_2D_AI_Continuous_Development`，目标是持续开发到**真实可游玩的 Godot 4.7.2 纯 2D 等距像素单人生存游戏**，而不是只写设计书。先阅读根目录 `AGENTS.md`、`README_从这里开始.md`、`doc/GAME_BIBLE.md`、`doc/优先级与旧版迁移.md`、`doc/实施与测试总流程.md`、`finished/state.json`。在功能细节上读取 `doc/modules/M00-M26_2D_适配索引.md` 与原始资料。

必须严格执行：不使用 3D 建模、GLB、自由镜头、伪 3D shader 模型；改为纯 2D 像素图，固定等距，64×32 菱形地面与 2D 精灵，2D 等距视图以 ISO-CORE 清晰的画面质感为方向但不盗用其美术。房屋由街道完整外观进入独立室内场景，再出来还原原位置和状态。不使用僵毁式屋顶透明。

**工作模式：单个 AI 会话连续执行。** 不需要我手动按模块发 27 个任务，也不要每做一个功能就问我能不能继续。你应当自己阅读需求、选择下一个能提升可玩性的完整功能切片、编辑 Godot 项目、生成或合法获取 2D 美术、运行测试、修复、提交 checkpoint、更新 `doc/` 和 `finished/`，然后继续下一个。尽可能推进到完整可发布的 Windows 游戏。每次测试结果写入日志；不能测试就清楚标注未验证，不得虚报。需要授权或付费/法律确认时才停下并记录阻塞。

先诊断现有 `game/` 原型能否在本机 Godot 中打开和运行，解决其真实错误并跑通“室外移动→房门→室内→搜刮→离开→战斗→保存→读档”的完整闭环。随后按 `doc/执行顺序与完成定义.md` 自主延伸机制，不要跳过验收而只堆积代码。引擎版本优先固定 4.7.2；如果电脑中只有其他版本，先诊断兼容性再决定变更。开始执行，不要只回复计划。
