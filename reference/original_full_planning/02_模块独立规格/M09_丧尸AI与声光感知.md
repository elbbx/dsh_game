## 1. 玩家体验与系统边界

视觉+遮挡+听觉+部分嗅觉；门窗攻击、楼梯、最后已知位置。本模块不得绕过物品所有权、世界层身份、世界时钟和全局事件幂等机制。

3. **最后位置记忆与超时清除**：输入由唯一对象ID、世界层、当前世界时钟以及必要的物品/技能/位置构成；先验证目标、条件和容量，再发布带event_id的动作事件；最后在统一状态记录中提交变更，更新显示并记录异常日志。

# 9. 丧尸类型、感知与尸潮

## 9.1 丧尸定位

丧尸是世界中数量最多的常规威胁。危险来自数量、声音、追逐、包围和持续消耗。

## 9.2 感知系统

  感知   机制
  ------ --------------------------------------
  视觉   根据距离、视野和遮挡发现玩家
  听觉   根据声音强度、距离和环境遮挡判断位置
  嗅觉   少数特殊丧尸追踪血液或气味

声音系统需要考虑墙壁、门窗、楼层和环境遮挡。

## 9.3 丧尸 AI 状态机

基础状态：

1.  游荡：随机移动、站立和徘徊。
2.  调查：发现声音后前往声音来源。
3.  发现目标：视觉或其他感知确认玩家。
4.  追逐：寻找路径并接近玩家。
5.  攻击：抓取、撕咬或攻击。
6.  搜索：失去目标后前往最后发现位置并搜索。
7.  恢复游荡：搜索失败后返回游荡。

丧尸失去视线后记录玩家最后出现位置，并前往该位置搜索。

## 9.4 丧尸能力

-   进入普通房屋。
-   撞击房门。
-   破坏部分门窗。
-   翻越低矮障碍。
-   使用楼梯在建筑内部移动。
-   聚集并挤压入口。
-   在建筑内部搜索玩家。

## 9.5 第一批丧尸种类

  类型       核心机制
  ---------- --------------------------------
  普通丧尸   行动缓慢，数量多，群体威胁高
  奔跑者     速度快，擅长追击
  爬行者     隐藏在家具、桌下和车辆附近
  膨胀丧尸   可能释放污染液体
  装甲丧尸   正面防护高，需要攻击暴露部位
  尖叫者     发现玩家后发出声音吸引附近尸群

普通丧尸必须占据绝大多数。特殊丧尸只在特定区域或事件中出现。

## 9.6 尸潮

尸潮采用动态模拟：

-   城镇、住宅区、医院和商业区有不同基础分布。
-   枪声、爆炸和警报吸引附近尸群。
-   尸群可以从多个方向向声音来源移动。
-   部分尸群在没有玩家干扰时缓慢迁徙。
-   尸群可以堵塞道路和建筑入口。
-   大量丧尸可以破坏外围防御设施。

玩家在超市搜刮时触发汽车警报，应当能够形成"继续搜刮、从后门撤离、丢弃物资、绕路或战斗"的选择。

# 12. 敌人刷新与世界生态

## 12.1 刷新原则

克苏鲁敌人刷新根据以下参数综合计算：

-   当前异常关注度。
-   最高解锁遭遇阶段。
-   当前区域污染等级。
-   昼夜和环境亮度。
-   区域刷新点类型。
-   当前区域活跃敌人数量。
-   玩家与刷新点的距离。
-   最近一次遭遇时间。
-   当前任务和特殊事件。

## 12.2 各级敌人刷新

  ---------------------------------------------------------------------------------------
  类型          主要区域                           刷新规则
  ------------- ---------------------------------- --------------------------------------
  T1            居民区边缘、森林、废弃建筑         可在较低关注度出现，数量相对多

  T2            建筑内部、地下室、低中污染区       关注度达到阶段1后提高概率

  T3            中高污染区、医院和研究设施         关注度达到阶段2后出现

  T4            高污染区、特殊地点外围             关注度达到阶段3后出现

  T5            固定遗迹、地下祭坛、核心实验设施   通过固定地点、调查进度或特殊事件触发
  ---------------------------------------------------------------------------------------

## 12.3 刷新保护规则

-   刷新锚点布置在玩家视野外，并结合遮挡、距离和环境预兆进行判定。
-   每类敌人设置最小生成距离和有效刷新范围。
-   高级敌人只在匹配的污染区域出现。
-   同一区域设置高级敌人数量上限。
-   同类遭遇设置刷新冷却。
-   T4出现前提供环境预兆。
-   安全据点使用独立刷新配置，敌人活动由据点防御和特殊事件控制。
-   T5只通过固定地点、任务或特殊事件触发。

## 12.4 环境预兆

高级敌人出现前可以出现：

-   远处短暂黑色轮廓。
-   环境光线异常。
-   无线电信号变化。
-   建筑内部不合理的阴影。
-   SAN短暂波动。
-   异常声音或空间视觉变化。

环境预兆采用多套表现组合，并根据区域与敌人类型变化；预兆提供威胁等级和方向线索。

## 12.5 丧尸与克苏鲁互动

  交互                           结果
  ------------------------------ ------------------------------------------------------------
  丧尸发现玩家                   追逐玩家
  丧尸发现可攻击克苏鲁           根据距离和攻击规则决定是否攻击
  敌对克苏鲁发现丧尸             可以攻击丧尸
  敌对克苏鲁发现玩家             满足感知与攻击条件后攻击
  T1发现玩家                     通过观察行为施加SAN压力
  玩家开枪                       声音事件由丧尸听觉系统响应，克苏鲁按视觉与特殊感知规则行动
  玩家照射具备光源感知的克苏鲁   可能触发光源仇恨

不同克苏鲁对丧尸的态度可以不同：捕食、驱赶、寄生、控制或忽略。

# 27. 克苏鲁仇恨值与持续追踪系统

## 27.1 设计目标

克苏鲁追踪由发现、仇恨积累、直接追逐、最后位置记忆、搜索和衰减构成。

需要建立一套有记忆、有仇恨积累、有视线判断、有搜索过程的AI系统。

核心行为：

-   看见玩家时，仇恨持续增加。
-   连续看到玩家越久，仇恨增长速度越快。
-   仇恨越高，移动速度越快。
-   失去视线后，移动速度明显下降。
-   失去视线后进入最后位置追踪和搜索状态。
-   敌人会前往玩家最后出现的位置。
-   到达最后位置后，会在附近搜索。
-   如果长时间找不到玩家，仇恨才逐渐消退。
-   敌人通过视线射线和特殊感知数据更新目标位置。

## 27.2 仇恨值

每个具备追踪能力的克苏鲁实例保存独立仇恨值：

`Aggro = 0–100`

仇恨值只代表该敌人对当前玩家的追踪和攻击意愿，不等同于全局异常关注度。

   仇恨值   状态   行为
  --------- ------ ----------------------------------
    0--19   游荡   按原有路径活动
   20--39   警觉   朝最后发现位置靠近
   40--59   追踪   主动追逐，速度提高
   60--79   狩猎   追踪更积极，搜索范围扩大
   80--100  狂猎   最高追踪速度，攻击间隔可适度缩短

T1使用视野SAN机制；T2使用低强度目标记忆；T3及以上使用完整仇恨系统。

## 27.3 持续视线与递增仇恨

仇恨增长必须体现"连续看到玩家越久，增长速度越快"。

建议使用连续可见时间 `continuous_sight_time`。

初始公式：

``` text
sight_multiplier = min(1 + continuous_sight_time / 5, 3)

aggro_gain_rate = base_aggro_gain × sight_multiplier
```

初始建议：

-   `base_aggro_gain = 1.5` 点/秒。
-   连续可见5秒，增长速度达到基础速度的2倍。
-   连续可见10秒，增长速度达到基础速度的3倍。
-   增长速度最高不超过基础速度的3倍。
-   仇恨值最高100。

实际仇恨增长：

``` text
Aggro += aggro_gain_rate × delta
Aggro = clamp(Aggro, 0, 100)
```

连续可见时间只在敌人确实看见玩家时增加。一旦失去视线，连续可见计时清零；重新看见时从基础增长速度重新开始。

## 27.4 其他仇恨修正

除持续视觉外，可以增加少量仇恨事件：

  事件                                仇恨变化建议
  ---------------------- --------------------------------------
  近距离直接看到玩家                    额外增加
  强光直接照射                          额外增加
  玩家对敌人造成伤害                    +10至20
  玩家在近距离进入视野                增长倍率提高
  玩家成功躲入掩体        停止视觉仇恨增长，并进入失去视线流程

克苏鲁的目标输入由视觉、光源、特殊感知和直接受击事件构成；枪声、脚步声和爆炸声音由丧尸听觉系统响应。

## 27.5 视线检测

必须使用真实遮挡检测。

判断因素：

-   敌人感知点到玩家身体检测点之间是否存在阻挡。
-   墙壁、关闭的门、实心家具和地形是否遮挡。
-   玩家是否在敌人视野角度内。
-   玩家与敌人之间距离是否满足感知范围。
-   光照和特殊视觉能力是否影响识别。

建议使用多个视线采样点：

-   玩家头部。
-   玩家胸部。
-   玩家身体中心。

至少一个有效采样点无遮挡时，可以判定为部分可见。完全遮挡时判定为失去视线。

## 27.6 掩体机制

掩体是玩家摆脱追踪的重要手段。

可用掩体包括：

-   建筑墙体。
-   关闭的实心门。
-   大型家具。
-   车辆车体。
-   岩石。
-   地形高差。
-   厚重的工业设备。

掩体效果：

1.  阻断敌人的直接视线。
2.  停止连续可见时间累积。
3.  触发敌人的最后位置记忆。
4.  降低敌人的追踪速度。
5.  给玩家转移位置、关灯、绕路或撤离的机会。

掩体遮挡能力由材质、厚度、破坏状态和敌人感知类型决定。

## 27.7 失去视线后的追踪

敌人失去视线后，使用last_seen_position作为导航目标，并通过搜索状态寻找玩家。

必须保存：

-   `last_seen_position`：最后看见玩家的位置。
-   `last_seen_time`：最后看见玩家的时间。
-   `last_seen_direction`：最后观察到的移动方向。
-   `search_center`：搜索中心。
-   `search_radius`：搜索半径。
-   `search_timer`：搜索剩余时间。

行为流程：

1.  玩家进入掩体后，敌人失去视线。
2.  敌人记录最后发现位置。
3.  敌人降低移动速度。
4.  敌人向最后发现位置移动。
5.  到达该位置后，在附近进行搜索。
6.  搜索范围根据仇恨值和敌人类型变化。
7.  如果重新看见玩家，重新进入直接追踪。
8.  如果搜索超时，仇恨逐渐衰减并返回区域活动状态。

## 27.8 仇恨与移动速度关系

建议使用两个独立乘数：

1.  仇恨速度倍率。
2.  视线状态倍率。

仇恨速度倍率：

``` text
aggro_speed_multiplier = 0.75 + 0.5 × (Aggro / 100)
```

结果：

   仇恨值   速度倍率
  -------- ----------
     0        0.75
     25      0.875
     50       1.00
     75      1.125
    100       1.25

视线状态倍率：

  状态                      速度倍率
  ------------------------ ----------
  直接看见玩家                1.00
  失去视线，前往最后位置      0.65
  到达最后位置，搜索附近      0.40
  搜索结束，返回区域          0.55

最终移动速度：

``` text
final_speed =
    base_speed
    × aggro_speed_multiplier
    × visibility_state_multiplier
    × creature_speed_modifier
```

高仇恨敌人在失去视线后明显减速，并继续执行最后位置追踪和搜索。

## 27.9 仇恨衰减

仇恨在失去视线后按照保留时间、搜索阶段和衰减速率逐步变化。

建议：

  阶段           仇恨处理
  -------------- ------------------------------------
  刚失去视线     保留当前仇恨一段时间，维持追踪压力
  前往最后位置   缓慢衰减
  搜索阶段       缓慢衰减
  搜索超时       中速衰减
  返回区域       较快衰减

初始参数：

-   失去视线后保留高仇恨2秒。
-   最后位置追踪时间：8--15秒。
-   搜索时间：6--12秒。
-   搜索结束后仇恨每秒降低3--5点。
-   当仇恨低于20时，允许返回普通游荡状态。

仇恨记忆时间根据敌人类型配置；高级克苏鲁拥有更长记忆和更大搜索范围，并通过记忆时长与区域边界控制追踪。

## 27.10 追踪状态机

``` text
IDLE
  ↓ 发现玩家
VISUAL_ACQUIRE
  ↓ 确认目标
DIRECT_CHASE
  ↓ 失去视线
LAST_KNOWN_POSITION
  ↓ 到达最后位置
SEARCH
  ├── 重新看见玩家 → DIRECT_CHASE
  ├── 找到新的有效线索 → INVESTIGATE
  └── 搜索超时 → RETURN_TO_TERRITORY
                         ↓
                       IDLE
```

`INVESTIGATE`使用该敌人配置的特殊感知线索更新目标位置；普通声音事件由丧尸听觉系统处理。

## 27.11 光源与仇恨系统联动

光源是部分高级克苏鲁发现玩家和建立仇恨的特殊来源。

-   夜间直接照射具备光源感知的克苏鲁时，触发感知。
-   光源被发现后，敌人获得玩家的最后有效位置。
-   光源持续照射时，仇恨持续增长。
-   玩家关闭光源后，敌人根据最后光源位置和搜索范围继续行动。
-   敌人前往最后感知位置并进行搜索。
-   信号棒可以作为部分敌人的光源诱饵。
-   每种生物通过光源感知配置定义可识别的光源类型。

光源机制与普通视觉共享同一套仇恨系统，避免出现两个互相冲突的追踪系统。
