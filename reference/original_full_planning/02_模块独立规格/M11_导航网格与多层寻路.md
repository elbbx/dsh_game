## 3. 模块专属规则、数值逻辑与边界

### 导航图层
`WorldPortalGraph`存区块边、道路、桥梁、建筑入口与楼层连接；粗图A*用于长途路线；近距离使用`NavigationServer3D`的局部路径。每个楼梯是明确的上下层Portal并带双端锚点；门是可开/需破坏/不可用的动态边。重新烘焙按变更区域批量执行，导航改动至少等待下一个物理帧同步再查询。路径规划失败分为“未加载/区域断开/不可穿门/等待地形刷新”，各自响应不同，不能简单把敌人传送到玩家旁。

# 9. 丧尸类型、感知与尸潮

## 9.1 丧尸定位

丧尸是世界中数量最多的常规威胁。危险来自数量、声音、追逐、包围和持续消耗。

## 9.2 感知系统

  感知   机制
  ------ --------------------------------------
  视觉   根据距离、视野和遮挡发现玩家
  听觉   根据声音强度、距离和环境遮挡判断位置
  嗅觉   少数特殊丧尸追踪血液或气味

声音系统需要考虑墙壁、门窗、楼层和环境遮挡。

## 9.3 丧尸 AI 状态机

基础状态：

1.  游荡：随机移动、站立和徘徊。
2.  调查：发现声音后前往声音来源。
3.  发现目标：视觉或其他感知确认玩家。
4.  追逐：寻找路径并接近玩家。
5.  攻击：抓取、撕咬或攻击。
6.  搜索：失去目标后前往最后发现位置并搜索。
7.  恢复游荡：搜索失败后返回游荡。

丧尸失去视线后记录玩家最后出现位置，并前往该位置搜索。

## 9.4 丧尸能力

-   进入普通房屋。
-   撞击房门。
-   破坏部分门窗。
-   翻越低矮障碍。
-   使用楼梯在建筑内部移动。
-   聚集并挤压入口。
-   在建筑内部搜索玩家。

## 9.5 第一批丧尸种类

  类型       核心机制
  ---------- --------------------------------
  普通丧尸   行动缓慢，数量多，群体威胁高
  奔跑者     速度快，擅长追击
  爬行者     隐藏在家具、桌下和车辆附近
  膨胀丧尸   可能释放污染液体
  装甲丧尸   正面防护高，需要攻击暴露部位
  尖叫者     发现玩家后发出声音吸引附近尸群

普通丧尸必须占据绝大多数。特殊丧尸只在特定区域或事件中出现。

## 9.6 尸潮

尸潮采用动态模拟：

-   城镇、住宅区、医院和商业区有不同基础分布。
-   枪声、爆炸和警报吸引附近尸群。
-   尸群可以从多个方向向声音来源移动。
-   部分尸群在没有玩家干扰时缓慢迁徙。
-   尸群可以堵塞道路和建筑入口。
-   大量丧尸可以破坏外围防御设施。

玩家在超市搜刮时触发汽车警报，应当能够形成"继续搜刮、从后门撤离、丢弃物资、绕路或战斗"的选择。

# 27. 克苏鲁仇恨值与持续追踪系统

## 27.1 设计目标

克苏鲁追踪由发现、仇恨积累、直接追逐、最后位置记忆、搜索和衰减构成。

需要建立一套有记忆、有仇恨积累、有视线判断、有搜索过程的AI系统。

核心行为：

-   看见玩家时，仇恨持续增加。
-   连续看到玩家越久，仇恨增长速度越快。
-   仇恨越高，移动速度越快。
-   失去视线后，移动速度明显下降。
-   失去视线后进入最后位置追踪和搜索状态。
-   敌人会前往玩家最后出现的位置。
-   到达最后位置后，会在附近搜索。
-   如果长时间找不到玩家，仇恨才逐渐消退。
-   敌人通过视线射线和特殊感知数据更新目标位置。

## 27.2 仇恨值

每个具备追踪能力的克苏鲁实例保存独立仇恨值：

`Aggro = 0–100`

仇恨值只代表该敌人对当前玩家的追踪和攻击意愿，不等同于全局异常关注度。

   仇恨值   状态   行为
  --------- ------ ----------------------------------
    0--19   游荡   按原有路径活动
   20--39   警觉   朝最后发现位置靠近
   40--59   追踪   主动追逐，速度提高
   60--79   狩猎   追踪更积极，搜索范围扩大
   80--100  狂猎   最高追踪速度，攻击间隔可适度缩短

T1使用视野SAN机制；T2使用低强度目标记忆；T3及以上使用完整仇恨系统。

## 27.3 持续视线与递增仇恨

仇恨增长必须体现"连续看到玩家越久，增长速度越快"。

建议使用连续可见时间 `continuous_sight_time`。

初始公式：

``` text
sight_multiplier = min(1 + continuous_sight_time / 5, 3)

aggro_gain_rate = base_aggro_gain × sight_multiplier
```

初始建议：

-   `base_aggro_gain = 1.5` 点/秒。
-   连续可见5秒，增长速度达到基础速度的2倍。
-   连续可见10秒，增长速度达到基础速度的3倍。
-   增长速度最高不超过基础速度的3倍。
-   仇恨值最高100。

实际仇恨增长：

``` text
Aggro += aggro_gain_rate × delta
Aggro = clamp(Aggro, 0, 100)
```

连续可见时间只在敌人确实看见玩家时增加。一旦失去视线，连续可见计时清零；重新看见时从基础增长速度重新开始。

## 27.4 其他仇恨修正

除持续视觉外，可以增加少量仇恨事件：

  事件                                仇恨变化建议
  ---------------------- --------------------------------------
  近距离直接看到玩家                    额外增加
  强光直接照射                          额外增加
  玩家对敌人造成伤害                    +10至20
  玩家在近距离进入视野                增长倍率提高
  玩家成功躲入掩体        停止视觉仇恨增长，并进入失去视线流程

克苏鲁的目标输入由视觉、光源、特殊感知和直接受击事件构成；枪声、脚步声和爆炸声音由丧尸听觉系统响应。

## 27.5 视线检测

必须使用真实遮挡检测。

判断因素：

-   敌人感知点到玩家身体检测点之间是否存在阻挡。
-   墙壁、关闭的门、实心家具和地形是否遮挡。
-   玩家是否在敌人视野角度内。
-   玩家与敌人之间距离是否满足感知范围。
-   光照和特殊视觉能力是否影响识别。

建议使用多个视线采样点：

-   玩家头部。
-   玩家胸部。
-   玩家身体中心。

至少一个有效采样点无遮挡时，可以判定为部分可见。完全遮挡时判定为失去视线。

## 27.6 掩体机制

掩体是玩家摆脱追踪的重要手段。

可用掩体包括：

-   建筑墙体。
-   关闭的实心门。
-   大型家具。
-   车辆车体。
-   岩石。
-   地形高差。
-   厚重的工业设备。

掩体效果：

1.  阻断敌人的直接视线。
2.  停止连续可见时间累积。
3.  触发敌人的最后位置记忆。
4.  降低敌人的追踪速度。
5.  给玩家转移位置、关灯、绕路或撤离的机会。

掩体遮挡能力由材质、厚度、破坏状态和敌人感知类型决定。

## 27.7 失去视线后的追踪

敌人失去视线后，使用last_seen_position作为导航目标，并通过搜索状态寻找玩家。

必须保存：

-   `last_seen_position`：最后看见玩家的位置。
-   `last_seen_time`：最后看见玩家的时间。
-   `last_seen_direction`：最后观察到的移动方向。
-   `search_center`：搜索中心。
-   `search_radius`：搜索半径。
-   `search_timer`：搜索剩余时间。

行为流程：

1.  玩家进入掩体后，敌人失去视线。
2.  敌人记录最后发现位置。
3.  敌人降低移动速度。
4.  敌人向最后发现位置移动。
5.  到达该位置后，在附近进行搜索。
6.  搜索范围根据仇恨值和敌人类型变化。
7.  如果重新看见玩家，重新进入直接追踪。
8.  如果搜索超时，仇恨逐渐衰减并返回区域活动状态。

## 27.8 仇恨与移动速度关系

建议使用两个独立乘数：

1.  仇恨速度倍率。
2.  视线状态倍率。

仇恨速度倍率：

``` text
aggro_speed_multiplier = 0.75 + 0.5 × (Aggro / 100)
```

结果：

   仇恨值   速度倍率
  -------- ----------
     0        0.75
     25      0.875
     50       1.00
     75      1.125
    100       1.25

视线状态倍率：

  状态                      速度倍率
  ------------------------ ----------
  直接看见玩家                1.00
  失去视线，前往最后位置      0.65
  到达最后位置，搜索附近      0.40
  搜索结束，返回区域          0.55

最终移动速度：

``` text
final_speed =
    base_speed
    × aggro_speed_multiplier
    × visibility_state_multiplier
    × creature_speed_modifier
```

高仇恨敌人在失去视线后明显减速，并继续执行最后位置追踪和搜索。

## 27.9 仇恨衰减

仇恨在失去视线后按照保留时间、搜索阶段和衰减速率逐步变化。

建议：

  阶段           仇恨处理
  -------------- ------------------------------------
  刚失去视线     保留当前仇恨一段时间，维持追踪压力
  前往最后位置   缓慢衰减
  搜索阶段       缓慢衰减
  搜索超时       中速衰减
  返回区域       较快衰减

初始参数：

-   失去视线后保留高仇恨2秒。
-   最后位置追踪时间：8--15秒。
-   搜索时间：6--12秒。
-   搜索结束后仇恨每秒降低3--5点。
-   当仇恨低于20时，允许返回普通游荡状态。

仇恨记忆时间根据敌人类型配置；高级克苏鲁拥有更长记忆和更大搜索范围，并通过记忆时长与区域边界控制追踪。

## 27.10 追踪状态机

``` text
IDLE
  ↓ 发现玩家
VISUAL_ACQUIRE
  ↓ 确认目标
DIRECT_CHASE
  ↓ 失去视线
LAST_KNOWN_POSITION
  ↓ 到达最后位置
SEARCH
  ├── 重新看见玩家 → DIRECT_CHASE
  ├── 找到新的有效线索 → INVESTIGATE
  └── 搜索超时 → RETURN_TO_TERRITORY
                         ↓
                       IDLE
```

`INVESTIGATE`使用该敌人配置的特殊感知线索更新目标位置；普通声音事件由丧尸听觉系统处理。

## 27.11 光源与仇恨系统联动

光源是部分高级克苏鲁发现玩家和建立仇恨的特殊来源。

-   夜间直接照射具备光源感知的克苏鲁时，触发感知。
-   光源被发现后，敌人获得玩家的最后有效位置。
-   光源持续照射时，仇恨持续增长。
-   玩家关闭光源后，敌人根据最后光源位置和搜索范围继续行动。
-   敌人前往最后感知位置并进行搜索。
-   信号棒可以作为部分敌人的光源诱饵。
-   每种生物通过光源感知配置定义可识别的光源类型。

光源机制与普通视觉共享同一套仇恨系统，避免出现两个互相冲突的追踪系统。

# 28. 固定型、区域型与伏击型克苏鲁

## 28.1 敌人移动类型分类

克苏鲁除了T1--T5威胁等级，还应增加独立的移动类型标签。

威胁等级决定强度和能力；移动类型决定敌人的空间活动方式。

  移动类型     说明
  ------------ --------------------------------
  普通追踪型   可以离开出生点追逐玩家
  固定扎根型   固定在地面、墙体或天花板
  区域活动型   只能在指定领地范围内活动
  潜伏伏击型   休眠或伪装，满足条件后发动攻击

同一个敌人可以同时具有威胁等级和移动类型。例如T4固定扎根型、T3区域活动型。

## 28.2 固定扎根型 Rooted Creature

固定扎根型敌人的主体锚定在地面、墙体或天花板。

常见位置：

-   地面裂隙周围。
-   地下室。
-   建筑墙体。
-   天花板。
-   地下通道。
-   大型异常生物巢穴。

外观可以是触手团、肉质根系、附着在墙面的生物组织或大型生物器官。

### 核心机制

-   主体固定在一个锚点。
-   通过触手、孢子、投射物或区域效果攻击。
-   仇恨值影响攻击积极程度。
-   固定型敌人的仇恨值转换为攻击频率、触手速度和攻击范围。
-   固定型敌人的攻击范围由触手长度和区域判定控制。
-   玩家可以破坏触手、攻击核心或离开控制区域。

### 固定型敌人的仇恨表现

   仇恨值   行为
  --------- ----------------------------------
    0--19   缓慢活动，偶尔伸出触手
   20--39   触手开始感知附近目标
   40--59   攻击频率提高，触手伸展距离增加
   60--79   多根触手连续攻击
   80--100  进入高强度攻击阶段，攻击间隔缩短

仇恨值影响：

-   触手伸展速度。
-   攻击频率。
-   攻击范围。
-   触手数量。
-   攻击预判程度。

固定型敌人通过触手伸展和区域攻击维持威胁，主体位置保持锚定。

### 固定型敌人的弱点

建议至少提供一种明确的反制方式：

-   破坏触手节点。
-   攻击裸露核心。
-   使用远程武器攻击根部。
-   关闭或破坏其异常供能装置。
-   从攻击范围外绕行。

固定型敌人可以作为地图区域障碍，玩家可以通过破坏节点、暂时压制或绕行完成应对。

## 28.3 区域活动型 Territorial Creature

区域活动型敌人有一个固定领地，但可以在领地内部移动。

例如：

-   活动范围为医院的一层和地下室。
-   活动范围为一栋大型仓库。
-   活动范围为森林中的一片空地。
-   活动范围为一段地下隧道。
-   活动范围为某个裂隙周围的区域。

### 领地数据

  参数                 说明
  -------------------- --------------
  `territory_center`   领地中心
  `territory_radius`   最大活动半径
  `patrol_points`      巡逻点
  `leash_distance`     最大追击距离
  `return_speed`       返回领地速度
  `territory_state`    领地当前状态

初始建议：

-   普通区域型敌人活动半径：15--25米。
-   大型敌人活动半径：25--40米。
-   追击范围由领地半径和leash_distance统一控制。
-   玩家离开领地后，敌人最多追到边界附近。

### 行为流程

1.  在领地内巡逻。
2.  发现玩家后增加仇恨。
3.  在领地内追逐玩家。
4.  玩家躲入掩体后，敌人前往最后发现位置。
5.  在领地范围内搜索。
6.  玩家离开领地后，敌人停止扩大追击范围。
7.  搜索失败后返回巡逻路线。

区域型敌人按照领地半径、巡逻点和追击边界活动。

### 领地边界表现

可以通过环境表现暗示领地边界：

-   地面菌丝密度变化。
-   墙面触手分布变化。
-   光线和雾气变化。
-   特殊地面纹理。
-   异常声音和视觉干扰。

领地边界通过地面菌丝、墙面触手、光照和雾气向玩家呈现。

## 28.4 潜伏伏击型 Ambush Creature

潜伏型敌人可以伪装成环境物体或处于休眠状态。

可能伪装的位置：

-   墙壁和天花板。
-   地面裂口。
-   家具背后。
-   废弃车辆。
-   建筑阴影。
-   大型异常组织。

触发条件：

-   玩家进入感知范围。
-   玩家触碰附近物体。
-   玩家停留时间过长。
-   玩家进入异常区域。
-   玩家照射其弱点或核心。

攻击后进入短暂暴露状态，允许玩家反击。

潜伏型敌人通过轻微移动、材质异常、呼吸状起伏或SAN波动提供可观察线索。

## 28.5 三种类型的战斗差异

  类型         玩家主要应对方式
  ------------ ----------------------------------------
  普通追踪型   利用掩体、绕路、拉开距离、攻击
  固定扎根型   判断攻击范围、破坏触手、攻击核心、绕行
  区域活动型   观察领地边界、诱导敌人、脱离区域
  潜伏伏击型   观察环境、提前发现、快速反击

# 39. 风险管理与技术验证清单

## 39.1 双世界同步风险

**验证重点：**
建筑、容器、门窗、家具和物品在两个世界使用相同实体ID和状态数据。

**技术措施：**
SharedWorldState集中管理实体状态；世界表现层根据当前WorldLayer读取状态；所有交互先更新共享数据，再刷新表现。

## 39.2 大地图AI性能

**验证重点：** 敌人数量增加时CPU、导航和物理开销的变化。

**技术措施：**
完整AI、简化AI和区域统计三级模拟；按玩家距离和区域活动状态切换更新频率。

## 39.3 建筑内部寻路

**验证重点：** 丧尸和克苏鲁能够识别门、楼梯、走廊和可破坏入口。

**技术措施：**
建筑内部导航区域分层管理，楼梯和门口使用连接点，破坏门窗后更新局部导航状态。

## 39.4 背包网格逻辑

**验证重点：** 物品旋转、堆叠、拆分、快速转移和容器嵌套后的占用正确性。

**技术措施：**
使用统一的GridContainer数据模型，UI只负责显示和操作请求，物品位置由InventorySystem验证和提交。

## 39.5 技能与体型计算

**验证重点：** 基础技能等级、有效技能等级和每一级能力解锁之间的关系。

**技术措施：**
基础等级永久保存；体型修正独立保存；有效等级实时计算；各级能力只读取基础等级。

## 39.6 克苏鲁追踪AI

**验证重点：** 视线中断、掩体、最后位置、搜索、仇恨衰减和区域边界。

**技术措施：**
将感知、仇恨、目标记忆、导航和攻击拆成独立组件；使用调试视线和目标点显示工具。

## 39.7 裂隙捕获与世界切换

**验证重点：**
抓取动画、玩家控制状态、目标世界落点、裂隙配对和存档恢复。

**技术措施：**
使用独立TransitionController管理过渡；切换前保存玩家状态和裂隙ID；切换后执行落点检测和状态恢复。

## 39.8 长期存档一致性

**验证重点：**
世界时间、热量余额、容器内容、敌人状态和裂隙状态的长期一致性。

**技术措施：**
存档使用版本号、唯一ID和时间戳；重要世界实体采用增量状态保存；读档后按依赖顺序恢复。

# 94. 挖掘地形与建筑道路载具的交互

## 94.1 挖掘边界与结构保护

- 建筑地基和预制地下室通过结构支撑代理参与稳定计算；下方可挖区域失去足够支撑会逐步受损，先给出裂纹和危险提示。
- 主线任务建筑、不可替代的NPC建筑、主干桥梁锚点和至少一条裂隙返程通路需设置保护区或可修复的安全机制。
- 玩家建造的地板、矿道木支柱、临时梯子和井口护栏可提供明确的支护效果；拆除构件后按局部依赖计算。
- 在普通道路下开掘只对可挖掘区生效；已保护的主干路基不能被低级镐头从地下随意掏空。
- 矿道塌方和地形挖空不能让服务器式事务中的NPC、车辆、货物或玩家落入未加载空间。

## 94.2 导航和敌人进出

采掘改变可站立表面后触发局部导航区域重建，并校验矿道坡度、通道最小宽度和楼梯/梯子连接。普通丧尸可以在满足体型和通行规则的矿道里寻路与调查声音；狭窄洞口会形成堵塞与撤退战术。克苏鲁使用原有区域边界和追踪规则，不能穿越真实岩层。远距离矿道NPC/敌人按事件摘要模拟，不为所有地下空间常驻完整寻路。

## 94.3 载具与开采地点

采矿区、采石场和林地可以设置车辆停靠位、木料装卸处和临时矿石箱。车辆能在玩家挖出的合法道路上行驶时需要足够宽的碰撞通道、坡度和高度；不能因为有一条挖出来的狭窄洞穴就允许SUV直接穿过。重载使车辆油耗与悬挂损耗变化；湿泥坡增加陷车风险。车内矿石、木料、工具与其他货物共用第75章真实库存，不创建“矿石专用无限车仓”。

## 94.4 地图标识与路径记忆

玩家可标记矿口、剩余储量预估、坡道、井口危险、采石场与林业点。已探索矿道在本地地图以简化剖面/层级信息显示，而不必须绘制全3D地下透视地图。洞穴入口和出口对应稳定世界坐标。已有矿洞路径在载入时必须恢复，不允许读档让出口变回实心石壁。
