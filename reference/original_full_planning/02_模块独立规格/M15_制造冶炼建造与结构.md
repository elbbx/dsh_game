## 3. 模块专属规则、数值逻辑与边界

### 配方执行工序
矿→筛选/破碎→冶炼→铸锭→零件→成品；木→砍伐→切段→干燥→锯板→家具/建材。每张配方必须标注材料ID、数量、工作台、电量、技能要求、加工时间、副产物和可中断阶段。玩家工作台可从据点有效连接储物箱调取材料，但不允许跨世界或无限距离取物。

## 4. 运行时数据与职责

- **定义资源**：`15_Definition`：保留静态属性、参数上下限、版本号和关联ID。
- **实例状态**：`15_InstanceState`：保留instance_id、world_layer、last_tick、state_version及本模块运行字段。
- **动作请求**：`15_ActionRequest`：actor_id、target_id、requested_time、payload、event_id。
- **写入策略**：本模块仅写其负责的实例字段，对其他模块通过事件和接口请求变更。

# 48. 玩家建造、拆除、制造与研究

## 48.1 建造范围

玩家既可把现有住宅改造成据点，也可在允许的区域放置基础设施。建设系统分为**建筑结构**（地板、墙、门、窗、屋顶、楼梯、平台）、**室内设施**（床、箱、工作台、炉灶）、**防御设施**（围墙、路障、陷阱、瞭望塔）和**电力设施**（发电机、太阳能板、锂电池、中继器、照明、哨塔）。结构应支持后续升级，而不是每次升级必须全部拆掉重造。

## 48.2 建造交互流程

打开建造菜单→选择结构或设施→预览透明模型→旋转/网格或自由吸附→校验占地与墙体连接→显示材料、制作/电力等级和耗时→确认放置→消耗材料→生成具有永久ID的实体→刷新碰撞、局部导航及供电/室内状态→写入存档。

拒绝放置的原因要明确显示：地形太斜、空间被占、缺少支撑、与门重叠、阻塞必经出口、材料不足、区域禁止建筑、碰撞其他玩家/敌人。已存在的家具移动遵循“拿起→占用背包或搬运状态→放下”原子事务。

## 48.3 结构稳定与玩家体验

使用轻量的支撑关系图，不做复杂实时材料物理仿真：基础地板可落地；上层楼板需要附近承重墙/柱/支撑点；悬空平台受最大跨距限制；删除承重件时可先预览将失去支撑的构件。倒塌/拆除产生材料回收，但有损耗。自动识别屋顶封闭性，用于温度、雨淋、睡眠安全和照明遮蔽。

## 48.5 配方数据与制作步骤

每条 `RecipeData` 保存：`recipe_id`、`input_items`、`output_items`、`tool_tags`、`station_tags`、`required_skill_levels`、`craft_time_min`、`power_kw_if_required`、`research_unlock`、`is_repeatable`。制作流程包含材料预留、制作耗时与任务中断处理；中断时原料或半成品按配方规则返还，不会因保存/切换世界重复产出。

配方可以通过逐级能力、图纸、NPC任务、特殊调查解锁。技能解锁“会做”，材料和工作台决定“能做”，供电和时间决定“做得成”。普通家具和基础材料不应需要高等级技能；高级塔防、电力、医疗配方才设置多技能门槛。

## 48.6 维修、拆解与资源回收

物品、门窗、围墙、塔楼和电力设备使用统一耐久接口。维修消耗对应材料和工具，成功恢复一定耐久；拆解根据材料类型回收30%—75%且不保证完整，避免拆/建无限刷材料。特殊可搬运家具在有空间的前提下优先完整收取，否则提供拆解选项。强制拆除引起物品掉落时，必须先确定唯一落点及唯一实例ID。

## 48.7 建造过程与敌人反应

锤击、锯切、焊接、发电机运转产生不同强度声音事件，丧尸可被吸引；焊接、工作灯、探照灯在夜间可能触发拥有光源感知的克苏鲁。正在进行的建造可因受伤、移动、敌人攻击中断。守卫NPC只做有限岗位动作，不替代玩家自动建设整个基地。

## 48.8 共用世界的设施行为

玩家建造设施与其耐久、开关和库存使用同一实例数据。玩家当前所处世界层决定设备能否激活：默认主世界普通据点设备可运作；颠倒世界中的相同设施占位和持久状态保持映射，设备动态运转由当前世界层的环境约束控制。任何来自一侧的破坏和修复应通过共享实例反映到另一侧，不进行两套设施双倍生产或双重燃料消耗。

# 63. 衣物破损、补丁与护甲维护

## 63.1 局部破损

受击部位将使覆盖它的衣物/护甲局部耐久下降。建议使用“部位耐久百分比+破洞标签”而不是在每张低模网格上做实时布料破裂模拟。一个左臂破洞会降低左臂抓咬防护、防雨和保暖；右臂仍按照未破损数据计算。装备耐久到零时标记报废，保留可拆回收材料。自动维修不应在存档加载时发生。

## 63.2 修补类型

| 修补方式 | 材料 | 工具/工作台 | 效果 |
|---|---|---|---|
| 临时缝合 | 针、线、布片 | 手工 | 恢复部分基础耐久与保暖，不保证抗咬完全恢复 |
| 同材质补丁 | 牛仔布、皮革片、合成布 | 裁缝工具或工作台 | 恢复局部防护，并产生略可见补丁 |
| 强化衬垫 | 厚布、皮革、轻量护板 | 高级制作台 | 增加抓/咬防护，同时提高重量与闷热 |
| 防水修补 | 防水布、胶带、密封材料 | 手工/工作台 | 恢复雨衣局部防水能力 |
| 护甲板替换 | 专用护板与固定件 | 防护装备维护台 | 主要恢复弹道/重型防护，与普通缝补分开 |

## 63.3 与十技能的关系

- **制作5级**：基础针线、布片修补、简易晾衣绳；**10级**：皮革、牛仔补丁；**15级**：防水修补与基础衬垫；**20级**：复合衬垫及护甲载体加工；**25级**：高级定制防护与复杂维护。此为追加解锁，不删除原有建造配方。
- **生存**：制作简易露营干燥架、野外衣物护理、识别安全水源；不决定护甲材料加工。
- **医疗**：清洁伤口和换绷带，不负责衣物强度属性。
- **机械/电力**：洗衣烘干设备修理及接线，修补服装仍为制作技能。

## 63.4 资源循环与防刷级

拆解坏衣可得到布条/线/皮革残片；修补后可以继续使用，但每次修补有**可恢复耐久上限**和材料消耗，防止无限刷品质。经验按“首次修复有效损失、材料消耗、实际获得耐久”发放，反复脱穿、洗干净衣物或洗已干衣服不能刷制作/电力经验。

## 63.5 战斗与外观

以可复用贴图遮罩/局部材质叠层表现血污、泥污、破洞和补丁，不要求给每件衣服制作数十套glb。防护属性以数据为准；特效不改变碰撞体与七部位判定。血污和湿度的视觉更新分级，远处角色仅用低精度状态标记。

# 91. 木材、矿石与工业原料加工链

## 91.1 工序结构

原料不直接变成高级装备，分为：**采集 → 分拣/运输 → 初加工 → 炉窑/冶炼 → 部件加工 → 成品组装**。玩家可以把搜刮所得零件直接用于制作，但若长期建设大据点，就需要建立稳定矿木材料供应。初级加工提供足够早期可用性，中高级工业通过更可靠的产率、批量生产和高阶材料体现发展。

## 91.2 工作设施

| 设施 | 核心用途 | 需要的基础资源 | 能源关系 |
|---|---|---|---|
| 手工处理区 | 分拣石料、手锯切木、制作柴薪 | 工具与干燥地面 | 不需供电 |
| 木工工作台 | 木板、木箱、门板、木支柱 | 原木、锯、钉等 | 手工操作 |
| 木炭窑 | 木柴转换为木炭 | 土/石/黏土、木料 | 直接燃烧原料，不自动发电 |
| 简易熔炉 | 铁矿初步熔炼、简单铜加工 | 黏土砖、石料、燃料 | 独立热源，不需电力接网 |
| 工业熔炉 | 批量矿石加工和较复杂合金 | 金属框架、耐火砖等 | 可燃料燃烧，自动化控制部分耗电 |
| 金属工作台 | 铁工具、支架、钢材部件 | 铁锭、紧固件、工具 | 纯手工版本不需电，机器版需供电 |
| 机修台 | 车件、动力钻具、链锯维修 | 金属零件、工具 | 对应机器型号可能需电 |
| 资源仓储架 | 按矿石、燃料、金属和木板分类 | 木板或金属架 | 不需供电 |

生活炉灶负责烹饪，普通熔炉负责冶炼，燃烧式**发电炉**负责热能转换成电能，三者的输入和输出不能混用为“火一烧就免费发电”。资源可以共享燃料物品，但设备工艺独立。

## 91.3 基础建材供应链

- 石块 → 碎石/石料 → 基础地基、路面、围墙、石质防御结构。
- 砂 + 黏土 → 砖坯/烧制砖 → 炉体、壁炉、墙体与耐火结构。
- 石灰石 + 砂 + 水 → 游戏化砂浆材料 → 高级墙基、支柱与部分混凝土组件。
- 原木 → 木板 + 副产木屑 → 房屋墙板、地板、木箱、楼梯和哨塔平台。
- 木材 → 木柴 → 营火、烹饪、取暖；木材 → 木炭 → 熔炉或发电炉燃料。
- 铁矿 → 铁锭 → 铁钉、镐头、斧头、门框、护板、围墙骨架。
- 铁锭 + 碳质材料 → 钢材 → 高等级工具、机械零件与自动哨塔结构。
- 铜矿 → 铜锭 → 铜导线/接头 → 中继器、电力设备、修车电路。

## 91.4 原材料加工中的空间经济

加工后的成品根据真实设计占用网格、重量和可堆叠数，运输价值受到车斗载重、道路和天气影响。原木可以通过皮卡装运；矿石通常更重，鼓励玩家在矿区设临时中转箱而不是一趟背回整座矿山。工作台可以从附近已授权仓储容器读取材料，但必须从一个明确库存逐件扣除，不能同时计入车厢和据点仓库。

# 92. 冶炼、燃烧发电、金属制造与物料守恒

## 92.1 冶炼步骤

铁矿示例：`筛选矿石 → 检查熔炉结构与燃料 → 分批加入铁矿 → 经过游戏时间完成工序 → 产出铁锭与少量废渣 → 冷却或转入工作台`。配方由工作台/炉窑有效性、制作等级、矿石品质、燃料供应和实际时间共同决定。

铜与其他矿石采用各自配方，不能把煤矿直接当成铁锭，也不能让玩家凭按键从泥土造出电子设备。高级合金以抽象游戏配方表现，不提供现实危险化学制造细节。

## 92.2 原料与产物的参考配方

以下物料单位是**游戏配方单位**，不是精确工业化学计量；实际质量和体积单独在物品数据中设置。输出需满足总物料预算和损耗规则。

| 工序 | 输入示例 | 输出示例 | 时间与设备 |
|---|---|---|---|
| 砍伐加工 | 原木2份 | 木板3份 + 木屑1份 | 木工台，2—4游戏分钟 |
| 备制柴薪 | 原木1份 | 柴薪2份 + 树皮1份 | 斧/锯，约1分钟 |
| 木炭窑 | 干柴4份 | 木炭2份 + 灰烬/消耗 | 炭窑，约12分钟 |
| 制砖 | 黏土3份 + 砂1份 + 燃料 | 烧制砖3份 + 损耗 | 砖窑/熔炉，约8分钟 |
| 铁矿冶炼 | 铁矿4份 + 燃料 | 铁锭2份 + 废渣 | 熔炉，约10分钟 |
| 铜矿冶炼 | 铜矿4份 + 燃料 | 铜锭2份 + 废渣 | 熔炉，约10分钟 |
| 钢材制造 | 铁锭3份 + 煤/木炭1份 | 钢材2份 + 工业残渣 | 工业熔炉，约15分钟 |
| 铜导线 | 铜锭1份 + 加工材料 | 导线束2份 | 金属工作台，约4分钟 |

同一种物料在不同制作阶段的“份数”并不要求等质量，但每条配方的原料总质量、产品质量、残渣及燃烧排放必须在游戏经济上守恒，禁止从1单位铁矿重复炼出无限金属。高等级技能主要降低工序损耗或加快速度，受产率上限约束。

## 92.3 煤、木柴与木炭发电

燃烧式发电炉延续第51章，功率初始参考1.2 kW；可以消耗干木柴、木炭及煤。单个设备的热机发电参数不因材料升级而无限提高额定功率，燃料品质主要影响运行时长、积灰速度、排烟和维护成本。

| 燃料 | 每1份（等质量参考）可维持1.2 kW输出的测试时长 | 特性 |
|---|---:|---|
| 湿木柴 | 6游戏分钟 | 发热效率低、烟多、点火更困难 |
| 干木柴 | 12游戏分钟 | 易获得、可通过植树再生 |
| 木炭 | 20游戏分钟 | 单位重量燃烧更持久，制作需耗材与时间 |
| 煤 | 30游戏分钟 | 更适合长时间稳定发电、积灰与烟尘较高 |

单位燃料真实重量和游戏时间倍率在物品配置中另行统一，以上只是用于比较燃料效能的首轮平衡参数。发电计算仍严格按 `发电量(kW) × 游戏时间(h) → 电量(kWh)` 结算；燃料不足时必须中断输出。煤作为燃料需要有独立燃烧记录，不因为在发电炉物品栏放了煤就持续免费产电。

## 92.4 热源、卫生与敌人联动

煤和木材燃烧产生热量与烟。营火、烧砖窑、熔炉和发电炉提供局部热源，帮助寒冷环境保暖，但密闭无排烟空间会积累烟雾与不适；需要有通风条件或室外放置。燃烧噪声、工业机械噪声和夜间火光分别产生原有声音/光源事件；煤尘、烟污可能使衣物变脏、增加清洗需求。雨天露天木材湿润会降低燃烧效率，干燥燃料可存入有屋顶仓库。雨不能直接创造或消除煤和矿石。

## 92.5 制作与供电闭环

煤矿 → 煤燃料 → 发电炉 → 电网 → 中继器 → 工作灯、维修台、哨塔。铁矿 → 铁锭 → 铁制斧镐/工具/护板/塔基。铜矿 → 铜锭 → 接线组件 → 中继器/太阳能板配件。原木 → 木板 → 瞭望塔/矿道支柱/家具；原木 → 柴薪/木炭 → 取暖或发电。石灰石与砂石 → 地基/墙体，改善据点耐久。获得稳定产能后仍必须补充燃料、维护设备、修复电网并外出寻找稀缺材料。

# 95. 采集物流、据点布局、NPC与任务

## 95.1 据点生产区域

玩家可以将住宅车库或工业厂房改造成五个功能区域：原料堆放区、木工与柴薪加工区、矿石分拣及熔炉区、金属维修与制造区、发电与电网区。它们共用房屋/家具放置系统与防火、遮雨、碰撞规则，不能把高温熔炉直接放在木床上无条件运行。道路或院内需要预留车辆卸货动线。

## 95.2 资源物流与生产链

玩家可手持或背负小型物料，用车辆货箱/拖车运输大宗矿石和原木。资源进入仓库时被移动至唯一库存容器；工作台可在允许距离内读取已授权原料箱并从实际物品实例扣除。建议矿石箱、柴薪架、原木堆各有不同的网格或批量容器限制，避免用一格手提箱存放整片森林。

木材/煤矿提供可持续燃料路线，铁和铜矿提供产业路线：**木工支柱与墙体 → 矿洞开发 → 冶炼铁锭 → 升级镐斧及支架 → 铜导线和发电装置 → 据点照明/自动哨塔**。每条生产线都存在工具、材料、耗时与维修成本。

## 95.3 NPC轻量协助

NPC依旧是少量功能角色，不组建无限采矿队。可以安排NPC在据点岗位执行轻量辅助：木工NPC加快一次加工工序、机械师维护一台动力工具、商人提供矿物交易、守卫在矿坑入口或据点承担有限防守。NPC的辅助必须消费真实原料、工具耐久或报酬；玩家不在附近时按限速汇总结算，不会无限自动生成矿石、煤炭和木材。

## 95.4 矿业和林业委托

| 任务类型 | 具体目标 | 奖励例子 | 防重复机制 |
|---|---|---|---|
| 修复矿坑 | 清除堵住旧矿口的塌方、安装两根支柱 | 镐头、工具图纸、少量金属 | 通过矿口事件ID结算一次 |
| 煤炭补给 | 交付限定数量的煤炭 | 燃料、代币、发电零件 | 交付直接扣除库存 |
| 铁材采集 | 交付铁矿或铁锭 | 金属台配件、钢材线索 | 不要求固定矿点重新刷矿 |
| 修复伐木场 | 重建锯木台、清理附近丧尸 | 木工材料与工作台图纸 | 修复状态持久保存 |
| 林地恢复 | 按指定范围种植若干树苗并存活数日 | 种子、林业工具 | 按树苗唯一ID与成长时间判断 |
| 运输合同 | 用货车运一定重量的木材/矿石 | 车件、燃油或物资奖励 | 车辆货物ID和任务交付绑定 |
| 异常矿调查 | 在污染矿脉获取唯一标记的样本 | 神秘学进度或研究设备 | 独立任务样本实例，不重置原矿 |

采集任务奖励经验也走真实完成事件，不得同一个矿点“交付一次、退回矿石、再交付一次”循环刷分。
