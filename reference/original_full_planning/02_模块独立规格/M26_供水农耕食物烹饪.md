# M26｜供水、农业、烹饪与食物保存——独立可执行设计书

## 1. 玩家体验与系统边界

雨水收集、净化、水污染、种植季节、食谱、冷藏/腐败。本模块不得绕过物品所有权、世界层身份、世界时钟和全局事件幂等机制。

## 3. 模块专属规则、数值逻辑与边界

### 食品与水循环
水源是可收集量+水质标签，雨水洁净与屋顶污染另算，烧水与过滤按工序改变饮用资格；种植作物需温度、雨量、土壤含水、日照以及病害。食物卡路里与饱腹感独立；冰箱只有当前电网有供电时才降低腐败速率，断电后按绝对世界时间补算腐败。

# 6. 食物、卡路里、饱腹感与体型变化

## 6.1 两项食物属性

每种食物具有两个核心属性：

  属性              作用
  ----------------- ----------------------------
  卡路里 Calories   提供能量，参与长期热量收支
  饱腹感 Satiety    降低角色饥饿值

两者独立计算。

卡路里与饱腹感是独立属性：高能量食物可以拥有较低饱腹感，饱腹感较高的食物也可以提供较少能量。

重量、占用格子、保质期和变质状态作为物品属性管理；营养系统使用卡路里和饱腹感两项核心数据。

## 6.2 食物示例

  食物           卡路里    饱腹感
  ------------ ---------- --------
  巧克力        250 kcal     8
  面包          220 kcal     18
  午餐肉罐头    350 kcal     25
  豆类罐头      420 kcal     32
  坚果          550 kcal     12
  蔬菜汤        180 kcal     30
  肉类炖菜      450 kcal     38

以上为游戏平衡示例值，用于区分食物定位和玩法效果。

## 6.3 饱腹感计算

饥饿值范围0--100，越高越饿。

`新饥饿值 = max(0, 原饥饿值 - 食物饱腹感)`

饱腹感用于降低饥饿值；力量、敏捷和体力由技能、体型和生存状态联动计算。

## 6.4 卡路里收支

`每日热量收支 = 摄入卡路里 - 基础消耗 - 活动额外消耗`

基础消耗可先设置为每日1800--2000 kcal，再根据游戏时间流速调整。

额外消耗来自：

-   长时间步行。
-   疾跑。
-   近战战斗。
-   搬运重物。
-   制作、维修和高强度劳动。

卡路里摄入和消耗按世界时间统一累计，菜单打开、场景切换和存档读取沿用同一结算时间戳。

## 6.5 短期能量状态

卡路里还影响短期身体能量表现。建议根据近期热量缺口计算隐藏能量状态：

  能量状态   效果
  ---------- ----------------------------------
  充足       正常最大体力和恢复
  轻度不足   体力恢复速度降低5%
  中度不足   最大体力降低10%，恢复速度降低10%
  严重不足   最大体力降低20%，恢复速度降低25%

短期能量状态与饥饿值分别计算，玩家在饱腹状态下仍可能存在长期热量摄入不足。

## 6.6 长期体型变化

长期净热量盈余导致体型向肥胖方向变化；长期净热量缺口导致体型向瘦弱方向变化。

初始游戏参数：

-   每累计2500 kcal净盈余，体型修正值增加1。
-   每累计2500 kcal净缺口，体型修正值减少1。
-   体型修正范围为-25至+25。
-   接近热量平衡时体型基本保持稳定。

该2500 kcal是游戏调参值，应结合游戏内一天的实际时长和活动消耗进行测试。

## 6.7 体型修正与技能等级

隐藏参数：`BodyConditionModifier`，范围-25至+25。

   修正值  体型        力量修正   敏捷修正
  -------- ---------- ---------- ----------
    -25    极度瘦弱      -25        +25
    -20    严重瘦弱      -20        +20
    -15    明显偏瘦      -15        +15
    -10    偏瘦          -10        +10
     -5    轻微偏瘦       -5         +5
     0     正常           0          0
     +5    轻微壮实       +5         -5
    +10    偏胖          +10        -10
    +15    明显肥胖      +15        -15
    +20    严重肥胖      +20        -20
    +25    极度肥胖      +25        -25

中间数值按照线性或分段曲线逐级计算。

有效技能等级：

`有效力量等级 = 基础力量等级 + BodyConditionModifier`

`有效敏捷等级 = 基础敏捷等级 - BodyConditionModifier`

基础力量、基础敏捷范围0--25；有效等级允许为负数，理论范围-25至50。

示例：

-   基础力量10、基础敏捷10、体型修正+15：有效力量25、有效敏捷-5。
-   基础力量10、基础敏捷10、体型修正-20：有效力量-10、有效敏捷30。

体型修正作用于力量和敏捷有效等级；技能经验和基础等级独立保存。

## 6.8 有效力量与敏捷对实际玩法的影响

最大负重初始公式：

`最大负重 = 20 + 0.4 × 有效力量等级（kg）`

示例：

   有效力量   最大负重
  ---------- ----------
     -25        10kg
      0         20kg
      10        24kg
      25        30kg
      50        40kg

近战体力消耗：

`近战消耗倍率 = clamp(1 - 0.006 × 有效力量等级, 0.70, 1.20)`

移动速度：

`移动速度倍率 = clamp(1 + 0.003 × 有效敏捷等级, 0.85, 1.15)`

疾跑速度：

`疾跑速度倍率 = clamp(1 + 0.004 × 有效敏捷等级, 0.85, 1.20)`

疾跑体力消耗：

`疾跑消耗倍率 = clamp(1 - 0.004 × 有效敏捷等级, 0.75, 1.20)`

这些公式为第一轮平衡参数。后续应根据角色动画、地图尺度和战斗节奏调整。

## 6.9 体型视觉表现

体型变化通过模型形变或预设档位体现，并按体型区间更新角色外观。

建议制作5个视觉档位：

1.  极瘦。
2.  偏瘦。
3.  正常。
4.  偏胖。
5.  肥胖。

通过角色身体网格的形变、预制模型切换或 Blend Shape
实现。头部、手脚和装备穿戴需要避免明显穿模。

体型修正通过有效力量改变最大负重；背包本身决定网格空间容量。

# 43. 完整动态天气、气候与生存影响

## 43.1 系统目标与约束

天气不是单纯的屏幕滤镜，而是由统一世界时钟驱动、能够改变探索路线、玩家行动、敌人感知、物品状态与据点供电的系统。天气系统与昼夜系统相互独立；同一天可从清晨多云转为中午晴朗、下午雨和夜晚雾。所有天气状态都可通过室外观察、声音与简化天气预报辨认。数值均为游戏平衡初稿，不直接对应真实气象测量。

- **全局时间**：主世界与颠倒世界共用时间戳；太阳位置、季节和基础天气依据时间推进。
- **区域天气**：每个区块引用所在气候区域，邻区过渡平滑，室内通过屋顶与门窗遮蔽天气影响。
- **共享与覆层**：主世界天气保存为基础数据；颠倒世界使用独立异常天空/雾/降尘覆层，但不另行复制建筑、家具、作物或电网状态。
- **天气前兆**：下雨前云量与风速上升，雷暴前有远处雷光，浓雾前可见度逐步缩短；避免瞬间天气切换。
- **性能分级**：近景完整粒子/地面积水；中景降级视觉；远景仅气象参数及音频，不对离屏雨滴做物理计算。

## 43.2 天气类型与预期体验

| 天气 | 视觉和声音 | 玩家影响 | 丧尸影响 | 电力影响 |
|---|---|---|---|---|
| 晴朗 | 高日照、清晰视野 | 外出搜刮较稳定；高温时口渴增加 | 视觉发现距离正常 | 太阳能产出高 |
| 多云 | 光照变软 | 不明显；部分区域更适合潜行 | 视距轻微缩短 | 太阳能中等 |
| 小雨 | 屋檐雨滴、湿地面 | 逐渐湿润、轻微移动变化 | 雨声掩盖部分脚步 | 太阳能较低 |
| 大雨 | 强降雨、积水、水声 | 长期暴露增加湿透/寒冷；泥地移动减速 | 视觉距离降低、听觉干扰增加 | 太阳能明显降低 |
| 雷暴 | 闪电、雷鸣、强风 | 室外设备风险、户外行动受阻 | 雷声形成大范围背景噪声；闪电短暂照亮视野 | 发电波动，暴露线路可能故障 |
| 雾 | 局部体积雾、能见度下降 | 侦察和导航难度提高 | 视觉判定缩短，听觉照常 | 有阳光时也会抑制部分太阳能 |
| 大风 | 树木摆动、风声 | 移动和瞄准轻微受影响 | 声音传播方向有偏置，视觉不直接增强 | 不新增风力发电设备 |
| 雪/寒潮（季节性） | 落雪、结霜、积雪 | 低温、湿冷、室外移动惩罚 | 特定丧尸移速随地形变化 | 低日照和覆盖影响太阳能板 |

## 43.3 天气状态与生成算法

建议 `WeatherState` 至少包含：`weather_id`、`climate_region_id`、`cloud_coverage`、`precipitation_rate`、`wind_vector`、`air_temperature`、`ambient_light`、`visibility_m`、`ground_wetness`、`start_world_minute`、`target_duration_min`、`transition_progress`、`seed`。采用确定性种子+季节概率矩阵生成天气段，并在天气段切换时插值，不使用每帧随机概率。

初步天气时长：小规模局部天气20—90个游戏分钟；持续阴雨1—4个游戏小时；强雷暴10—40个游戏分钟。大地图相邻区域天气可有延迟差异，但必须避免在边界瞬间从暴雨切为晴天。天气强制调试应覆盖天气过渡、跨区域、读档和切换世界。

## 43.4 玩家体温、湿度和装备联动

保留原有七项核心状态，不新设永久“体温条”。通过短期隐藏变量 `wetness 0—100`、`thermal_stress -100—100` 生成状态效果“湿润/湿透/寒冷/过热/低体温风险”。玩家装备 `water_resistance`、`insulation`、`breathability` 和遮蔽系数；屋顶、完整密闭车辆、雨棚可以阻挡大部分降水，打开窗户或破损屋顶降低遮蔽值。

- **湿润**：持续室外降雨、过河、站在深积水中累积；避雨、炉火附近、换干衣和室内休息降低。
- **寒冷**：受温度、风寒、湿润和服装影响；持续低温增加体力消耗与疲劳积累、降低恢复效率。
- **过热**：受高气温、太阳直射、厚重护甲和剧烈行动影响；口渴增长和疲劳增长略增。
- **雨天战斗**：潮湿泥地使转向/加速稍慢；湿装备增加少量负重；不采用普遍随机滑倒以免削弱操作可控性。
- **受伤与感染**：恶劣天气只间接降低伤口恢复效率；丧尸感染仍由攻击与治疗逻辑决定，不能仅因雨淋而凭空感染。

初始建议：雨中每游戏分钟湿润+2（防雨装备乘0.25—0.8），遮蔽处每分钟-1.5，干燥室内每分钟-3；当 `wetness>=70` 且环境寒冷时触发寒冷状态。恶劣状态对移动/恢复的惩罚宜先控制在5%—15%。

上述`wetness`继续作为角色级体验参考，但不再是各系统直接写入的单一存储字段；其数值由皮肤与已穿着衣物湿度聚合计算。单件衣物具有独立的`wetness`、材质与晾晒干燥速率；以上角色级干燥速度不能直接套用至洗衣机内/晾衣架上的所有服装实例，详见第57、59、61章。

## 43.5 敌人的感知、寻路和行为

**普通丧尸**：视觉有效距离乘 `visibility_factor`（晴1.00、小雨0.90、大雨0.70、浓雾0.45），且仍需视野角度和遮挡；听觉使用 `signal_noise_ratio` 而不是直接把所有声音距离固定缩小，雨和风为持续背景噪声，枪声仍能穿透。湿泥、积雪等地表类型修正移动速度，丧尸在视觉失联后仍前往最后发现位置执行搜索。个别嗅觉丧尸可参考风向进行概率追踪。

**克苏鲁**：保留原作设计中视觉/光源/异常感知分离的规则。雾和雨只作用于视觉与可见光，不能普遍削弱领域感知；雷闪可能短暂暴露玩家轮廓或扰动光源判定。高级克苏鲁识别玩家据点探照灯和哨塔灯光时依然遵循第27章仇恨与追踪上限。无普通听觉的克苏鲁不会因雷声触发声音追踪。

**天气与刷新**：雨雾使部分常规丧尸更容易接近玩家，但刷新数量不因天气任意翻倍；异常区域的浓雾可加强预兆呈现。天气改变的是应对条件，不替代既有的区域污染与异常关注度。

## 43.6 天气与资源和据点

- 太阳能受到云量、时间、板面遮挡与积雪影响；电池负责夜间储能。
- 降雨可填充雨水收集器，但收集的水不直接视为安全饮水，仍走过滤或烧水逻辑。
- 户外木材可能受潮，燃烧式发电炉使用干燥燃料效率更稳定；已存放在密闭储物箱的燃料不受室外雨影响。
- 暴雨和雷暴可使未保护的中继器、电缆接头、电力设备耐久降低，前期以低概率的可修复故障呈现。
- 据点照明、门窗、屋顶和防御设施决定是否能在恶劣天气中安全休息。

## 43.7 天气信息与测试

玩家可通过窗外变化、地图天气提示、收音机简报或据点简易预报牌获知当前天气，预测只提供趋势，不必精确到分钟。测试：天气跨区连续；雨停后地面逐渐变干；室内有遮蔽时不积累湿润；雾中丧尸视觉下降但听枪声仍响应；深夜太阳能为零且储电能够续供；世界切换后同一时间戳正确恢复天气。

# 60. 个人清洁、血污、泥污与气味

## 60.1 污染分层

每件衣物和角色皮肤至少记录**三种独立污染**：

1. `blood`：战斗中的血液、尸体搬运与贴近喷溅。
2. `dirt`：泥地奔跑、搜查废屋、修车、拆墙、挖掘和野外作业。
3. `sweat` / `odor`：热环境和长时间高体力消耗；气味只作为轻量级近距离线索，不形成全地图持续追踪。

衣物 `wetness` 是水分，不等于脏污；烘干只降低湿度，不会洗去血和泥。反过来洗衣后污渍减少，但衣物会更湿。

## 60.2 影响范围

| 污染 | 轻度 | 中度 | 重度 |
|---|---|---|---|
| 血污 | 可见贴图污渍 | 手部/开放伤口接触时普通感染风险上升 | 触碰伤口、拆除绷带等行为更应清洁 |
| 泥污 | 外观变化 | 洗衣耗水和时间增加 | 鞋靴动作音效变化；开放伤口护理条件变差 |
| 汗液/气味 | 逐步积累 | 不适与舒适睡眠轻微影响 | 潜行时少数嗅觉丧尸的近距离搜索权重上升 |
| 潮湿 | 触发“湿”提示 | 保暖下降、重量微增 | 湿冷风险上升，需干衣和更换 |

玩家仅仅穿着脏衣服不自动损失HP；只有脏污与**皮肤破口、局部伤势、医疗操作**等事件相交时，才对 `WoundInfection` 做明确风险修正，且保留第44章对丧尸感染的独立约束。

## 60.3 洗澡和擦洗动作

交互对象：水龙头、淋浴器、浴缸、室外水桶、河流/水井边（简易清洁）、储水桶、湿毛巾和清洁用品。

| 方式 | 需要条件 | 初始耗水 | 时间（游戏时间） | 效果 |
|---|---|---:|---:|---|
| 擦手/擦脸 | 少量水或湿巾 | 0.5—1L | 10—30秒 | 清手部与脸部血污，适合处理伤口前 |
| 局部擦洗 | 水、毛巾，可有肥皂 | 1—3L | 1—3分钟 | 清指定身体区域 |
| 冷水冲洗 | 有水源和淋浴/桶 | 8—15L | 3—6分钟 | 清除多数泥污与血污，低温环境可增加冷压力 |
| 热水洗澡 | 水源、热水供应 | 10—20L | 4—8分钟 | 较好清洁，短暂改善舒适度，不能治疗疾病 |
| 野外快速清洁 | 河流/瓶装水/湿巾 | 1—5L | 1—4分钟 | 有效但效率较低，污水接触伤口可能有风险 |

以上耗水是**游戏抽象值**，可按难度缩放，不作现实水资源标准。洗澡动作会推进世界时间、消耗水与肥皂，可以被危险环境打断；完成时只结算实际清洁部分，不得因反复开关交互重复获得效果。

清洗身体前，系统提示玩家：有开放伤口时最好先使用干净水和合适护理；腐败/受污染水可能增加**普通局部伤口感染**风险。清洁不是消毒或抗感染治疗。

## 60.4 手部卫生重点

为减少操作负担，单独跟踪 `hands_dirty` 而非整套精细微生物模型。用脏手吃食物、准备生肉或给开放伤口换绷带时，根据污染等级产生小幅附加风险；洗手一次清除主要风险。玩家无需每次打开柜子都洗手。

## 60.5 环境与丧尸嗅觉交互

普通丧尸默认仍使用视觉与听觉。只有第9章配置了 `scent_detection=true` 的少数特殊丧尸，才会在距离较近、风向合理且有血污或气味线索时提高搜索概率。雨水会削弱地面残留气味，强风会偏移线索，但不允许凭一个全局嗅觉值使所有敌人凭空锁定玩家。克苏鲁默认不因血污或洗澡而修改异常关注度。

## 60.6 睡眠与SAN界限

干净床铺、干衣和合理室温可以提升**睡眠质量**，具体表现为疲劳恢复效率+3%—8%；脏湿床铺可能相反。卫生不是精神病模拟：清洁度本身不降低SAN，SAN由原有异常机制控制。

# 61. 洗衣、晾晒、烘干、供水及电力联动

## 61.1 衣物维护完整闭环

```text
衣服产生血污/泥污/湿润
 → 玩家卸下/选择清洗对象
 → 选择手洗/洗衣机
 → 校验水、清洁剂、设备状态及电力
 → 扣除资源并启动计时任务
 → 污渍逐步减少，衣物含水量上升
 → 晾晒/风干/烘干
 → 按当前含水量重新计算保暖和重量
 → 折叠/入柜/装备
```

### 手洗

- 水源：水池、浴缸、井、水桶、雨水收集器、河边；清洗污渍可使用非饮用级水，但洗伤口和身体卫生用水要求较高。
- 工具：肥皂、洗衣粉、刷子；清洁剂提高去污率，缺少时可用更多水和时间完成基本清洁。
- 时长与耗水：单件2—7游戏分钟、2—6L；重型大衣增加消耗。
- 手洗后 `wetness` 通常上升至75—100；可进行“拧干”动作使其降低约20—35点，但不等于已干燥。

### 洗衣机

- 洗衣机是第51章电网的**用电终端**，不是新种类的发电/中继节点；需要既有电网可用电、设备完好及供水容器或建筑的可用水源。
- 批量处理5—8件中小型衣物，按重量限制超载；单次消耗15—30L水、清洁剂与0.4—0.8kWh电（初始建议）；标准洗涤程序20—40游戏分钟。
- 运行中停电：暂停并记录剩余阶段，恢复电力后继续；不会重复扣整桶水/整份洗衣粉。
- 不放入不能机洗的重型护甲板、电池、武器、重要异常材料。设备UI显示禁止物品理由。

### 烘干机

- 独立**电力消费者**，每次约0.8—1.5kWh、20—40游戏分钟；仅降低湿度，不去除血污、泥土或修复耐久。
- 发热、噪音按设备配置转化为室内温度与声音事件，噪声可能吸引附近普通丧尸。
- 防止利用开关反复触发烘干完成事件；物品湿度按工作时长连续结算。

### 晾衣架/晾衣绳

- 不耗电；玩家可制作并安放，离开区块后依旧按游戏时间与天气推算。
- 室外晴朗、有风：相对快；雨天户外可能重新淋湿；室内靠近安全热源快，但封闭高湿空间较慢。
- 床、箱子中湿衣干得更慢；防水收纳袋隔绝雨水但不凭空烘干。

## 61.2 统一干燥模型

每个实例使用 `wetness 0—100`，示意：

```text
wetness_next = clamp(
    wetness_old + rain_gain + sweat_transfer + wash_gain - dry_rate × delta_game_minutes,
    0, 100
)
```

`dry_rate`由材质、室内外、风、温度、相对湿度、是否贴身穿着、是否靠近热源决定。干燥器覆盖自然干燥速率，但绝不影响污渍值。示例完全湿透衣物的自然干燥时间：晴天室外约1—3游戏小时、室内常温约3—6小时、阴冷室内更久；具体随天气与材质调整。

## 61.3 与供水系统整合

玩家据点有一个轻量级 `WaterContainerState`，统一记录：容器ID、存水L、容量、卫生水质、当前使用保留量。洗衣用水与饮用/医疗用水分配在UI中可视，避免在旱季将最后一桶饮用水洗掉。以第43章雨水收集器作为主要新增水源，洗涤可利用过滤前雨水，但不得将洗后的水自动回收到饮用库存。玩家可以在交互时选择“洗衣优先使用非饮用水”。

## 61.4 与电网和技能整合

- 电力等级决定设备安装、简单线路诊断、能耗优化；机械决定滚筒/电机修理；制作决定晾衣架、洗衣盆和修补材料配方。
- 电网负载不足按第51章优先级断电；建议洗衣机与烘干机默认低于医疗冷藏柜、关键照明及哨塔。
- **仅使用原版规划的发电端、储能和中继器网络**，洗衣机、烘干机、热水器、室内取暖器和浴室照明属于负载终端；不追加复杂电路工具或电线类别。
- 热水洗澡：燃烧加热或已有电热水器提供热水，用房屋设施UI展示可用热水，不需要真实管线网模拟。燃烧式加热装置按第51章的燃料与安全规则。

## 61.5 家居场景布置

房屋类型按第47章生成合理设备：住宅浴室有浴缸/淋浴、卫生间水池；洗衣间放洗衣机、烘干机、洗衣液架；公寓公共洗衣间有共享设备；汽车旅馆可有洗衣区；医院设清洁室；废弃农庄有水桶/晾衣绳。高端设备只在符合房屋用途的地点出现，不随机塞入每个厨房。

# 91. 木材、矿石与工业原料加工链

## 91.1 工序结构

原料不直接变成高级装备，分为：**采集 → 分拣/运输 → 初加工 → 炉窑/冶炼 → 部件加工 → 成品组装**。玩家可以把搜刮所得零件直接用于制作，但若长期建设大据点，就需要建立稳定矿木材料供应。初级加工提供足够早期可用性，中高级工业通过更可靠的产率、批量生产和高阶材料体现发展。

## 91.2 工作设施

| 设施 | 核心用途 | 需要的基础资源 | 能源关系 |
|---|---|---|---|
| 手工处理区 | 分拣石料、手锯切木、制作柴薪 | 工具与干燥地面 | 不需供电 |
| 木工工作台 | 木板、木箱、门板、木支柱 | 原木、锯、钉等 | 手工操作 |
| 木炭窑 | 木柴转换为木炭 | 土/石/黏土、木料 | 直接燃烧原料，不自动发电 |
| 简易熔炉 | 铁矿初步熔炼、简单铜加工 | 黏土砖、石料、燃料 | 独立热源，不需电力接网 |
| 工业熔炉 | 批量矿石加工和较复杂合金 | 金属框架、耐火砖等 | 可燃料燃烧，自动化控制部分耗电 |
| 金属工作台 | 铁工具、支架、钢材部件 | 铁锭、紧固件、工具 | 纯手工版本不需电，机器版需供电 |
| 机修台 | 车件、动力钻具、链锯维修 | 金属零件、工具 | 对应机器型号可能需电 |
| 资源仓储架 | 按矿石、燃料、金属和木板分类 | 木板或金属架 | 不需供电 |

生活炉灶负责烹饪，普通熔炉负责冶炼，燃烧式**发电炉**负责热能转换成电能，三者的输入和输出不能混用为“火一烧就免费发电”。资源可以共享燃料物品，但设备工艺独立。

## 91.3 基础建材供应链

- 石块 → 碎石/石料 → 基础地基、路面、围墙、石质防御结构。
- 砂 + 黏土 → 砖坯/烧制砖 → 炉体、壁炉、墙体与耐火结构。
- 石灰石 + 砂 + 水 → 游戏化砂浆材料 → 高级墙基、支柱与部分混凝土组件。
- 原木 → 木板 + 副产木屑 → 房屋墙板、地板、木箱、楼梯和哨塔平台。
- 木材 → 木柴 → 营火、烹饪、取暖；木材 → 木炭 → 熔炉或发电炉燃料。
- 铁矿 → 铁锭 → 铁钉、镐头、斧头、门框、护板、围墙骨架。
- 铁锭 + 碳质材料 → 钢材 → 高等级工具、机械零件与自动哨塔结构。
- 铜矿 → 铜锭 → 铜导线/接头 → 中继器、电力设备、修车电路。

## 91.4 原材料加工中的空间经济

加工后的成品根据真实设计占用网格、重量和可堆叠数，运输价值受到车斗载重、道路和天气影响。原木可以通过皮卡装运；矿石通常更重，鼓励玩家在矿区设临时中转箱而不是一趟背回整座矿山。工作台可以从附近已授权仓储容器读取材料，但必须从一个明确库存逐件扣除，不能同时计入车厢和据点仓库。
