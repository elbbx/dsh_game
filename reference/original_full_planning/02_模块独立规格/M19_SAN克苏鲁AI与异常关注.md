## 3. 模块专属规则、数值逻辑与边界

### 追踪规则
SAN负责角色即时精神状态；异常关注度决定高阶遭遇概率。T1视线造成SAN压力但不要求攻击；T3/T4按连续可见时间提高仇恨并递增增长率，失去视线后速度降低但仍追踪最后位置并搜索；达到搜索超时、最大领地距离或冷却后脱战。强光直接照射某些T4会建立仇恨，普通声音不自动替代克苏鲁特殊感知。

# 10. 克苏鲁生物与特殊 AI

## 10.1 核心规则

克苏鲁系统与丧尸系统独立设计。

-   感知输入由视觉、光源和特殊异常感知构成，普通声音事件由丧尸听觉系统处理。
-   敌对型克苏鲁按照可感知目标、距离和可达性选择玩家、丧尸及其他有效目标。
-   低级观察型个体以观察、跟随和SAN压力为主要行为。
-   低级个体进入玩家视野并满足可见条件时造成SAN损失。
-   大部分高级个体拥有光源感知。
-   夜间直接照射到具备光源感知能力的克苏鲁时，可能触发仇恨。
-   克苏鲁追踪由感知范围、最后位置记忆、搜索时间和区域边界共同控制。

"无差别攻击"指敌对型克苏鲁按照感知、距离、可达性和攻击规则选择有效目标，目标阵营不会改变其敌对倾向。

## 10.2 克苏鲁感知

  敌人           视觉或特殊感知   听觉   光源感知
  -------------- ---------------- ------ ------------
  T1观察者       视觉             无     通常无
  T2异常潜伏体   特殊感知         无     通常无
  T3狩猎者       视觉或特殊感知   无     部分拥有
  T4高级猎食者   特殊感知         无     大部分拥有
  T5领域守护者   领域感知         无     独立规则

潜行技能主要影响常规视觉与听觉敌人的发现效率；克苏鲁根据自身配置的特殊感知能力识别目标。

## 10.3 光源感知系统

光源类型：

  光源         初始感知强度   说明
  ------------ -------------- --------------------
  普通手电筒   高             直接照射可触发
  强光手电筒   很高           感知距离更远
  信号棒       高             可作为诱饵
  车辆前灯     很高           容易被远处个体发现
  普通台灯     低             取决于距离和照度
  营火         中             固定位置光源
  弱光照明     极低           低概率触发

光源判断需要综合：

-   光源强度。
-   光照距离。
-   光束是否直接照射目标。
-   目标是否处于可见范围。
-   墙壁和障碍物遮挡。
-   当前环境亮度。

光源感知综合光源强度、照射方向、距离、遮挡和目标可见性进行判定。

## 10.4 有限光源追踪

**光源追踪的统一规则：**
> 本节定义光源仇恨的建立条件；仇恨持续、视线丢失、掩体搜索、移动速度和衰减统一使用第27节参数。

建议使用以下初始测试参数：

  参数                     初始值
  ---------------------- ----------
  光源确认时间            0.5--1秒
  光源锁定时间             3--5秒
  失去光源后的搜索时间    5--10秒
  单次追击时间上限        15--20秒
  最大追击距离            25--40米
  仇恨解除冷却            20--30秒

行为流程：

1.  在区域内待机或游荡。
2.  夜间直接感知到玩家照射过来的有效光源。
3.  记录光源最后出现的位置。
4.  朝该位置接近。
5.  如果进入攻击范围并满足攻击条件，则发动攻击。
6.  如果光源消失，前往最后位置。
7.  在有限范围内搜索。
8.  超过时间或距离上限后解除仇恨。
9.  返回原本活动区域或进入短暂冷却。

必须满足：

-   光源感知通过遮挡检测确定有效照射路径。
-   玩家关闭光源后，敌人依据最后光源位置和搜索范围继续行动。
-   追击通过最大距离、目标记忆时长和搜索时间控制。
-   追击结束后允许玩家脱离。

## 10.5 光源诱导玩法

玩家可以利用信号棒或其他光源改变克苏鲁的移动方向。

例如：

1.  玩家手电筒照射高级克苏鲁。
2.  克苏鲁锁定光源。
3.  玩家将信号棒扔向其他方向。
4.  玩家关闭手电筒。
5.  克苏鲁前往最后感知到的光源位置或被有效诱饵吸引。
6.  玩家从另一条路线撤离。

诱饵响应由各生物的感知配置决定，配置表明确可响应的光源类型。

## 10.6 五级克苏鲁分类

  等级   类型              是否攻击玩家           核心机制
  ------ ----------------- ---------------------- ------------------------------
  T1     观察者            否                     进入视野造成SAN损失
  T2     异常潜伏体        否或以非伤害干扰为主   跟随、隐藏、制造异常
  T3     狩猎者            是                     特殊感知、有限追击
  T4     高级猎食者        是                     大部分拥有夜间光源追踪
  T5     领域守护者/Boss   是                     区域控制、特殊攻击和独立机制

### T1：观察者

-   以观察、跟随和SAN压力为主要行为。
-   感知由视野和异常感知条件驱动。
-   在满足视野和遮挡条件时造成SAN损失。
-   玩家靠近时可能消失或改变位置。
-   常见于居民区边缘、森林和废弃建筑。

### T2：异常潜伏体

-   以潜伏、环境干扰和精神影响为主要行为，部分变体具有轻度物理攻击。
-   隐藏在建筑、地下室和阴暗区域。
-   玩家接近时可能改变位置。
-   制造幻觉和被观察感。
-   接触时间越长，SAN压力越明显。

### T3：狩猎者

-   具备主动攻击能力。
-   通过视觉、特殊感知和区域异常感知建立目标。
-   通过视觉、区域感知或特殊感知寻找目标。
-   追击有范围限制。
-   可以攻击玩家和丧尸。
-   部分个体拥有光源感知。

### T4：高级猎食者

-   大部分拥有光源感知。
-   夜间直接被照射时可能产生仇恨。
-   具备特殊攻击和较高生命值。
-   可以破坏部分建筑结构。
-   具有可研究的弱点。

### T5：领域守护者/Boss

-   固定在特殊地点。
-   T5通过固定地点、调查进度和特殊事件触发。
-   拥有独立领域和阶段机制。
-   可以控制异常光照、制造精神冲击、改变空间或召唤低级个体。
-   需要调查、特殊道具、弱点机制或仪式才能有效应对。

## 10.7 T1视野触发SAN损失

触发条件：

1.  T1进入玩家摄像机视野。
2.  双方没有墙壁等遮挡。
3.  距离处于有效范围。
4.  持续可见达到最低触发时间。

建议初始测试值：

  情况                          SAN损失
  -------------------- --------------------------
  远距离、短暂看见            每秒0.1--0.2
  中距离持续观察              每秒0.3--0.5
  近距离观察                  每秒0.6--1.0
  多个观察者同时出现    额外压力，但设置叠加上限

离开视野后停止持续损失。短暂离开视野再重新看见时，应设置触发冷却，防止画面边缘反复触发。

T1采用轻量级环境实体和观察行为状态机。

# 11. SAN、异常关注度与遭遇阶段

## 11.1 两个数值必须分开

SAN越低，表示玩家精神状态越差。玩家看见T1后SAN下降。

高级遭遇阶段由异常关注度和区域污染决定，SAN用于描述玩家精神稳定程度。

建议新增一个不显示在HUD上的隐藏参数：

**异常关注度 Anomaly Attention，范围0--100。**

它代表异常世界对玩家的关注程度，不是角色生存状态。

## 11.2 异常关注度增加来源

  行为                 初始增加值
  ---------------- ------------------
  第一次发现T1             +5
  持续观察T1        分段增加，带冷却
  第一次接触T2             +8
  进入低污染区域        缓慢增加
  进入中污染区域        中速增加
  进入高污染区域        快速增加
  获取异常遗物           +5至15
  阅读禁忌资料           +5至10
  完成异常调查          +10至20

异常关注度事件使用唯一事件ID、单次结算标记、冷却时间和每日增长上限。

## 11.3 遭遇阶段

   关注度   遭遇阶段   可出现敌人
  --------- ---------- ----------------------------
    0--19   阶段0      T1、少量环境异常
   20--39   阶段1      T1增加、少量T2
   40--59   阶段2      T2增加、少量T3
   60--79   阶段3      T3增加、T4开始出现
   80--100  阶段4      T4高级猎食者、特殊领域事件

## 11.4 阶段保留与当前强度

建议采用两个概念：

-   最高解锁阶段：永久记录玩家曾达到的最高异常遭遇阶段。
-   当前异常关注度：决定近期遭遇强度和刷新概率。

玩家离开污染区、休息或完成特定调查后，当前关注度可以缓慢下降；最高解锁阶段作为长期进度记录。

玩家恢复SAN后仍保留已解锁的遭遇阶段和内容进度。

# 27. 克苏鲁仇恨值与持续追踪系统

## 27.1 设计目标

克苏鲁追踪由发现、仇恨积累、直接追逐、最后位置记忆、搜索和衰减构成。

需要建立一套有记忆、有仇恨积累、有视线判断、有搜索过程的AI系统。

核心行为：

-   看见玩家时，仇恨持续增加。
-   连续看到玩家越久，仇恨增长速度越快。
-   仇恨越高，移动速度越快。
-   失去视线后，移动速度明显下降。
-   失去视线后进入最后位置追踪和搜索状态。
-   敌人会前往玩家最后出现的位置。
-   到达最后位置后，会在附近搜索。
-   如果长时间找不到玩家，仇恨才逐渐消退。
-   敌人通过视线射线和特殊感知数据更新目标位置。

## 27.2 仇恨值

每个具备追踪能力的克苏鲁实例保存独立仇恨值：

`Aggro = 0–100`

仇恨值只代表该敌人对当前玩家的追踪和攻击意愿，不等同于全局异常关注度。

   仇恨值   状态   行为
  --------- ------ ----------------------------------
    0--19   游荡   按原有路径活动
   20--39   警觉   朝最后发现位置靠近
   40--59   追踪   主动追逐，速度提高
   60--79   狩猎   追踪更积极，搜索范围扩大
   80--100  狂猎   最高追踪速度，攻击间隔可适度缩短

T1使用视野SAN机制；T2使用低强度目标记忆；T3及以上使用完整仇恨系统。

## 27.3 持续视线与递增仇恨

仇恨增长必须体现"连续看到玩家越久，增长速度越快"。

建议使用连续可见时间 `continuous_sight_time`。

初始公式：

``` text
sight_multiplier = min(1 + continuous_sight_time / 5, 3)

aggro_gain_rate = base_aggro_gain × sight_multiplier
```

初始建议：

-   `base_aggro_gain = 1.5` 点/秒。
-   连续可见5秒，增长速度达到基础速度的2倍。
-   连续可见10秒，增长速度达到基础速度的3倍。
-   增长速度最高不超过基础速度的3倍。
-   仇恨值最高100。

实际仇恨增长：

``` text
Aggro += aggro_gain_rate × delta
Aggro = clamp(Aggro, 0, 100)
```

连续可见时间只在敌人确实看见玩家时增加。一旦失去视线，连续可见计时清零；重新看见时从基础增长速度重新开始。

## 27.4 其他仇恨修正

除持续视觉外，可以增加少量仇恨事件：

  事件                                仇恨变化建议
  ---------------------- --------------------------------------
  近距离直接看到玩家                    额外增加
  强光直接照射                          额外增加
  玩家对敌人造成伤害                    +10至20
  玩家在近距离进入视野                增长倍率提高
  玩家成功躲入掩体        停止视觉仇恨增长，并进入失去视线流程

克苏鲁的目标输入由视觉、光源、特殊感知和直接受击事件构成；枪声、脚步声和爆炸声音由丧尸听觉系统响应。

## 27.5 视线检测

必须使用真实遮挡检测。

判断因素：

-   敌人感知点到玩家身体检测点之间是否存在阻挡。
-   墙壁、关闭的门、实心家具和地形是否遮挡。
-   玩家是否在敌人视野角度内。
-   玩家与敌人之间距离是否满足感知范围。
-   光照和特殊视觉能力是否影响识别。

建议使用多个视线采样点：

-   玩家头部。
-   玩家胸部。
-   玩家身体中心。

至少一个有效采样点无遮挡时，可以判定为部分可见。完全遮挡时判定为失去视线。

## 27.6 掩体机制

掩体是玩家摆脱追踪的重要手段。

可用掩体包括：

-   建筑墙体。
-   关闭的实心门。
-   大型家具。
-   车辆车体。
-   岩石。
-   地形高差。
-   厚重的工业设备。

掩体效果：

1.  阻断敌人的直接视线。
2.  停止连续可见时间累积。
3.  触发敌人的最后位置记忆。
4.  降低敌人的追踪速度。
5.  给玩家转移位置、关灯、绕路或撤离的机会。

掩体遮挡能力由材质、厚度、破坏状态和敌人感知类型决定。

## 27.7 失去视线后的追踪

敌人失去视线后，使用last_seen_position作为导航目标，并通过搜索状态寻找玩家。

必须保存：

-   `last_seen_position`：最后看见玩家的位置。
-   `last_seen_time`：最后看见玩家的时间。
-   `last_seen_direction`：最后观察到的移动方向。
-   `search_center`：搜索中心。
-   `search_radius`：搜索半径。
-   `search_timer`：搜索剩余时间。

行为流程：

1.  玩家进入掩体后，敌人失去视线。
2.  敌人记录最后发现位置。
3.  敌人降低移动速度。
4.  敌人向最后发现位置移动。
5.  到达该位置后，在附近进行搜索。
6.  搜索范围根据仇恨值和敌人类型变化。
7.  如果重新看见玩家，重新进入直接追踪。
8.  如果搜索超时，仇恨逐渐衰减并返回区域活动状态。

## 27.8 仇恨与移动速度关系

建议使用两个独立乘数：

1.  仇恨速度倍率。
2.  视线状态倍率。

仇恨速度倍率：

``` text
aggro_speed_multiplier = 0.75 + 0.5 × (Aggro / 100)
```

结果：

   仇恨值   速度倍率
  -------- ----------
     0        0.75
     25      0.875
     50       1.00
     75      1.125
    100       1.25

视线状态倍率：

  状态                      速度倍率
  ------------------------ ----------
  直接看见玩家                1.00
  失去视线，前往最后位置      0.65
  到达最后位置，搜索附近      0.40
  搜索结束，返回区域          0.55

最终移动速度：

``` text
final_speed =
    base_speed
    × aggro_speed_multiplier
    × visibility_state_multiplier
    × creature_speed_modifier
```

高仇恨敌人在失去视线后明显减速，并继续执行最后位置追踪和搜索。

## 27.9 仇恨衰减

仇恨在失去视线后按照保留时间、搜索阶段和衰减速率逐步变化。

建议：

  阶段           仇恨处理
  -------------- ------------------------------------
  刚失去视线     保留当前仇恨一段时间，维持追踪压力
  前往最后位置   缓慢衰减
  搜索阶段       缓慢衰减
  搜索超时       中速衰减
  返回区域       较快衰减

初始参数：

-   失去视线后保留高仇恨2秒。
-   最后位置追踪时间：8--15秒。
-   搜索时间：6--12秒。
-   搜索结束后仇恨每秒降低3--5点。
-   当仇恨低于20时，允许返回普通游荡状态。

仇恨记忆时间根据敌人类型配置；高级克苏鲁拥有更长记忆和更大搜索范围，并通过记忆时长与区域边界控制追踪。

## 27.10 追踪状态机

``` text
IDLE
  ↓ 发现玩家
VISUAL_ACQUIRE
  ↓ 确认目标
DIRECT_CHASE
  ↓ 失去视线
LAST_KNOWN_POSITION
  ↓ 到达最后位置
SEARCH
  ├── 重新看见玩家 → DIRECT_CHASE
  ├── 找到新的有效线索 → INVESTIGATE
  └── 搜索超时 → RETURN_TO_TERRITORY
                         ↓
                       IDLE
```

`INVESTIGATE`使用该敌人配置的特殊感知线索更新目标位置；普通声音事件由丧尸听觉系统处理。

## 27.11 光源与仇恨系统联动

光源是部分高级克苏鲁发现玩家和建立仇恨的特殊来源。

-   夜间直接照射具备光源感知的克苏鲁时，触发感知。
-   光源被发现后，敌人获得玩家的最后有效位置。
-   光源持续照射时，仇恨持续增长。
-   玩家关闭光源后，敌人根据最后光源位置和搜索范围继续行动。
-   敌人前往最后感知位置并进行搜索。
-   信号棒可以作为部分敌人的光源诱饵。
-   每种生物通过光源感知配置定义可识别的光源类型。

光源机制与普通视觉共享同一套仇恨系统，避免出现两个互相冲突的追踪系统。

# 28. 固定型、区域型与伏击型克苏鲁

## 28.1 敌人移动类型分类

克苏鲁除了T1--T5威胁等级，还应增加独立的移动类型标签。

威胁等级决定强度和能力；移动类型决定敌人的空间活动方式。

  移动类型     说明
  ------------ --------------------------------
  普通追踪型   可以离开出生点追逐玩家
  固定扎根型   固定在地面、墙体或天花板
  区域活动型   只能在指定领地范围内活动
  潜伏伏击型   休眠或伪装，满足条件后发动攻击

同一个敌人可以同时具有威胁等级和移动类型。例如T4固定扎根型、T3区域活动型。

## 28.2 固定扎根型 Rooted Creature

固定扎根型敌人的主体锚定在地面、墙体或天花板。

常见位置：

-   地面裂隙周围。
-   地下室。
-   建筑墙体。
-   天花板。
-   地下通道。
-   大型异常生物巢穴。

外观可以是触手团、肉质根系、附着在墙面的生物组织或大型生物器官。

### 核心机制

-   主体固定在一个锚点。
-   通过触手、孢子、投射物或区域效果攻击。
-   仇恨值影响攻击积极程度。
-   固定型敌人的仇恨值转换为攻击频率、触手速度和攻击范围。
-   固定型敌人的攻击范围由触手长度和区域判定控制。
-   玩家可以破坏触手、攻击核心或离开控制区域。

### 固定型敌人的仇恨表现

   仇恨值   行为
  --------- ----------------------------------
    0--19   缓慢活动，偶尔伸出触手
   20--39   触手开始感知附近目标
   40--59   攻击频率提高，触手伸展距离增加
   60--79   多根触手连续攻击
   80--100  进入高强度攻击阶段，攻击间隔缩短

仇恨值影响：

-   触手伸展速度。
-   攻击频率。
-   攻击范围。
-   触手数量。
-   攻击预判程度。

固定型敌人通过触手伸展和区域攻击维持威胁，主体位置保持锚定。

### 固定型敌人的弱点

建议至少提供一种明确的反制方式：

-   破坏触手节点。
-   攻击裸露核心。
-   使用远程武器攻击根部。
-   关闭或破坏其异常供能装置。
-   从攻击范围外绕行。

固定型敌人可以作为地图区域障碍，玩家可以通过破坏节点、暂时压制或绕行完成应对。

## 28.3 区域活动型 Territorial Creature

区域活动型敌人有一个固定领地，但可以在领地内部移动。

例如：

-   活动范围为医院的一层和地下室。
-   活动范围为一栋大型仓库。
-   活动范围为森林中的一片空地。
-   活动范围为一段地下隧道。
-   活动范围为某个裂隙周围的区域。

### 领地数据

  参数                 说明
  -------------------- --------------
  `territory_center`   领地中心
  `territory_radius`   最大活动半径
  `patrol_points`      巡逻点
  `leash_distance`     最大追击距离
  `return_speed`       返回领地速度
  `territory_state`    领地当前状态

初始建议：

-   普通区域型敌人活动半径：15--25米。
-   大型敌人活动半径：25--40米。
-   追击范围由领地半径和leash_distance统一控制。
-   玩家离开领地后，敌人最多追到边界附近。

### 行为流程

1.  在领地内巡逻。
2.  发现玩家后增加仇恨。
3.  在领地内追逐玩家。
4.  玩家躲入掩体后，敌人前往最后发现位置。
5.  在领地范围内搜索。
6.  玩家离开领地后，敌人停止扩大追击范围。
7.  搜索失败后返回巡逻路线。

区域型敌人按照领地半径、巡逻点和追击边界活动。

### 领地边界表现

可以通过环境表现暗示领地边界：

-   地面菌丝密度变化。
-   墙面触手分布变化。
-   光线和雾气变化。
-   特殊地面纹理。
-   异常声音和视觉干扰。

领地边界通过地面菌丝、墙面触手、光照和雾气向玩家呈现。

## 28.4 潜伏伏击型 Ambush Creature

潜伏型敌人可以伪装成环境物体或处于休眠状态。

可能伪装的位置：

-   墙壁和天花板。
-   地面裂口。
-   家具背后。
-   废弃车辆。
-   建筑阴影。
-   大型异常组织。

触发条件：

-   玩家进入感知范围。
-   玩家触碰附近物体。
-   玩家停留时间过长。
-   玩家进入异常区域。
-   玩家照射其弱点或核心。

攻击后进入短暂暴露状态，允许玩家反击。

潜伏型敌人通过轻微移动、材质异常、呼吸状起伏或SAN波动提供可观察线索。

## 28.5 三种类型的战斗差异

  类型         玩家主要应对方式
  ------------ ----------------------------------------
  普通追踪型   利用掩体、绕路、拉开距离、攻击
  固定扎根型   判断攻击范围、破坏触手、攻击核心、绕行
  区域活动型   观察领地边界、诱导敌人、脱离区域
  潜伏伏击型   观察环境、提前发现、快速反击

# 29. 裂隙、敌人与异常关注度的联动

## 29.1 三种独立参数

需要区分：

  参数           作用
  -------------- --------------------------
  SAN            玩家当前精神稳定程度
  异常关注度     异常世界对玩家的关注程度
  区域污染等级   当前区域的异常强度

三者分别保存，并通过明确的联动规则共同影响敌人刷新和裂隙生成。

## 29.2 裂隙生成权重

建议：

-   SAN越低，精神异常压力越高，裂隙候选点权重越高。
-   异常关注度越高，裂隙生成概率越高。
-   区域污染等级越高，裂隙更容易生成。
-   玩家在同一地区停留越久，候选地块权重可以逐渐增加。
-   已经生成裂隙的区域进入冷却，避免短时间连续生成。

## 29.3 颠倒世界敌人刷新

颠倒世界的克苏鲁刷新由以下因素决定：

-   当前区域污染等级。
-   当前异常关注度。
-   最高遭遇阶段。
-   玩家在颠倒世界停留时间。
-   当前区域的敌人数量。
-   固定型和区域型敌人的占位情况。
-   是否存在特殊剧情事件。

颠倒世界敌人密度根据区域等级、当前敌人数量、刷新冷却和玩家停留时间动态计算。

## 29.4 玩家停留时间

颠倒世界可以增加一个隐藏的 `InvertedExposureTime`：

-   用于控制特殊事件出现概率。
-   用于调整异常环境效果。
-   用于触发部分裂隙不稳定事件。
-   用于提高高等级克苏鲁的遭遇概率。

InvertedExposureTime作为独立世界层参数，控制特殊事件、环境变化和遭遇权重；SAN仍单独计算。

## 29.5 裂隙与敌人的关系

建议增加以下规则：

-   部分固定型克苏鲁守护裂隙。
-   部分区域型克苏鲁以裂隙为领地中心。
-   T4刷新点在区域内分散布置，并依据出口安全距离进行配置。
-   T5可以控制某个区域的裂隙开合。
-   跨越裂隙的克苏鲁通过专属跨界能力和特殊事件配置实现。
-   特殊剧情敌人可以拥有跨世界能力，但必须作为独立能力设计。

## 29.6 进入颠倒世界的风险递增

建议玩家在颠倒世界停留越久，环境压力越明显，但必须给出可读的预兆：

1.  初期：环境异响、远处轮廓和低频SAN压力。
2.  中期：异常生物活动增加，裂隙位置出现变化。
3.  后期：高等级克苏鲁巡猎，部分区域出现空间干扰。
4.  极端状态：特殊事件触发，玩家需要尽快寻找出口。

颠倒世界停留时间通过环境压力、敌人活动和裂隙状态逐步提高探索风险，让玩家根据路线和资源判断继续深入的时机。

``` gdscript
func can_spawn_rift(player, region, anchor) -> bool:
    if anchor == null:
        return false

    if not anchor.is_safe_for_spawn:
        return false

    if anchor.is_on_cooldown():
        return false

    if region.pollution_level >= 3:
        return true

    if player.san <= 35 and player.anomaly_attention >= 30:
        return true

    if player.anomaly_attention >= 60:
        return true

    return false
```

此处是第一轮规则示例。正式实现应把阈值放入可配置资源，避免硬编码。

## 31.5 仇恨值计算伪代码

``` gdscript
func update_aggro(delta: float) -> void:
    if has_line_of_sight_to_player():
        continuous_sight_time += delta

        var sight_multiplier = min(
            1.0 + continuous_sight_time / 5.0,
            3.0
        )

        var gain_rate = base_aggro_gain * sight_multiplier

        aggro += gain_rate * delta
        aggro = clamp(aggro, 0.0, 100.0)

        last_seen_position = player.global_position
        last_seen_time = Time.get_ticks_msec() / 1000.0

    else:
        continuous_sight_time = 0.0
        update_lost_sight_behavior(delta)
```

## 31.6 速度计算伪代码

``` gdscript
func get_current_speed() -> float:
    var aggro_multiplier = 0.75 + 0.5 * (aggro / 100.0)

    var visibility_multiplier := 1.0

    match current_state:
        State.DIRECT_CHASE:
            visibility_multiplier = 1.0
        State.LAST_KNOWN_POSITION:
            visibility_multiplier = 0.65
        State.SEARCH:
            visibility_multiplier = 0.40
        State.RETURN_TO_TERRITORY:
            visibility_multiplier = 0.55
        _:
            visibility_multiplier = 0.5

    return (
        base_speed
        * aggro_multiplier
        * visibility_multiplier
        * creature_speed_modifier
    )
```

## 31.7 失去视线后的逻辑伪代码

``` gdscript
func update_lost_sight_behavior(delta: float) -> void:
    lost_sight_time += delta

    if lost_sight_time <= last_position_memory_time:
        set_navigation_target(last_seen_position)
        current_state = State.LAST_KNOWN_POSITION
        return

    if not reached_last_seen_position():
        set_navigation_target(last_seen_position)
        return

    current_state = State.SEARCH
    search_timer += delta

    if search_timer >= search_duration:
        current_state = State.RETURN_TO_TERRITORY
        aggro = max(0.0, aggro - decay_rate * delta)
```

## 31.8 区域型敌人边界判断

``` gdscript
func can_move_to_position(target_position: Vector3) -> bool:
    var distance = territory_center.distance_to(target_position)
    return distance <= territory_radius
```

如果目标超出领地范围：

-   将目标点限制在领地边缘。
-   停止继续向外追逐。
-   在边缘进行短暂搜索。
-   超时后返回领地内部巡逻点。

固定型敌人将仇恨值转换成攻击频率、触手速度和攻击范围，主体锚定在固定位置。
