# 3. 玩家角色与七项生存状态

玩家只有一个可操作角色。角色状态分为七项，HUD以圆形图标和外圈进度呈现；其中HP、饥饿、口渴、疲劳、SAN及丧尸感染六项常驻左下角，体力在角色右侧按消耗动态出现。

## 3.1 七项状态定义

  状态            数值范围  数值含义           主要影响
  -------------- ---------- ------------------ ----------------------------
  HP / 生命值      0--100   角色整体生命状况   归零死亡
  饥饿 Hunger      0--100   越高越饿           影响身体状态和生命恢复
  口渴 Thirst      0--100   越高越渴           影响体力、行动和生命状态
  疲劳 Fatigue     0--100   越高越疲劳         降低最大体力和恢复效率
  SAN / 理智       0--100   越低越不稳定       幻觉、精神干扰和异常事件
  体力 Stamina     0--100   当前可用行动能量   奔跑、攻击、翻越和搬运消耗
  感染 Infection   0--100   越高表示感染越重   丧尸伤害积累、药物与医疗控制

饥饿、口渴、疲劳和感染的数值越高，状态越差；SAN和体力则相反，数值越高越好。

## 3.1.1 感染值与七项HUD规则
感染值 Infection 为第七项核心生存状态，范围0—100，数值越高越严重。丧尸攻击成功且未被完全防护时会按攻击类型增加感染值；咬伤增加更多。感染不直接导致不可逆死亡，100也仍可治疗；严重感染会引起体力恢复下降、疲劳加重及生命恢复受限。基础抗生素、强化抗感染剂和高级治疗药物按医疗等级提升疗效与制作权限，详见第44章。一般伤口细菌感染仍由原本的局部伤势系统维护，避免与全局丧尸感染混淆。

## 3.2 HP

HP代表整体生命值，并与局部伤势联动计算。

HP下降来源：

-   丧尸攻击、抓取和撕咬。
-   枪械和其他人类敌人的攻击。
-   克苏鲁生物攻击。
-   坠落、火焰、爆炸和环境伤害。
-   严重伤势导致的持续伤害。

HP恢复来源：

-   医疗用品。
-   正确处理伤口后的自然恢复。
-   充分休息。
-   特殊医疗资源。

止血用于终止持续失血；骨折处理用于恢复部位稳定性并进入休养阶段；感染治疗用于控制感染并进入恢复阶段。

## 3.3 饥饿

饥饿值范围0--100，数值越高越饿。

   饥饿值   状态       效果
  --------- ---------- ----------------------------
    0--24   正常       无明显惩罚
   25--49   轻度饥饿   体力恢复轻微下降
   50--74   中度饥饿   体力恢复下降
   75--89   严重饥饿   生命恢复受限，行动效率下降
   90--100  极度饥饿   持续损害身体状态

饱腹感用于降低饥饿值，卡路里用于计算能量摄入与长期热量收支。

## 3.4 口渴

口渴值范围0--100，数值越高越渴。

   口渴值   状态       效果
  --------- ---------- --------------------
    0--24   正常       无明显惩罚
   25--49   轻度口渴   体力恢复轻微下降
   50--74   中度脱水   最大体力下降
   75--89   严重脱水   移动与战斗效率下降
   90--100  极度脱水   持续损害生命状态

水资源分为干净水、未净化水、污染水和特殊液体。玩家可以通过烧水、过滤器、净水设备等方式获得安全饮用水。

## 3.5 疲劳

疲劳与体力分开计算。

-   体力：短期动作资源，停止活动后较快恢复。

-   疲劳：长期睡眠需求，主要通过睡眠降低。

      劳值 状态       效果     
      ------------ ----------- --------------------
      0--24 精力    充足 正常  行动
      5--49 轻度    疲劳 体力  恢复略慢
      0--69 中度    疲劳 最大  体力下降
      0--89 严重    疲劳 移动  和攻击效率下降
      --100 极度    疲劳 难以  正常战斗，需要睡眠

睡眠地点包括床、沙发和临时床铺。睡眠质量受安全程度、床铺质量和异常区域影响。危险环境中的睡眠质量由周围安全程度、敌人活动、异常事件和床铺条件共同决定，并支持睡眠中断与受袭事件。

## 3.6 SAN

SAN范围0--100，数值越低代表精神状态越差。

        SAN 精神阶段   表现
  --------- ---------- ----------------------------
    80--100 稳定       正常感知
     60--79 不安       偶发异常声音
     40--59 恐惧       轻微幻听、视觉干扰
     20--39 精神紊乱   假目标、异常影像、瞄准干扰
      1--19 崩溃边缘   强烈幻觉、恐慌和行动干扰
          0 精神崩溃   触发特殊精神事件

SAN下降来源：

-   看见低级观察型克苏鲁。
-   接触中高级克苏鲁。
-   长时间处于异常区域。
-   接触禁忌遗物和异常样本。
-   阅读禁忌资料。
-   遭遇异常空间和精神事件。

SAN恢复来源：

-   在安全区域休息。
-   睡眠。
-   特定药物和治疗。
-   离开异常区域。
-   完成部分调查或剧情事件。

SAN不等于异常关注度。两者必须分开保存。

## 3.7 体力

体力范围0--100。

消耗场景：

-   奔跑和冲刺。
-   近战攻击。
-   重型武器攻击。
-   跳跃、翻越和闪避。
-   推开丧尸。
-   搬运重物。

恢复方式：

-   停止活动：缓慢恢复。
-   坐下或短暂休息：较快恢复。
-   睡眠：恢复体力并降低疲劳。

力量、敏捷、负重、饥饿、口渴和疲劳共同影响体力消耗与恢复。

# 5. 十种技能与25级成长系统

## 5.1 技能成长与逐级解锁的统一规则

角色拥有枪械、力量、敏捷、潜行、生存、医疗、机械、制作、神秘学、电力共十项技能，独立保存基础等级和经验，等级范围0—25。**取消固定间隔的特殊奖励、阶段宝箱或额外天赋点。每次升级都立即产生一次基础属性增益，并获得一项可辨认的操作熟练度、技能知识、配方或轻量被动能力。** 每一级的永久解锁完整写入下表，不依赖额外手动加点。

- 每次升级的数值效果采用累计修正并设上限；例如技能10级应包含1—10级全部增益，不需要分五档发奖。
- 0级即可使用生存必需的基础工具、探索拾取的枪械和药品、现成发电机与普通家具。技能等级主要改善效率、复杂操作和自制能力，不把基础生存操作锁死。
- 技能解锁以**基础技能等级**作为条件；力量与敏捷的体型修正仅改变实际属性，不提前解锁配方。
- 配方可能额外要求工具、材料、蓝图和工作台。技能解锁仅代表掌握知识，不代表无物资直接制作。
- 重要操作若按默认键即可执行，不再设置同一种动作的重复技能门槛；高等级改进速度、成功率、品质与可处理复杂度。
- 熟练度经验只由真实且有效的活动产生。矿块耗尽、空树桩挥砍、反复放置同一个中继器、故意制造同一机械故障均不产生可持续经验。
- 建议升级所需经验：`XP_next = 100 + 25 × 当前基础等级`；从0到25级累计约10000经验。经验曲线与每级奖励全部由配置文件控制。
- UI显示“当前等级 / 升下一级经验 / 本级已获得能力 / 下一级具体奖励”，只显示最近等级，不需要五级奖励里程碑条。
- 存档中的已学配方采用稳定配方ID；升级时按等级重算可解锁项，再合并来自图纸和任务的永久解锁。读档与世界切换不会重复给道具。

## 5.13 技能配置与升级结算

1. `SkillDefinition` 记录 `skill_id`、经验公式、每级数值曲线和25条 `LevelBenefit`。
2. 每个玩家保存 `skill_id → {base_level, xp}`；不保存第二份“阶段等级”。
3. 当经验跨越多个等级时按等级逐个发放知识性解锁，但向玩家合并展示一次结果。
4. `LevelBenefit` 支持 `passive_modifier`、`recipe_unlock`、`action_mastery`、`ui_knowledge` 四种效果，不直接凭空生成材料。
5. 若技能配置调整或存档迁移，依据当前基础等级重算全部应有能力，再与由NPC/图纸解锁的项目求并集。
6. 25级继续使用已有能力，但不再累积经验超过上限，也不重复发放物品。
7. `Survival` 承担采矿、砍伐、资源识别等经验；`Crafting` 承担冶炼、加工、木工、建筑；`Mechanical` 负责动力工具维护；`Electrical` 负责供电接入。技能总数仍为十项。

# 6. 食物、卡路里、饱腹感与体型变化

## 6.1 两项食物属性

每种食物具有两个核心属性：

  属性              作用
  ----------------- ----------------------------
  卡路里 Calories   提供能量，参与长期热量收支
  饱腹感 Satiety    降低角色饥饿值

两者独立计算。

卡路里与饱腹感是独立属性：高能量食物可以拥有较低饱腹感，饱腹感较高的食物也可以提供较少能量。

重量、占用格子、保质期和变质状态作为物品属性管理；营养系统使用卡路里和饱腹感两项核心数据。

## 6.2 食物示例

  食物           卡路里    饱腹感
  ------------ ---------- --------
  巧克力        250 kcal     8
  面包          220 kcal     18
  午餐肉罐头    350 kcal     25
  豆类罐头      420 kcal     32
  坚果          550 kcal     12
  蔬菜汤        180 kcal     30
  肉类炖菜      450 kcal     38

以上为游戏平衡示例值，用于区分食物定位和玩法效果。

## 6.3 饱腹感计算

饥饿值范围0--100，越高越饿。

`新饥饿值 = max(0, 原饥饿值 - 食物饱腹感)`

饱腹感用于降低饥饿值；力量、敏捷和体力由技能、体型和生存状态联动计算。

## 6.4 卡路里收支

`每日热量收支 = 摄入卡路里 - 基础消耗 - 活动额外消耗`

基础消耗可先设置为每日1800--2000 kcal，再根据游戏时间流速调整。

额外消耗来自：

-   长时间步行。
-   疾跑。
-   近战战斗。
-   搬运重物。
-   制作、维修和高强度劳动。

卡路里摄入和消耗按世界时间统一累计，菜单打开、场景切换和存档读取沿用同一结算时间戳。

## 6.5 短期能量状态

卡路里还影响短期身体能量表现。建议根据近期热量缺口计算隐藏能量状态：

  能量状态   效果
  ---------- ----------------------------------
  充足       正常最大体力和恢复
  轻度不足   体力恢复速度降低5%
  中度不足   最大体力降低10%，恢复速度降低10%
  严重不足   最大体力降低20%，恢复速度降低25%

短期能量状态与饥饿值分别计算，玩家在饱腹状态下仍可能存在长期热量摄入不足。

## 6.6 长期体型变化

长期净热量盈余导致体型向肥胖方向变化；长期净热量缺口导致体型向瘦弱方向变化。

初始游戏参数：

-   每累计2500 kcal净盈余，体型修正值增加1。
-   每累计2500 kcal净缺口，体型修正值减少1。
-   体型修正范围为-25至+25。
-   接近热量平衡时体型基本保持稳定。

该2500 kcal是游戏调参值，应结合游戏内一天的实际时长和活动消耗进行测试。

## 6.7 体型修正与技能等级

隐藏参数：`BodyConditionModifier`，范围-25至+25。

   修正值  体型        力量修正   敏捷修正
  -------- ---------- ---------- ----------
    -25    极度瘦弱      -25        +25
    -20    严重瘦弱      -20        +20
    -15    明显偏瘦      -15        +15
    -10    偏瘦          -10        +10
     -5    轻微偏瘦       -5         +5
     0     正常           0          0
     +5    轻微壮实       +5         -5
    +10    偏胖          +10        -10
    +15    明显肥胖      +15        -15
    +20    严重肥胖      +20        -20
    +25    极度肥胖      +25        -25

中间数值按照线性或分段曲线逐级计算。

有效技能等级：

`有效力量等级 = 基础力量等级 + BodyConditionModifier`

`有效敏捷等级 = 基础敏捷等级 - BodyConditionModifier`

基础力量、基础敏捷范围0--25；有效等级允许为负数，理论范围-25至50。

示例：

-   基础力量10、基础敏捷10、体型修正+15：有效力量25、有效敏捷-5。
-   基础力量10、基础敏捷10、体型修正-20：有效力量-10、有效敏捷30。

体型修正作用于力量和敏捷有效等级；技能经验和基础等级独立保存。

## 6.8 有效力量与敏捷对实际玩法的影响

最大负重初始公式：

`最大负重 = 20 + 0.4 × 有效力量等级（kg）`

示例：

   有效力量   最大负重
  ---------- ----------
     -25        10kg
      0         20kg
      10        24kg
      25        30kg
      50        40kg

近战体力消耗：

`近战消耗倍率 = clamp(1 - 0.006 × 有效力量等级, 0.70, 1.20)`

移动速度：

`移动速度倍率 = clamp(1 + 0.003 × 有效敏捷等级, 0.85, 1.15)`

疾跑速度：

`疾跑速度倍率 = clamp(1 + 0.004 × 有效敏捷等级, 0.85, 1.20)`

疾跑体力消耗：

`疾跑消耗倍率 = clamp(1 - 0.004 × 有效敏捷等级, 0.75, 1.20)`

这些公式为第一轮平衡参数。后续应根据角色动画、地图尺度和战斗节奏调整。

## 6.9 体型视觉表现

体型变化通过模型形变或预设档位体现，并按体型区间更新角色外观。

建议制作5个视觉档位：

1.  极瘦。
2.  偏瘦。
3.  正常。
4.  偏胖。
5.  肥胖。

通过角色身体网格的形变、预制模型切换或 Blend Shape
实现。头部、手脚和装备穿戴需要避免明显穿模。

体型修正通过有效力量改变最大负重；背包本身决定网格空间容量。

## 结语：整体设计原则

本项目的核心是建立相互影响的角色成长、生存、探索、战斗和异常生态系统：

-   技能代表后天训练。
-   食物代表能量摄入。
-   卡路里收支决定长期身体变化。
-   体型修正改变力量和敏捷的有效等级。
-   背包空间和负重决定搜刮取舍。
-   身体伤势决定战斗和行动能力。
-   丧尸通过声音、视觉和尸潮制造常规生存压力。
-   克苏鲁通过观察、特殊感知、光源仇恨和SAN制造未知恐怖。
-   神秘学成长让玩家逐步获得理解和处理异常的能力。

开发时优先验证角色、饮食、背包、丧尸和T1/T3克苏鲁之间的核心循环，再逐步扩展地图、敌人和高级异常内容。所有表格中的数值均作为第一轮游戏平衡参数，最终应通过实际测试调整。
