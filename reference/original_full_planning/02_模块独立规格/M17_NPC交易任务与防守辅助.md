# M17｜NPC职业、任务、交易与微量守卫——独立可执行设计书

> **定位：**本文件先给本模块的完整可执行设计与对应数据，再附106章原规划中属于本模块的条款。表中数值为初始游戏平衡配置，非已测试结论。

## 1. 玩家体验与系统边界

功能型NPC有限辅助；世界实体身份唯一，任务阶段和物品交付原子结算。本模块不得绕过物品所有权、世界层身份、世界时钟和全局事件幂等机制。

## 2. 完整业务处理链

1. **NPC职业服务时段和据点岗位**：输入由唯一对象ID、世界层、当前世界时钟以及必要的物品/技能/位置构成；先验证目标、条件和容量，再发布带event_id的动作事件；最后在统一状态记录中提交变更，更新显示并记录异常日志。
2. **接任务生成目标与奖励**：输入由唯一对象ID、世界层、当前世界时钟以及必要的物品/技能/位置构成；先验证目标、条件和容量，再发布带event_id的动作事件；最后在统一状态记录中提交变更，更新显示并记录异常日志。
3. **任务区域兴趣点触发**：输入由唯一对象ID、世界层、当前世界时钟以及必要的物品/技能/位置构成；先验证目标、条件和容量，再发布带event_id的动作事件；最后在统一状态记录中提交变更，更新显示并记录异常日志。
4. **验收任务并发放一次奖励**：输入由唯一对象ID、世界层、当前世界时钟以及必要的物品/技能/位置构成；先验证目标、条件和容量，再发布带event_id的动作事件；最后在统一状态记录中提交变更，更新显示并记录异常日志。
5. **战斗仅做有限守卫不替代玩家**：输入由唯一对象ID、世界层、当前世界时钟以及必要的物品/技能/位置构成；先验证目标、条件和容量，再发布带event_id的动作事件；最后在统一状态记录中提交变更，更新显示并记录异常日志。

## 3. 模块专属规则、数值逻辑与边界

### NPC任务
NPC只做有限后勤：据点定点巡逻、交易、治疗服务和有限射击支援，弹药由实际库存扣除。任务有 `OFFERED→ACCEPTED→PROGRESS→READY→CLAIMED`；每次奖励有唯一claim event_id；击杀目标、货物运送或探索地点都应有服务端式幂等验证，即使单人游戏也不可依赖纯UI状态。

## 4. 运行时数据与职责

- **定义资源**：`17_Definition`：保留静态属性、参数上下限、版本号和关联ID。
- **实例状态**：`17_InstanceState`：保留instance_id、world_layer、last_tick、state_version及本模块运行字段。
- **动作请求**：`17_ActionRequest`：actor_id、target_id、requested_time、payload、event_id。
- **写入策略**：本模块仅写其负责的实例字段，对其他模块通过事件和接口请求变更。

# 14. 游戏循环与进度结构

## 14.1 核心循环

1.  探索开放世界。
2.  发现建筑、资源、事件和异常地点。
3.  搜刮物资并规划背包空间和负重。
4.  处理丧尸、伤势、饥饿、口渴和疲劳。
5.  返回据点整理物资、维修装备、制作物品和休息。
6.  研究异常线索，提升神秘学技能和异常关注度。
7.  进入更危险区域，遭遇更高级克苏鲁。
8.  获得高级资源，逐步揭开世界异常的来源。

### 长期生存循环
观察天气与发电预测→查看七项状态与感染→规划枪械本体和配件→接取NPC委托→外出搜刮建材/药品/燃料→返回据点制造、治疗、建设和布线→给电池充电并配置哨塔→抵御局部尸群与天气影响→研究异常裂隙与高风险区域。外出探索始终是获取高阶配方、药物及稀有设备的主要来源。

## 14.2 玩家决策示例

玩家进入超市时需要考虑：

-   当前饥饿和口渴。
-   背包剩余格子。
-   当前负重。
-   附近丧尸数量。
-   是否有足够弹药。
-   是否值得继续搜刮。
-   是否需要在夜间使用手电筒。
-   是否可能进入克苏鲁活动区域。

这样生存、背包、技能和敌人系统才能真正形成联系。

# 49. 据点防御、瞭望塔、塔防与守卫

## 49.1 据点定位

据点是玩家休息、储物、维修、研究、发电与抵挡局部威胁的核心区域，但不是完全自动化的安全岛。防御以**布置位置、耐久、弹药、电力和少量NPC协助**为核心，参考生存游戏据点建造与轻量塔防，而非不断建塔无限刷怪的纯塔防游戏。玩家外出时防御设施可以进行简化结算，但不会在离线模拟中无限歼灭敌人并产出无穷物资。

## 49.2 据点区域和安全评级

玩家通过放置据点标记或选择已控制的完整房屋建立据点，记录 `safehouse_id`、区域边界、建设权限、入口、防御岗位与库存。安全评级由外围围栏完整度、照明、可以通行的安全入口、哨塔覆盖、NPC守卫、附近敌人威胁和天气遮蔽共同影响。高安全评级降低睡眠中断和普通游荡丧尸接近的风险，但不完全阻止任务袭击或高级异常事件。

## 49.3 防御设施类型

| 设施 | 核心效果 | 消耗 | 主要弱点 |
|---|---|---|---|
| 木/金属围墙 | 阻挡路线、让敌人绕行或攻击 | 建材、维修材料 | 长期受攻击后破损 |
| 加固门窗 | 减慢破门、阻挡常规丧尸 | 木材或金属 | 集中攻击仍可突破 |
| 尖刺/地面陷阱 | 对接近目标造成少量伤害或减速 | 耐久或补充材料 | 作用次数有限，可能误伤 |
| 瞭望塔（人工） | 提供高处观察与射界 | 建筑材料、照明、守卫弹药 | 需要玩家或NPC操作 |
| 简易固定射击位 | NPC持枪守卫的防守位置 | NPC装备、弹药 | NPC反应慢，盲区多 |
| 自动哨塔 | 有电时自动识别并射击敌对目标 | 电力、弹药、组件耐久 | 断电、缺弹、遮挡和被破坏 |
| 探照灯 | 提高夜间照明和观察范围 | 电力 | 会暴露据点，可能触发克苏鲁光感知 |
| 警报器 | 对入侵发出提醒 | 电力或电池 | 声音会吸引部分丧尸 |

## 49.4 瞭望塔结构与操作

建造瞭望塔时先放底座，再建支柱/平台、护栏、梯子或楼梯、照明与守卫岗位。建议初级塔高4—6米，占地约3×3米；高级塔高6—9米，但高塔并非自动提高射程无限远。塔体有独立结构耐久，基座破损会影响顶层平台；登塔时角色和NPC必须有合法导航连接。塔上人员使用原有角色枪械和弹药规则，NPC必须能实际看到目标才开火。

人工哨塔不消耗持续电力；夜间照明和自动观测附件才消耗电力。玩家可在塔上亲自射击或将一名NPC指派给守卫岗位。NPC不会拥有超出基础AI能力的穿墙索敌或无限弹药。

## 49.5 自动哨塔

自动哨塔由底座、旋转架、武器模块、弹药箱、供电接口、目标检测器构成（为游戏物品组件，不要求玩家逐个安装真实机械结构）。运行状态：`OFFLINE`（断电）→`IDLE`（有电待机）→`TRACK`（锁定合法目标）→`FIRE`（射击）→`RELOAD`（装填）→`COOLDOWN`（冷却）/`BROKEN`（故障）。

- **目标识别**：只瞄准本世界层内允许攻击的丧尸或敌对克苏鲁，不能攻击NPC、玩家和非敌对T1观察者；支持友军安全判定。
- **瞄准/射界**：必须满足水平旋转角、俯仰角、射线无遮挡、距离和射速冷却；墙后敌人不可被追踪并射中。
- **弹药**：使用单独弹药库存，与常规弹药物品共用；空弹时停止攻击并显示缺弹。
- **电力**：有电才能转动/索敌；射击期间功率提高，供电不足按低优先级或断电规则处理。
- **耐久/修理**：可被丧尸破坏，雨暴和雷击可造成低概率电气故障；维修需要材料。
- **仇恨噪音**：枪声是原有声音事件，会吸引更多丧尸；照明在夜间可能增加高级克苏鲁遭遇风险。

## 49.6 轻度NPC守卫

玩家最多指派少量NPC在固定岗位巡逻、观察或驻守，建议初始同时在岗1—3人。NPC有基础生命、弹药、士气（简化为岗位有效性状态）、装备和守卫半径。与玩家相比，其命中率较低、射速受限、反应存在延迟；优先自保、持有固定的守卫目标，不会自行跨地图清怪。受伤后可能撤回安全点；NPC任务与交易功能不会因担任守卫而丢失。

## 49.7 敌人对据点的攻击

普通丧尸因噪音、光线（其视觉规则）或尸群迁徙接近据点；尖叫者能触发局部增援；尸群优先尝试可达入口，无法进入时攻击可破坏的门、窗、墙段。克苏鲁依旧执行原有第10、27、28章感知与领域约束，不默认参加普通尸潮。高级克苏鲁可能攻击墙体、照明或设备，但具有遭遇前兆、生成限制和可逃脱条件。

## 49.8 防御事件而非强制波次

防守压力由周围威胁程度、玩家噪音、据点安全评级、NPC任务事件、区域危险度共同形成。可有预报式局部围攻、尸群迁徙撞击、突发停电与物资维修任务；频率应留出外出搜刮和治疗时间，不强制每晚发生一次大型攻城。首个可玩版本以一次有预兆的小型围攻为验收，不要一开始实现无限复杂波次生成器。

## 49.9 远距离模拟与存档

玩家离开据点后，对普通丧尸骚扰采用时间分片的简化伤害/耐久/弹药结算；NPC守卫通过命中概率与消耗量估算，禁止远距离即时生成完整弹道和持续NavMesh寻路。玩家返回时根据持久状态恢复破损围墙、消耗弹药、NPC伤势与断电情况；跨越世界层时，不启动两套同时存在的据点守卫。基地公共库存与设施只存在一份。

## 49.10 验收

NPC能爬上瞭望塔并防守合法视线范围；自动哨塔有电有弹时对敌开火，没电或缺弹立即停火；子弹消耗与原有弹药统一；防御设施不能穿墙射击；塔被破坏会失效；离开再回来后弹药、破损和岗位状态保持；据点照明造成的克苏鲁光源仇恨遵守原有规则。

# 50. NPC功能、交易、任务与防守协助

## 50.1 NPC的角色定位

NPC数量少、能力有限，参考《泰拉瑞亚》功能型居民的陪伴与轻度帮助，以及《七日杀》商人提供分级委托的结构。NPC不会组成大规模可操控军队，不替玩家自动完成主线，不提供无穷物资。其核心作用是：提供交易和信息、在据点承担少量岗位任务、通过委托引导玩家探索不同地点。

## 50.2 NPC职业及功能

| NPC职业 | 玩家可获得的服务 | 据点轻度辅助 |
|---|---|---|
| 商人/物资商 | 以物易物、基础补给、委托 | 提供物资需求与交易刷新 |
| 医生/护士 | 基础治疗、感染药物、医疗配方线索 | 定期治疗伤口或缩短NPC恢复时间 |
| 机械师 | 发电机修理、机械零件交易 | 为设备提供少量维修辅助 |
| 电工/工程师 | 中继器故障处理、供电任务 | 对电力设备进行少量维护 |
| 武器商/猎人 | 基础枪械与配件、弹药委托 | 可成为弱守卫岗位人员 |
| 侦察者/调查员 | 建筑位置、异常事件委托 | 提供周边威胁短时情报 |

NPC职业可合并，首版只需要物资商、医疗NPC和工程师/守卫三类原型；地图扩充后加入更多外观、语音和任务，但不强制复杂生活模拟。

## 50.3 招募、安置与岗位

玩家通过救援、完成NPC委托或地图事件获得安置资格。NPC有唯一 `npc_id`、阵营、职业、交互位置、当前岗位、生活需求抽象等级和存活状态。安置应检查床位、基本安全与行走路线；玩家能够指定“留守/守卫/修理/休息”之一。角色周边寻路使用导航代理，停靠与楼梯连接按原建筑寻路规范。无路径时提示无法分配，不瞬移到不可达哨塔。

## 50.4 任务体系：NPC委托

任务分为**搜集、清理、调查、修复、守卫、救援和特殊异常研究**，每项配置难度T1—T5、任务区域、持续性要求、目标、奖励和冷却。T1偏向住宅/便利店，T2工业/医疗，小型守卫任务；T3医院/警局/污染外围；T4军事设施或复杂异常；T5领域事件与阶段研究。任务难度由任务目标实际风险决定，不简单按玩家技能等级自动无限缩放。

| 类型 | 任务目标示例 | 与系统的联动 |
|---|---|---|
| 资源搜集 | 带回3份医疗物资、电子零件等 | 房屋房间物资、背包与负重 |
| 地点清理 | 清除指定维修站周边敌人 | 丧尸分布、限时局部事件 |
| 调查 | 前往医院收集一份异常研究报告 | 神秘学、SAN与异常关注度 |
| 恢复供电 | 为一栋指定建筑恢复发电机与中继器 | 电力技能、线路连通、天气 |
| 防守委托 | 在据点周边守住一次短时尸群冲击 | 围墙、NPC守卫、哨塔 |
| 救援NPC | 清除路径并护送NPC至临时安全处 | NPC简单跟随、敌人寻路 |
| 高风险清理 | 找到特殊丧尸/克苏鲁巢穴并完成目标 | 敌人生态、环境预兆 |

## 50.5 任务状态与奖励

`OFFERED → ACCEPTED → ACTIVE → OBJECTIVES_COMPLETE → READY_TO_TURN_IN → REWARDED`，可由具体规则进入 `FAILED` 或 `ABANDONED`；任务奖励仅提交一次。奖励可为资源、药品、枪械模组、稀有配方、NPC交易解锁、据点建筑图纸和少量技能经验。任务日志显示地点、有效世界层、可选条件、危险评级和奖励预览。

NPC每游戏日提供少量可选任务，但不得靠快速反复接取同一低风险任务无限刷新奖励。任务只为特定地点新增**独立的任务目标实例**；不重置已经搜刮的正常建筑、家具、容器或门窗。若任务目标地点已被玩家完全清空，生成合法替代目标或从尚未探索POI列表选择地点，避免迫使世界物资“复活”。

## 50.6 任务、天气与双世界

部分救援任务受暴风雨路线和可见度影响；恢复供电任务要求通电稳定保持例如60游戏秒，而不是瞬间按按钮完成。异常任务可以要求从主世界裂隙进入颠倒世界收集特定记录，但任务道具具有唯一共享实例，不能从两个世界各拿一份。NPC默认属于主世界的动态生物实体，不因为共享房屋复制进颠倒世界；任务事件若涉及跨界，显式记录其世界层。

## 50.7 交易与经济限制

优先使用以物易物或简化代币经济，不引入复杂宏观经济模拟。NPC库存由职业、区域、任务进度和刷新时间决定；昂贵模组、抗感染药品、电芯/太阳能部件有数量上限。卖出物品要扣除实际物品实例，买入物品生成唯一新实例；交易流程与背包空间、负重校验一体化。医疗NPC的紧急服务消耗资源，不能无限免费治愈。

## 50.8 NPC生存、存档与保护

NPC受攻击可以受伤、逃避、暂时停止服务，受严重伤害会失去守卫能力。任务核心NPC的保护需有合理的替代联系人/任务转交方案，防止单次意外使全部长期系统无法继续。所有NPC状态持久保存，读档后恢复所在岗位、装备、任务进度，不按普通丧尸刷怪规则重生。

## 50.9 验收

接受任务后地点标记正确，目标完成后才能领取奖励；任务领奖不能重复；已搜刮建筑接受任务后保持原有容器状态；NPC能从住处走至岗位，且不堵塞玩家门口；少量守卫对尸群提供有效但有限的辅助；颠倒世界不会复制NPC；任务日志可清楚解释阶段和奖励。

# 95. 采集物流、据点布局、NPC与任务

## 95.1 据点生产区域

玩家可以将住宅车库或工业厂房改造成五个功能区域：原料堆放区、木工与柴薪加工区、矿石分拣及熔炉区、金属维修与制造区、发电与电网区。它们共用房屋/家具放置系统与防火、遮雨、碰撞规则，不能把高温熔炉直接放在木床上无条件运行。道路或院内需要预留车辆卸货动线。

## 95.2 资源物流与生产链

玩家可手持或背负小型物料，用车辆货箱/拖车运输大宗矿石和原木。资源进入仓库时被移动至唯一库存容器；工作台可在允许距离内读取已授权原料箱并从实际物品实例扣除。建议矿石箱、柴薪架、原木堆各有不同的网格或批量容器限制，避免用一格手提箱存放整片森林。

木材/煤矿提供可持续燃料路线，铁和铜矿提供产业路线：**木工支柱与墙体 → 矿洞开发 → 冶炼铁锭 → 升级镐斧及支架 → 铜导线和发电装置 → 据点照明/自动哨塔**。每条生产线都存在工具、材料、耗时与维修成本。

## 95.3 NPC轻量协助

NPC依旧是少量功能角色，不组建无限采矿队。可以安排NPC在据点岗位执行轻量辅助：木工NPC加快一次加工工序、机械师维护一台动力工具、商人提供矿物交易、守卫在矿坑入口或据点承担有限防守。NPC的辅助必须消费真实原料、工具耐久或报酬；玩家不在附近时按限速汇总结算，不会无限自动生成矿石、煤炭和木材。

## 95.4 矿业和林业委托

| 任务类型 | 具体目标 | 奖励例子 | 防重复机制 |
|---|---|---|---|
| 修复矿坑 | 清除堵住旧矿口的塌方、安装两根支柱 | 镐头、工具图纸、少量金属 | 通过矿口事件ID结算一次 |
| 煤炭补给 | 交付限定数量的煤炭 | 燃料、代币、发电零件 | 交付直接扣除库存 |
| 铁材采集 | 交付铁矿或铁锭 | 金属台配件、钢材线索 | 不要求固定矿点重新刷矿 |
| 修复伐木场 | 重建锯木台、清理附近丧尸 | 木工材料与工作台图纸 | 修复状态持久保存 |
| 林地恢复 | 按指定范围种植若干树苗并存活数日 | 种子、林业工具 | 按树苗唯一ID与成长时间判断 |
| 运输合同 | 用货车运一定重量的木材/矿石 | 车件、燃油或物资奖励 | 车辆货物ID和任务交付绑定 |
| 异常矿调查 | 在污染矿脉获取唯一标记的样本 | 神秘学进度或研究设备 | 独立任务样本实例，不重置原矿 |

采集任务奖励经验也走真实完成事件，不得同一个矿点“交付一次、退回矿石、再交付一次”循环刷分。
