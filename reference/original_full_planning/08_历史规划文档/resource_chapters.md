# 86. 自然资源采集系统总览与生态循环

## 86.1 定位与目标

玩家不仅通过房屋搜刮获得物资，还能从自然环境主动获取原材料：在林地砍树获得木柴、原木和树枝，在地表收集石块、砂土与黏土，通过地表矿石线索找到地下矿脉，使用采掘工具获得煤、铁、铜、铅等矿石，将原料运回据点进行分拣、锯切、冶炼、维修与制造。采集是一项有负重、时间、耐久、体力、天气和敌人威胁的实际劳动。

参考《七日杀》的采矿、采集工具和地表矿点指示地下矿脉的设计方向：地表矿石提示深层矿产，玩家可沿矿带向下寻找更大储量；石斧、铁镐、钢镐、动力钻具效率逐步提高；树木随生长阶段提供不同木料并可再植。本项目使用低模3D世界、既有网格背包及单份双世界数据，采集效果和存档实现按本作架构独立设计。

## 86.2 采集分类

| 分类 | 主要行为 | 核心产物 | 主要工具 | 资源性质 |
|---|---|---|---|---|
| 地表拾取 | 捡石、拾枝、拾碎木 | 小石块、枯枝、草料 | 徒手 | 少量散落资源，受区域补给上限约束 |
| 砍伐林木 | 砍树干、修枝、分段 | 原木、柴薪、树枝、种子 | 石斧/铁斧/钢斧/链锯 | 可通过种植和自然成长长期恢复 |
| 软土挖掘 | 挖黏土、砂、表土、砾石 | 黏土、砂、土、砾石 | 铲/动力钻具 | 本地可挖体积有限 |
| 岩石开采 | 敲碎露岩、采石场作业 | 石料、碎石、石灰石 | 镐/钻具 | 有限矿体、可调查 |
| 煤与矿石 | 追踪矿脉、采掘 | 煤、铁、铜、铅及其他矿石 | 镐/动力采掘工具 | 地表线索+地下矿体、不可无条件重刷 |
| 废料回收 | 拆家具、汽车与设备 | 废铁、铜线、塑料、电子零件 | 扳手、撬棍、锯等 | 消耗唯一世界实体，不无限刷新 |

## 86.3 从原材料到成品的可玩循环

1. 观察地图和环境，找到森林、露岩、老矿坑、山坡碎石带或工业废墟。
2. 根据任务准备工具、燃料、维修件、照明、足够的背包/车辆容量、食水及避雨衣物。
3. 发现资源节点，检查剩余资源、硬度、矿种、工具适配和挖掘安全。
4. 选择砍伐、采掘或挖土，持续造成可追踪的资源节点损伤并获得有限资源。
5. 将大件原木、矿石装车，或在现场简易处理以节省空间；负重影响行程和风险。
6. 返回据点，通过锯木、炭化、烧制、熔炼、机加工等生产配方转成可用物资。
7. 使用材料建围墙、制造工具、修车、维护供电网和哨塔，再探索更危险的采集点。

采掘与伐木不是单独的小游戏，必须能够支持制造与防御主循环。高品质装备通过技能、工具和材料提高效率，但不能让普通木材、石块、煤矿和铁矿完全依赖罕见图纸才能获取。

## 86.4 世界资源所有权

所有可破坏资源节点具有唯一 `resource_node_id` 和确定的剩余量；玩家行动造成的树木破损、矿脉开采、地形挖空、自然长成等变化写入 `SharedWorldState`。同一树或同一矿块不能因为再次加载、换世界层、接任务而恢复满值。用于教学或一次性剧情的额外资源节点应有单独的事件ID。

# 87. 矿脉生成、地表线索与可挖掘地形

## 87.1 矿点发现方式

- **可见露头**：山坡、采石场、悬崖脚或废弃矿井入口出现矿物颜色、晶体或金属色条纹，适合玩家直接辨认。
- **地表碎矿**：散落小型煤块、铁锈色碎石、带矿砾石；少量可拾取，可提示下方或附近矿带。
- **地图与调查线索**：工业区地质图、矿场标记、NPC委托、工具扫描提示可能的矿藏分布。
- **追随矿带**：开采时遇到碎石层、矿物条带或不同颜色石壁，可以沿岩层方向追踪更深的矿块。
- **地下遗迹和旧矿道**：提供成型通道、部分可采矿体、废弃轨道和环境危险，适合高级探索。

矿体根据世界种子、区域、地层和地形生成；坐标固定，首次开采时即可保存矿体状态。地表线索应大体可靠，不能让所有露头都指向空地，但同一露头不保证地下拥有无限矿石。

## 87.2 矿脉空间结构

| 矿脉类型 | 生成形态 | 玩法定位 |
|---|---|---|
| 露天单点 | 地表可破坏矿块与小块地下矿石 | 教学与紧急少量材料 |
| 浅层矿带 | 2—6米深的带状矿区 | 日常铁、煤、铜等中等规模供应 |
| 深层矿脉 | 更深的团块、分支或断层矿体 | 较高储量与挖掘/支护要求 |
| 废弃矿道 | 已有洞室与局部矿带 | 危险、搜刮、敌人遭遇与工业遗物 |
| 采石场 | 大块开放式可挖岩体 | 大量石料、砂砾、石灰石 |
| 异常矿带 | 污染区专属矿化物或晶体 | 神秘学及特殊设施，不取代普通矿物 |

建议地表矿点附近设2—4条可能的采掘方向，玩家通过矿石纹理、碎石、工具回声或简易地质调查发现方向。矿石按稳定世界种子生成，已采空的格子写入差量数据，而不是每次按概率重新生成。

## 87.3 3D开放世界的可挖掘地形方案

采用**大型静态低模地表 + 局部可挖掘三维矿区**的混合方案：房屋与主要道路仍使用既有低模地形、建筑和碰撞；可开采的山坡、矿洞、土坑、沙坑、采石场具有显式的 `DiggableVolume`。玩家能够在这些空间向下、侧向掘进并扩展洞室，而不需要全世界所有地面实时生成可破坏地块。

- 建议可挖区域基础单元 `0.5 × 0.5 × 0.5 米`。渲染时对连续相同材质合并表面，维持原本低模风格。
- 运行时采掘区块建议为 `16×16×16` 个单元（边长约8米）；可见面网格、碰撞与导航按脏区块局部重建。
- 每个单元记录岩层材质、耐久、资源剩余量、空/实状态和矿体引用。需要不同视觉外观时使用材质映射，不为每格实例化一个独立 Godot 节点。
- 碰撞仅在发生实际拓扑变化时更新；连续挥镐只改变数值或局部破损表现，不强制每帧重建整个矿洞。
- 主要道路、关键剧情建筑和大型固定桥梁使用 `ProtectedFoundation` 限制，玩家在禁挖位置看到原因；非保护土层允许在安全规则内扩建矿坑。
- 开挖到已存在房间或地下室时，入口按碰撞、房间气候、导航与声音传播重新连接。

对高性能设备可扩展更多可挖掘地层，但存档格式与工具命中接口保持不变。只允许更改被标记为可挖掘的地形单元，不以GPU粒子假装挖出会永久保存的真实洞穴。

## 87.4 世界生成时的环境逻辑

同一种矿石并非所有生物群系都同样丰富。林区可能有浅层黏土、煤与铁矿线索；丘陵、山地更适合露岩与深层矿；工业区的废弃矿场适合工业产线与维修物资；河岸更适合砂石、黏土；污染区域可能有异常矿物。分布由区域数据明确配置，难度取决于采掘距离、天气、路况和敌人威胁，而不是只按角色等级刷出更高级矿。

## 87.5 开采与挖空状态

矿块拥有 `integrity_hp` 和 `remaining_units`。工具击中后根据硬度扣除耐久，并按有效累计采掘进度掉落部分资源，完全打碎后将实体变为空格；为避免只剩1点矿量却刷出大量物品，实际产出不能超过剩余资源池。矿脉连通关系仅用于提示与寻矿，不将所有相邻矿块视为一整个库存。

# 88. 矿种、矿物分布、工具适应与资源经济

## 88.1 基础矿产

| 资源 | 常见来源 | 基础用途 | 工业延伸 |
|---|---|---|---|
| 石块/碎石 | 山坡、石壁、采石场 | 火堆、石斧镐、路基、石墙 | 碎石混凝土、石灰加工 |
| 砂 | 河岸、沙地、砾石层 | 建材填充 | 玻璃、砂浆、混凝土 |
| 黏土 | 湿地、表土、旧河床 | 砖坯、陶器、简易炉体 | 耐火砖与工业炉衬 |
| 石灰石 | 露岩、采石场 | 砂浆、建筑材料 | 冶炼熔剂、混凝土 |
| **煤矿石** | 浅深层煤脉、废弃矿坑 | 火堆、锅炉与**燃烧式发电炉**燃料 | 冶炼燃料、钢材加工、煤焦 |
| **铁矿石** | 山地、露头、工业区旧矿脉 | 冶炼铁锭、工具、基础建材 | 钢材、金属零件、车库设备、哨塔框架 |
| 铜矿石 | 山坡矿带、旧矿井 | 导线、接头、修理 | 电机线圈、中继器与发电部件 |
| 铅矿石 | 地下矿带、废弃矿场 | 配重、屏蔽材料 | 特定工业部件、游戏化弹药材料配方 |
| 硫/硝酸盐类矿物 | 地下矿化物、洞穴沉积 | 专用加工、农业/工业辅助 | 特殊游戏化工坊材料，不含现实危险配方 |
| 异常矿晶 | 高污染矿带或遗迹 | 异常研究 | 特殊防护与封印组件 |

电池所用高品质锂电芯主要来自车辆与电子设备拆解、交易和工业搜刮；矿脉开采可以为电池外壳、导线、支架提供材料。若后期设置含锂矿体，仍需独立的高复杂度加工配方，不把普通原矿直接等同于成品锂电池。

## 88.2 按区域调整资源收益

| 区域 | 可见材料倾向 | 采掘风险 | 运输策略 |
|---|---|---|---|
| 居民区边缘 | 石块、零散木料、少量铁矿 | 游荡丧尸、噪音暴露 | 小背包、步行 |
| 森林/农场 | 树木、树枝、黏土、浅层煤线索 | 雨天湿冷、野外视线与动物 | 皮卡或拖车回收木料 |
| 丘陵/山地 | 铁、煤、铜、石灰石 | 陡坡、坠落、矿坑坍塌 | 车停山脚、分段运输 |
| 工业区 | 废铁、设备拆件、旧矿井 | 密集丧尸、复杂建筑寻路 | 货车与安静装卸 |
| 异常区 | 稀有矿晶、混合矿带 | SAN压力、裂隙、T3—T5威胁 | 轻装撤离、明确返程路线 |
| 颠倒世界对应矿区 | 与主世界共享已存在矿体 | 仅克苏鲁生态与特殊环境风险 | 注意车辆捕获与跨层唯一性 |

## 88.3 矿石品质与加工

矿石统一为 `ore_type + grade + remaining_units`。建议品质分为低品位、常规、高品位三档，主要改变冶炼损耗/杂质或单位工序耗时，而不是粗暴让同一个矿点无限倍增。地图早期常规铁煤供应应足够建立熔炉；铜与其他工业材料在更高风险地点更多，促使玩家使用车辆远征。

## 88.4 物资重量与背包

- 原矿通常占用较多重量和网格，石块、煤与铁矿以可堆叠小件形式进入背包。
- 原木作为长大件，建议搬运状态或车斗货物占位；砍倒后切段可变成多份较易携带的木料。
- 加工成锭、板、零件可能降低空间占用但仍应遵守质量和产率；不能把矿石加工成“零重量”材料。
- 车辆货箱的格子与最大载重均检查，超载增加悬挂、制动和泥地陷车风险。

# 89. 挖矿操作、采掘工具、支护与安全

## 89.1 采矿操作

玩家持工具进入可挖区域，准星指向矿石、岩壁或土层时显示名称、材质、硬度、耐久、预估产物、当前工具和可挖状态。按住或点击攻击执行挥镐；工具有实际打击间隔、手部动画、碰撞射线、体力和耐久消耗。命中有效单元后产生火星或碎屑、沉闷敲击声与进度反馈；挖空后出现真实空腔，并且局部碰撞、遮挡与可通行区域更新。

挖掘过程：`检测交互面 → 确认工具/距离/遮挡 → 消耗体力和耐久 → 降低矿格完整度 → 结算采集量 → 释放物品或加入容器 → 触发区块网格更新 → 存储差量`。

## 89.2 工具等级与行为差异

| 工具 | 合适目标 | 效率与消耗 | 风险 |
|---|---|---|---|
| 徒手/简易石器 | 小石头、细枝、松软土 | 极低效率 | 体力耗尽、手部不适 |
| 石镐 | 岩石、基础矿体 | 初期可用，耐久低 | 噪声小、耗时长 |
| 铁镐 | 铁/煤/铜等主要矿体 | 中期稳定效率 | 金属零件维修成本 |
| 钢镐 | 硬质岩层与深矿 | 高效但较重 | 使用体力较高 |
| 铁锹/钢铲 | 黏土、砂、表土、砾石 | 土质效率高，硬岩效率差 | 斜坡挖掘易失稳 |
| 动力采掘钻具 | 岩石/矿层/大量土方 | 高效率，使用燃油或电池 | 大噪声、发热、需机械维修 |
| 探矿锤 | 岩石类型、矿化迹象 | 用于辨识而非大量采掘 | 近身调查时间较长 |

示例初始采掘倍率（只用于调试）：石镐1.0、铁镐1.6、钢镐2.2、动力钻具3.5。土壤被铲挖时另用材质系数。硬度高于工具有效等级时允许缓慢挖掘，但可能有高耐久消耗；剧情保护区域则明确禁止而不假装工具没伤害。

## 89.3 力量、生存与工具共同计算

`work_damage = tool_base_power × material_match × tool_condition × stamina_factor × effective_strength_factor × survival_efficiency`

`gathered_units = min(remaining_units, progress_yield × ore_grade_factor × (1 + survival_level × 0.003))`

采掘速度、每次耐久损失、体力消耗和产出各自有上下限。力量用于挥动重工具和搬运，生存用于识别、产率与野外操作，制作解锁自制工具和冶炼知识，机械负责动力钻具保养。采矿行为不会自动增加枪械或电力经验。

## 89.4 矿坑支护与塌方

- 洞顶、支柱、岩壁和剩余支撑体以轻量连通支撑图计算稳定性，按粗粒度区块重新评估，不每次击中就对整张世界执行物理求解。
- 采掘破坏大跨度顶板或软弱土层承重时出现碎石、声响、落尘等明确预兆；玩家可以放置木支柱、金属支架或调整矿道宽度。
- 到达警戒阈值后局部掉落石块或产生坍塌，造成七部位伤势、堵路和矿坑损伤；不无提示随机秒杀。
- 坍塌不会瞬间删除玩家全部物品，危及出口时检查可挖掘救援路线；若完全堵塞，应确保可通过工具挖开、预留通道或救援机制脱困。
- 关键任务、裂隙返程点、重要建筑基础及世界层入口设保护边界，不允许因采矿导致永久不可恢复的剧情软锁。

## 89.5 照明、空气与安全

矿坑内天然光随深度衰减；玩家需要手电筒、矿灯、灯笼或据点延伸的照明。矿场作业产生粉尘、噪声和局部温度影响。粉尘通过工作区域暴露时间以及口罩保护表现为短期不适或咳嗽，沿用第62章环境疾病系统；明火与燃烧发电炉在密闭地下空间必须检测通风，存在烟雾积聚风险并给出明显预警。矿坑气体规则保持简化，不做不可见、无法反制的随机致命效果。

矿道中警戒线、支柱、照明和标记位置可制作；夜间采矿声音传到地面时能够吸引普通丧尸在洞口聚集，克苏鲁仍按其视觉与异常感知规则追踪。

## 89.6 工具耐久与维修

工具耐久随有效挥击减少；低耐久导致效率下降或无法继续使用。简单磨刃消耗磨石与时间；木柄可更换；金属镐头修理需要金属材料和对应工作台；动力钻具需要机械零件及动力来源。维修只能恢复受损耐久，不通过反复修理变出材料，也不刷新矿块。

# 90. 伐木、树木倒伏、再生与林业经营

## 90.1 树木种类与生长

可砍伐树木包括松树、阔叶树、白桦/桤木等普通品种，以及少量果树、枯木；每棵树拥有树种、年龄档、健康度、木材储量和砍伐损伤。树木视觉使用低模网格/LOD，不为整片森林创建昂贵的逐枝碰撞体。

| 生长状态 | 外观 | 主要产物 | 处理方式 |
|---|---|---|---|
| 幼苗 | 低矮绿色植株 | 极少或不产木料 | 可种植、保护、移栽 |
| 幼树 | 细树干 | 少量枝条/木料 | 可砍，但效率低 |
| 成年树 | 正常树冠、粗树干 | 原木、柴薪、少量种子 | 主要伐木目标 |
| 老树/大树 | 高大树干 | 更多原木、粗木段 | 需要更久砍伐、倒伏范围更大 |
| 枯木 | 无叶或稀叶 | 干柴、劣质木料 | 适合作为易燃料 |

不同树种决定木板颜色、木材品质、重量和火堆燃烧时间，避免只是复制一棵树再随机改变外观。

## 90.2 砍伐的完整流程

1. 装备斧头或链锯，对准树干可砍伐碰撞区域。
2. 每次挥击消耗体力和工具耐久，树干出现局部切痕、碎木屑和音效。
3. 树干砍伐进度达到阈值时显示倒伏方向提示；玩家可站到侧面或转移工具。
4. 树木按预计方向逐步倾斜并倒下，倒伏过程保留合理碰撞、障碍检测与短暂危险。
5. 倒木变为若干个可交互木段，而非自动复制整棵树的无限原木。
6. 玩家分段锯切，获得粗原木、木柴、树枝、树皮或少量种子，再选择背负、拖动或装车。
7. 树桩可以保留、拆除或自然腐朽；想重新种植必须满足空地、光照、土质和树苗条件。

树木掉落与砍伐前资源池绑定，掉落一次性生成，服务器式单机事务确保坍倒、捡取与读档不会重放掉落。树倒到建筑、围墙、载具上时造成**有上限**的结构伤害，避免一棵小树瞬间毁掉重型车辆或关键建筑。

## 90.3 伐木工具

- 石斧：初期易制、效率低但安静，耐久较低。
- 铁斧：中期常用，可兼作近战，便于伐木和应急防御。
- 钢斧：适合长期伐木和较粗树木，重量略高。
- 双手伐木斧：高砍树效率，但战斗动作较慢且体力耗费较高。
- 手锯：倒木分段和木板粗加工，噪声较低。
- 电锯/链锯：消耗燃油或电池，大幅加快砍伐和截断，噪声较大且有维修需求。

砍树效率可以随有效力量、生存技能和工具品质提高。工具所需图纸仅约束自制与维修，不限制玩家拾取现成斧头使用。

## 90.4 种植、再生与森林管理

树苗由树种种子、苗木搜刮或NPC交易获得；种植时检查土壤、光照、树间距、岩石/建筑占用和水分条件。树木使用世界时间与地区天气按阶段成长，不每帧执行。缺水、严寒、极端高温和污染可以延缓成长或降低健康。树木被砍后不会离开区域再回来立即刷新，只有实际种植或受限的长期自然再生使其恢复。

建议树木成长使用游戏化天数，例如幼苗到幼树3—6游戏日、幼树到成年8—15游戏日，具体取决于游戏一天的真实时长。自动再生有区域密度上限、营地禁植区域和充分的时间成本。据点周边可规划小树林、柴薪堆和锯木区，长期提供可再生燃料。

## 90.5 木材处理和保存

- 湿木与干木使用不同 `moisture` 值。雨天砍下的新鲜木料或露天堆放的木柴含水较高，火堆和发电炉燃烧效率较低。
- 玩家可在带屋顶、通风的木柴架上晾干，或使用有限的室内烘干设施，按世界时间结算干燥程度。
- 原木经过木工台或手锯可锯成木板，产生树皮与锯屑；木板用于墙板、门、地板、家具和矿道支护。
- 柴薪可直接燃烧；木炭需要炭窑进行加工，使用时间和燃料获得更高单位重量的燃烧效率。
- 树枝、锯屑可作少量生火引火料；不能按完整木柴的热值结算。

# 91. 木材、矿石与工业原料加工链

## 91.1 工序结构

原料不直接变成高级装备，分为：**采集 → 分拣/运输 → 初加工 → 炉窑/冶炼 → 部件加工 → 成品组装**。玩家可以把搜刮所得零件直接用于制作，但若长期建设大据点，就需要建立稳定矿木材料供应。初级加工提供足够早期可用性，中高级工业通过更可靠的产率、批量生产和高阶材料体现发展。

## 91.2 工作设施

| 设施 | 核心用途 | 需要的基础资源 | 能源关系 |
|---|---|---|---|
| 手工处理区 | 分拣石料、手锯切木、制作柴薪 | 工具与干燥地面 | 不需供电 |
| 木工工作台 | 木板、木箱、门板、木支柱 | 原木、锯、钉等 | 手工操作 |
| 木炭窑 | 木柴转换为木炭 | 土/石/黏土、木料 | 直接燃烧原料，不自动发电 |
| 简易熔炉 | 铁矿初步熔炼、简单铜加工 | 黏土砖、石料、燃料 | 独立热源，不需电力接网 |
| 工业熔炉 | 批量矿石加工和较复杂合金 | 金属框架、耐火砖等 | 可燃料燃烧，自动化控制部分耗电 |
| 金属工作台 | 铁工具、支架、钢材部件 | 铁锭、紧固件、工具 | 纯手工版本不需电，机器版需供电 |
| 机修台 | 车件、动力钻具、链锯维修 | 金属零件、工具 | 对应机器型号可能需电 |
| 资源仓储架 | 按矿石、燃料、金属和木板分类 | 木板或金属架 | 不需供电 |

生活炉灶负责烹饪，普通熔炉负责冶炼，燃烧式**发电炉**负责热能转换成电能，三者的输入和输出不能混用为“火一烧就免费发电”。资源可以共享燃料物品，但设备工艺独立。

## 91.3 基础建材供应链

- 石块 → 碎石/石料 → 基础地基、路面、围墙、石质防御结构。
- 砂 + 黏土 → 砖坯/烧制砖 → 炉体、壁炉、墙体与耐火结构。
- 石灰石 + 砂 + 水 → 游戏化砂浆材料 → 高级墙基、支柱与部分混凝土组件。
- 原木 → 木板 + 副产木屑 → 房屋墙板、地板、木箱、楼梯和哨塔平台。
- 木材 → 木柴 → 营火、烹饪、取暖；木材 → 木炭 → 熔炉或发电炉燃料。
- 铁矿 → 铁锭 → 铁钉、镐头、斧头、门框、护板、围墙骨架。
- 铁锭 + 碳质材料 → 钢材 → 高等级工具、机械零件与自动哨塔结构。
- 铜矿 → 铜锭 → 铜导线/接头 → 中继器、电力设备、修车电路。

## 91.4 原材料加工中的空间经济

加工后的成品根据真实设计占用网格、重量和可堆叠数，运输价值受到车斗载重、道路和天气影响。原木可以通过皮卡装运；矿石通常更重，鼓励玩家在矿区设临时中转箱而不是一趟背回整座矿山。工作台可以从附近已授权仓储容器读取材料，但必须从一个明确库存逐件扣除，不能同时计入车厢和据点仓库。

# 92. 冶炼、燃烧发电、金属制造与物料守恒

## 92.1 冶炼步骤

铁矿示例：`筛选矿石 → 检查熔炉结构与燃料 → 分批加入铁矿 → 经过游戏时间完成工序 → 产出铁锭与少量废渣 → 冷却或转入工作台`。配方由工作台/炉窑有效性、制作等级、矿石品质、燃料供应和实际时间共同决定。

铜与其他矿石采用各自配方，不能把煤矿直接当成铁锭，也不能让玩家凭按键从泥土造出电子设备。高级合金以抽象游戏配方表现，不提供现实危险化学制造细节。

## 92.2 原料与产物的参考配方

以下物料单位是**游戏配方单位**，不是精确工业化学计量；实际质量和体积单独在物品数据中设置。输出需满足总物料预算和损耗规则。

| 工序 | 输入示例 | 输出示例 | 时间与设备 |
|---|---|---|---|
| 砍伐加工 | 原木2份 | 木板3份 + 木屑1份 | 木工台，2—4游戏分钟 |
| 备制柴薪 | 原木1份 | 柴薪2份 + 树皮1份 | 斧/锯，约1分钟 |
| 木炭窑 | 干柴4份 | 木炭2份 + 灰烬/消耗 | 炭窑，约12分钟 |
| 制砖 | 黏土3份 + 砂1份 + 燃料 | 烧制砖3份 + 损耗 | 砖窑/熔炉，约8分钟 |
| 铁矿冶炼 | 铁矿4份 + 燃料 | 铁锭2份 + 废渣 | 熔炉，约10分钟 |
| 铜矿冶炼 | 铜矿4份 + 燃料 | 铜锭2份 + 废渣 | 熔炉，约10分钟 |
| 钢材制造 | 铁锭3份 + 煤/木炭1份 | 钢材2份 + 工业残渣 | 工业熔炉，约15分钟 |
| 铜导线 | 铜锭1份 + 加工材料 | 导线束2份 | 金属工作台，约4分钟 |

同一种物料在不同制作阶段的“份数”并不要求等质量，但每条配方的原料总质量、产品质量、残渣及燃烧排放必须在游戏经济上守恒，禁止从1单位铁矿重复炼出无限金属。高等级技能主要降低工序损耗或加快速度，受产率上限约束。

## 92.3 煤、木柴与木炭发电

燃烧式发电炉延续第51章，功率初始参考1.2 kW；可以消耗干木柴、木炭及煤。单个设备的热机发电参数不因材料升级而无限提高额定功率，燃料品质主要影响运行时长、积灰速度、排烟和维护成本。

| 燃料 | 每1份（等质量参考）可维持1.2 kW输出的测试时长 | 特性 |
|---|---:|---|
| 湿木柴 | 6游戏分钟 | 发热效率低、烟多、点火更困难 |
| 干木柴 | 12游戏分钟 | 易获得、可通过植树再生 |
| 木炭 | 20游戏分钟 | 单位重量燃烧更持久，制作需耗材与时间 |
| 煤 | 30游戏分钟 | 更适合长时间稳定发电、积灰与烟尘较高 |

单位燃料真实重量和游戏时间倍率在物品配置中另行统一，以上只是用于比较燃料效能的首轮平衡参数。发电计算仍严格按 `发电量(kW) × 游戏时间(h) → 电量(kWh)` 结算；燃料不足时必须中断输出。煤作为燃料需要有独立燃烧记录，不因为在发电炉物品栏放了煤就持续免费产电。

## 92.4 热源、卫生与敌人联动

煤和木材燃烧产生热量与烟。营火、烧砖窑、熔炉和发电炉提供局部热源，帮助寒冷环境保暖，但密闭无排烟空间会积累烟雾与不适；需要有通风条件或室外放置。燃烧噪声、工业机械噪声和夜间火光分别产生原有声音/光源事件；煤尘、烟污可能使衣物变脏、增加清洗需求。雨天露天木材湿润会降低燃烧效率，干燥燃料可存入有屋顶仓库。雨不能直接创造或消除煤和矿石。

## 92.5 制作与供电闭环

煤矿 → 煤燃料 → 发电炉 → 电网 → 中继器 → 工作灯、维修台、哨塔。铁矿 → 铁锭 → 铁制斧镐/工具/护板/塔基。铜矿 → 铜锭 → 接线组件 → 中继器/太阳能板配件。原木 → 木板 → 瞭望塔/矿道支柱/家具；原木 → 柴薪/木炭 → 取暖或发电。石灰石与砂石 → 地基/墙体，改善据点耐久。获得稳定产能后仍必须补充燃料、维护设备、修复电网并外出寻找稀缺材料。

# 93. 矿木采集与天气、身体、敌人生态

## 93.1 天气影响

| 天气 | 伐木 | 采矿 | 交通与发电 |
|---|---|---|---|
| 晴朗 | 木料容易晾干，森林视线好 | 露头易观察 | 太阳能较高，土路较稳定 |
| 小雨 | 木料逐渐湿润 | 露天矿面打滑 | 太阳能下降，路面变湿 |
| 暴雨 | 倒树方向更难控制，林地泥泞 | 矿坑积水、软土失稳风险增高 | 装满矿石的货车更易陷车 |
| 大风 | 倒伏方向更偏移，砍树预警扩大 | 洞外警示声音受风声干扰 | 非风力发电；树影影响太阳能板 |
| 雪与寒潮 | 工具握持、衣物保温更重要 | 冻土挖掘困难，矿灯需求提高 | 冰雪道路抓地变差，太阳能可能积雪 |
| 高温 | 重体力伐木易过热 | 密闭矿坑热感增加 | 必须合理饮水和休息 |

天气影响采集速度应有上限；暴雨不应让工作永久卡住。受第43、59、62章角色湿润、体温和环境疾病的共同影响。

## 93.2 身体消耗

采矿、挥斧、拖原木、装卸矿石作为高强度活动消耗Stamina、增加长期Fatigue并参与卡路里额外消耗。高温使口渴积累更快，寒湿衣服降低舒适和动作效率；手臂局部伤势降低挥击速度，腿部伤势影响搬运，负重限制可携带矿石数量。矿粉与汗污使衣服变脏，玩家可以回据点洗澡、洗衣和修补防护服。

**感染边界：** 矿井粉尘、湿冷、烟雾、普通伤口脏污不会凭空增加七项核心状态中的丧尸感染值；丧尸抓咬或已有感染机制的指定攻击才改变该值。普通伤口感染与呼吸道不适走第4、62章已有独立疾病链。

## 93.3 装备防护

矿工安全帽、手套、防尘面罩、工装、耐磨长裤和靴子属于原有衣物/护甲槽位，提供局部减伤、温度和舒适修正。安全帽降低坠落碎石头部伤害，手套降低工具作业摩擦伤，面罩减少粉尘不适，防雨装备降低雨天湿润；但这些装备增加重量、保温与疲劳负担。采集工具可作为近战备用武器，攻击敌人与攻击矿格应使用不同耐久/破坏系数。

## 93.4 与丧尸及克苏鲁感知联动

手镐敲击、锯木、链锯、钻具和矿坑塌方都产生具有位置、音量、材质和遮挡的声音事件；丧尸会调查声音来源并可能围堵矿口。安静手工工具适合潜行采集但效率低，动力工具效率高却吸引敌人。夜间矿灯、火堆和高亮工作灯对具备光感知能力的克苏鲁遵守第10、27章的特殊规则；普通声音不自动让所有克苏鲁具有听觉。高污染矿带中的异象由区域污染与异常关注度驱动，不因为煤矿作业就随机创造裂隙。

## 93.5 生存采集决策示例

玩家在雨前需要补充发电燃料：开皮卡去浅层煤矿，使用铁镐开采，夜间矿灯吸引异常生物的风险增加；采集过多煤导致满载汽车在泥地更难制动。另一种策略是在据点周边砍树制作木炭，较安全但更费时间、劳力与设施，并对林木再生形成长期规划。两种路线都能够保证基本发电，但有明显效率和风险差异。

# 94. 挖掘地形与建筑道路载具的交互

## 94.1 挖掘边界与结构保护

- 建筑地基和预制地下室通过结构支撑代理参与稳定计算；下方可挖区域失去足够支撑会逐步受损，先给出裂纹和危险提示。
- 主线任务建筑、不可替代的NPC建筑、主干桥梁锚点和至少一条裂隙返程通路需设置保护区或可修复的安全机制。
- 玩家建造的地板、矿道木支柱、临时梯子和井口护栏可提供明确的支护效果；拆除构件后按局部依赖计算。
- 在普通道路下开掘只对可挖掘区生效；已保护的主干路基不能被低级镐头从地下随意掏空。
- 矿道塌方和地形挖空不能让服务器式事务中的NPC、车辆、货物或玩家落入未加载空间。

## 94.2 导航和敌人进出

采掘改变可站立表面后触发局部导航区域重建，并校验矿道坡度、通道最小宽度和楼梯/梯子连接。普通丧尸可以在满足体型和通行规则的矿道里寻路与调查声音；狭窄洞口会形成堵塞与撤退战术。克苏鲁使用原有区域边界和追踪规则，不能穿越真实岩层。远距离矿道NPC/敌人按事件摘要模拟，不为所有地下空间常驻完整寻路。

## 94.3 载具与开采地点

采矿区、采石场和林地可以设置车辆停靠位、木料装卸处和临时矿石箱。车辆能在玩家挖出的合法道路上行驶时需要足够宽的碰撞通道、坡度和高度；不能因为有一条挖出来的狭窄洞穴就允许SUV直接穿过。重载使车辆油耗与悬挂损耗变化；湿泥坡增加陷车风险。车内矿石、木料、工具与其他货物共用第75章真实库存，不创建“矿石专用无限车仓”。

## 94.4 地图标识与路径记忆

玩家可标记矿口、剩余储量预估、坡道、井口危险、采石场与林业点。已探索矿道在本地地图以简化剖面/层级信息显示，而不必须绘制全3D地下透视地图。洞穴入口和出口对应稳定世界坐标。已有矿洞路径在载入时必须恢复，不允许读档让出口变回实心石壁。

# 95. 采集物流、据点布局、NPC与任务

## 95.1 据点生产区域

玩家可以将住宅车库或工业厂房改造成五个功能区域：原料堆放区、木工与柴薪加工区、矿石分拣及熔炉区、金属维修与制造区、发电与电网区。它们共用房屋/家具放置系统与防火、遮雨、碰撞规则，不能把高温熔炉直接放在木床上无条件运行。道路或院内需要预留车辆卸货动线。

## 95.2 资源物流与生产链

玩家可手持或背负小型物料，用车辆货箱/拖车运输大宗矿石和原木。资源进入仓库时被移动至唯一库存容器；工作台可在允许距离内读取已授权原料箱并从实际物品实例扣除。建议矿石箱、柴薪架、原木堆各有不同的网格或批量容器限制，避免用一格手提箱存放整片森林。

木材/煤矿提供可持续燃料路线，铁和铜矿提供产业路线：**木工支柱与墙体 → 矿洞开发 → 冶炼铁锭 → 升级镐斧及支架 → 铜导线和发电装置 → 据点照明/自动哨塔**。每条生产线都存在工具、材料、耗时与维修成本。

## 95.3 NPC轻量协助

NPC依旧是少量功能角色，不组建无限采矿队。可以安排NPC在据点岗位执行轻量辅助：木工NPC加快一次加工工序、机械师维护一台动力工具、商人提供矿物交易、守卫在矿坑入口或据点承担有限防守。NPC的辅助必须消费真实原料、工具耐久或报酬；玩家不在附近时按限速汇总结算，不会无限自动生成矿石、煤炭和木材。

## 95.4 矿业和林业委托

| 任务类型 | 具体目标 | 奖励例子 | 防重复机制 |
|---|---|---|---|
| 修复矿坑 | 清除堵住旧矿口的塌方、安装两根支柱 | 镐头、工具图纸、少量金属 | 通过矿口事件ID结算一次 |
| 煤炭补给 | 交付限定数量的煤炭 | 燃料、代币、发电零件 | 交付直接扣除库存 |
| 铁材采集 | 交付铁矿或铁锭 | 金属台配件、钢材线索 | 不要求固定矿点重新刷矿 |
| 修复伐木场 | 重建锯木台、清理附近丧尸 | 木工材料与工作台图纸 | 修复状态持久保存 |
| 林地恢复 | 按指定范围种植若干树苗并存活数日 | 种子、林业工具 | 按树苗唯一ID与成长时间判断 |
| 运输合同 | 用货车运一定重量的木材/矿石 | 车件、燃油或物资奖励 | 车辆货物ID和任务交付绑定 |
| 异常矿调查 | 在污染矿脉获取唯一标记的样本 | 神秘学进度或研究设备 | 独立任务样本实例，不重置原矿 |

采集任务奖励经验也走真实完成事件，不得同一个矿点“交付一次、退回矿石、再交付一次”循环刷分。

# 96. 颠倒世界矿产树木与世界同步

## 96.1 共享数据原则

主世界与颠倒世界地图坐标、房屋结构、可砍树木、地表石块、矿体储量、矿道挖空、支柱、物资容器和玩家建造结构使用同一份权威数据。主世界砍倒一棵树后，颠倒世界对应树不再是另一棵可独立采伐的完整树；颠倒世界挖掉一格煤矿后，主世界对应矿格也被挖空。

环境表现可以不同：颠倒世界树木呈异常颜色或被附着菌丝，岩壁有异常纹理，矿坑存在特殊光照与克苏鲁生态；这些视觉差异默认不改变共享木料与矿产数量。剧情专属异常矿晶可作为独立世界层事件资源，但必须拥有唯一ID、明确掉落与生成规则，不干扰普通矿物共享储量。

## 96.2 物资掉落与互斥

矿物开采掉落采用 `harvest_transaction_id` 原子写入：先从共享矿块扣除储量，再生成一份可交互资源实例，绑定唯一物品ID和当前实际物品容器/地面位置，提交后在两个世界渲染共享的对应物品视图。任何时候同一地面物品只能被拾取一次。树木倒伏时也只生成一次木料；如果玩家在转层前未拾取矿物，其物品数据仍然保持共享归属，不出现平行世界重复掉落。

## 96.3 地形空腔和空间传送

两个世界共用同一个矿洞空腔与支护数据；玩家在矿坑中进入裂隙后，目标层的安全落点必须检查当前已经挖空的实际空间、坡度、可站立面及克苏鲁碰撞。矿洞内可配置行人裂隙，但必须有至少一条安全返回路径。车辆仍仅由第81—84章R4/R5可抓车裂隙单独转层；共享矿坑不能直接变成任意车辆的无条件世界传送门。

## 96.4 矿坑生态分层

主世界地下可出现丧尸及少量符合区域规则的克苏鲁，颠倒世界矿洞内只刷新克苏鲁；NPC主要属于主世界的动态实体。地下开采声音由普通丧尸听觉处理；颠倒世界克苏鲁仍遵守视觉、光源和异常感知，不因为共享声音事件而得到普通听觉能力。

## 96.5 防卡死与恢复

如果地形编辑、局部塌方、跨层传送或读档导致角色站在实心矿格内，使用已保存的安全锚点与局部空间投射将角色放到附近合法位置；不能以此复制矿石、免费生成出口或重置地形。若载具在矿区附近跨层，应保持车辆尺寸/落点验证与车货唯一性。游戏存档仅需保留一次矿洞差量数据、一次树木状态与唯一资源事件记录。

## 97.4 挖矿动作的伪代码

```gdscript
func try_harvest(target_id: String, tool_id: String, hit_id: String) -> void:
    if HarvestLedger.was_committed(hit_id):
        return
    var node = SharedWorldState.get_resource_node(target_id)
    var tool = InventorySystem.get_item(tool_id)
    if node == null or tool == null:
        return
    if not target_is_in_reach(target_id) or not line_of_sight_to_target(target_id):
        return
    if not valid_tool_and_stamina(node, tool):
        return

    var work = compute_work_damage(node, tool, SkillSystem)
    var yield_units = min(node.remaining_units, compute_yield(node, work))
    # 原子事务：体力/工具耐久 → 节点储量/损伤 → 唯一掉落 → 事务日志
    HarvestLedger.commit_harvest(hit_id, target_id, tool_id, work, yield_units)
    DiggableTerrainManager.mark_dirty_neighborhood(target_id)
```

此代码只表达系统关系，具体节点、单例名称和事务调用按项目现有接口编写。玩家未命中目标、耐久不足或目标已采空时不能消耗该矿块资源；掉落与世界层显示应在提交成功后触发。

## 97.5 性能设计

- 远距离资源点只保存静态种子与动态差量，不生成独立的数千棵树的完整物理刚体。
- 森林采用MultiMesh/LOD，近距离被击中的树才切为可交互实例；倒伏动画结束后变成可收集的少量木段。
- 地形只重建实际发生变更的局部可挖掘区块；将多次击打合并到一次视觉/碰撞更新队列。
- 矿脉数组用紧凑的类型ID和稀疏差量存储；不逐格保存完整Godot场景树，也不每帧遍历整张地图。
- 动态导航更新限制在洞口和近距离有效区；远处矿坑使用缓存导航或事件级摘要。
- 地质调查使用固定世界种子和已探索地图状态，不在客户端每次随机生成新矿。
- 同世界时间跨度恢复时树木成长使用分段计算，熔炉/炭窑按剩余燃料和输入数量封顶，不能因读档或加速时间无限生产。

## 97.6 存档与迁移

在既有顶层存档中保留 `resource_distribution_seed`、`resource_node_states`、`tree_instances`、`diggable_chunk_deltas`、`mineshaft_support_states`、`processing_jobs`、`resource_transaction_ledger`。缺失字段使用基于世界种子的确定性初值；如果旧存档在矿区已存在玩家建筑，新矿体生成需校验占地冲突并稳定迁移。修改区块前备份关键场景状态；读取后按区块差量恢复地形，再放置建筑、车辆与NPC，最后重建局部碰撞和导航。

# 98. 采集进度、平衡参数及防刷规则

## 98.1 初始平衡参数

| 参数 | 建议值 | 调整依据 |
|---|---:|---|
| 采掘单元 | 0.5米立方 | 兼顾通道细节、碰撞与存档 |
| 活跃可挖区块 | 16³个单元 | 网格重建和运行内存 |
| 采集工具有效距离 | 2—2.5米 | 玩家身高、第三人称操作距离 |
| 石镐/铁镐/钢镐/动力钻具效率倍率 | 1.0 / 1.6 / 2.2 / 3.5 | 工具获得难度与声音风险 |
| 资源点单次耐久示例 | 石60、煤90、铁120、铜110 | 工具击打速度和稀缺性 |
| 生存技能每级增产 | +0.3%，累计最多+7.5% | 防止材料产率失控 |
| 生存技能每级采集耗体下降 | -0.3%，累计最多-7.5% | 与力量、天气共同结算 |
| 伐木成长时间 | 3—6 + 8—15游戏日 | 必须与世界天数倍率联动 |
| 支柱影响范围 | 以约3—5米局部支撑验证 | 矿坑宽度与结构玩法 |
| 炭窑木柴4份产炭 | 木炭2份 | 配方损耗与燃料价值 |
| 燃烧式发电炉额定功率 | 1.2 kW | 与第51章一致 |
| 干柴 / 木炭 / 煤（等质量份） | 12 / 20 / 30游戏分钟 | 仅首轮燃料平衡 |
| 单次露头资源 | 约6—15矿料单位 | 早期工具与配方成本 |
| 一条浅层矿脉资源 | 约30—90矿料单位 | 支撑短期据点发展 |
| 一条深层矿脉资源 | 约100—300矿料单位 | 支撑中长期制造，需要运输 |
| 挖矿经验结算 | 有效采得资源按价值计 | 禁止空挥镐刷经验 |
| 伐木经验结算 | 有效损伤与实际木料收获 | 禁止反复攻击树桩刷经验 |

所有样例值为配置初值，不要求同时在首个原型实现全部矿种。铁矿和煤矿应在小地图内有可找到、可开采的稳定资源供应；复杂深矿和异常矿体用后续地图区域承载。

## 98.2 技能经验反刷机制

`XP_harvest = base_xp × difficulty_factor × valid_output_factor × activity_diminishing_factor`。同一节点反复空挥、打到零资源、对无需加工的弱物反复拆建不能赚经验。首次辨识新矿脉可以给一次调查经验，由地质地点ID去重；同配方短时间批量制作可按实际工序给少量经验，但逐渐衰减，不能使用买进一份木板拆了再装无穷升级。

## 98.3 资源供给与平衡护栏

- 木料相对丰富、可再生；铁和煤在风险较低区域能够找到少量，扩大规模后要远征或开发矿区。
- 产出实际受矿体有限储量约束，采集效率奖励不突破储量上限；升级不能让1单位煤变成10单位煤。
- 工具耐久、维修消耗和燃料价值应与收获成正比，不能出现电钻运行成本高于所有可能产出且没有说明的情况。
- 废弃工厂和车辆拆解提供金属的替代来源，但回收率较低，避免采矿成为唯一材料渠道。
- 资源交易有数量限制、运输成本和刷新规则，不能从商人无限买进煤然后以无成本制造代币获利。
- 矿坑与森林不会在世界层切换或读档时复活；任务地点不会重置所有资源。
- 电力消耗使用kW与kWh统一结算；燃烧炉不能无燃料运转，太阳能不能在深夜输出。

## 98.4 角色成长与游戏循环示例

**游戏前期**：生存0级也能使用石镐、石斧采集零星木料石块；收集煤和铁矿；制作低级木墙与火堆。生存升级时每级提高采集数值并逐步掌握资源辨识。制作4级能造简易熔炉，制作9级能自主冶炼铁锭；玩家仍可在此之前搜刮铁制工具和铁锭。

**中期**：玩家学会金属工具与锯木，接矿工NPC任务修复旧矿坑，搭建木支柱、抽水和照明，把铁矿与铜矿运回车库，用煤或木炭保证冶炼和发电，安装中继器供电给加工台与据点照明。

**长期阶段**：使用钢制工具或动力钻具开发深层矿脉，开辟运输路线，使用种植林地持续补充木料，扩建仓库、自动哨塔和车辆维修工位。进入高污染矿区时，矿工必须考虑SAN、克苏鲁光感知和高等级裂隙是否能吞噬运矿货车。

# 99. 实施里程碑、验收矩阵与测试示例

## 99.1 与原有开发阶段的关系

| 里程碑 | 自然资源系统的交付 | 最小验收 |
|---|---|---|
| M0—M2 | 统一资源ID、工具属性、生存技能逐级成长、原始材料物品 | 石块和树枝可拾取，技能从0到25每级有成长 |
| M3—M4 | 可砍伐树木、地表煤/铁露头、工具命中、局部声音 | 树木可倒伏，露头采完不再产出 |
| M5 | 小型可挖土坑/矿体、木工台、简易熔炉、木炭窑 | 挖煤/铁、锯板、炼出铁锭并建墙 |
| M6—M7 | 煤燃料接入发电炉、铜材用于中继器、原木仓与车辆装载 | 发电量与煤消耗、储电和灯具联动 |
| M8—M9 | 矿木NPC委托、地质调查、尸群和气候风险 | 交付真实矿材且不能重复领奖 |
| M10 | 矿坑/林木双世界同步、矿洞裂隙安全返回 | 跨世界不复制矿物、木料和矿道 |
| M11—M12 | 深层矿脉、树苗长期成长、局部支护、性能与迁移 | 大世界多矿区稳定存档和流式加载 |

实施初始原型可以先使用可破坏矿石块/预制可挖掘矿坑，再推进局部可编辑地形；但最终可玩设计需要真正的可挖矿体和可保存地形变化。

## 99.2 验收矩阵

| 编号 | 行为 | 合格标准 |
|---|---|---|
| R01 | 生存技能从0依次升到25级 | 每级有数值与具体永久能力，不存在“等待下一次五级大奖” |
| R02 | 其他九项技能逐级升级 | 每项25个单级知识/能力均可查询，升级跨多级不漏发 |
| R03 | 0级工具作业 | 石斧石镐可砍树挖基础煤/铁，低效但功能完整 |
| R04 | 地表煤矿线索 | 找到对应可采矿体且位置和储量稳定 |
| R05 | 向地下开采铁矿 | 改变可挖区块的几何、碰撞与寻路，可保存 |
| R06 | 砍倒一棵成年树 | 倒伏方向和伤害可观察，掉落木段数量有限 |
| R07 | 不同工具开采同一材质 | 石/铁/钢/动力工具效率、耐久和噪声有差别 |
| R08 | 同矿点持续挖到采空 | 总产出受资源池约束，不刷出额外矿料 |
| R09 | 重复读档或切换区块 | 已砍树木与已挖矿洞保持状态，物资不复制 |
| R10 | 建造矿道支柱再开挖 | 支护状态影响局部稳定，危险有预兆 |
| R11 | 砍木晾干与制造木炭 | 木材湿度、炭窑输入产出和世界时间正确 |
| R12 | 铁矿冶炼 | 产出铁锭和残渣，消耗燃料和原矿 |
| R13 | 煤烧发电炉 | 逐步消耗煤、输出有限kW与kWh，断燃料即停机 |
| R14 | 铜材制作电网组件 | 配方检查实际库存、技能及工作台，不能凭空生成 |
| R15 | 装矿石进皮卡后上坡 | 实际货重影响车辆行驶、制动和体力运输 |
| R16 | 雨天挖矿、伐木 | 湿润、滑坡、工具与能源效率有真实交互 |
| R17 | 夜间开链锯 | 声音吸引普通丧尸，克苏鲁仍采用自身感知 |
| R18 | 再植树苗并快速推进游戏日 | 依世界时间成长，密度和气候条件生效 |
| R19 | 任务交付矿石 | 正确扣除矿材，奖品只能领取一次 |
| R20 | 主世界采完矿再进颠倒世界 | 对应矿格仍为空，货物不可两边同时领取 |
| R21 | 在颠倒世界砍树再返回 | 主世界的同一树同步倒伏，不额外生成一批木料 |
| R22 | 载具靠近高等级裂隙及矿洞 | 只符合捕获配置的裂隙可吞车，矿洞不触发错误传送 |
| R23 | 高速多次挖掘同一区块 | 无重复掉落、无卡顿性整区重建、无导航错误 |
| R24 | 保存时正在熔炼并退出/读档 | 材料预留、时间进度和完成产出不会重复结算 |
| R25 | 软锁场景：矿坑坍塌堵路 | 存在可见、可达的人工挖通或保底脱困路径 |

## 99.3 测试地图

准备一个小型森林与林业区、一片铁煤露头、一个8米边长的可挖矿块、浅层矿洞、带支柱的试验巷道、一座锯木和熔炉工坊、发电炉与中继器示例、一条可通行的矿区道路、一辆有载重记录的皮卡以及主世界/颠倒世界对应区。调试界面显示矿块ID、材料、剩余量、工具效率、树木生长阶段、支护稳定、声音事件、加工队列、当前世界层、区块网格更新次数和采集事务ID。

## 99.4 数据与设计一致性

1. 角色为七项核心状态和十项技能，每项技能25级，并且每级获得具体成长；采矿/伐木活动归生存技能，不另设第十一技能。
2. 煤炭可作为营火、冶炼和燃烧式发电炉的真实消耗燃料；木炭、木柴为有差异的替代燃料。
3. 铁矿通过冶炼变成铁锭、铁制工具、基础金属建材与防御设备原料；铜等矿物支持电力制造链。
4. 玩家挖开的矿道、采空资源点、砍倒树木与种植树苗都要持久保存并跨世界映射一致。
5. 地形采掘、砍伐、制造与车辆运输消耗实际体力、工具耐久、材料、燃料、时间与库存容量。
6. 丧尸感染、一般疾病、SAN和天气等原有规则保持各自独立；高等级裂隙吞车严格遵守车辆唯一世界层及防软锁规则。
7. 自然资源再生只通过明确的时间与种植/生态机制，不能靠重新载入、接任务或切换世界层复原矿体。
