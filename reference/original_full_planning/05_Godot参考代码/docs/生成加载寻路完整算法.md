# 世界底层：区块流送 → 敌人生成 → 导航追逐

## 1. 区块数据与状态
水平区块64×64m，局部矿洞16m可修改数据单元。区块最少包含`terrain`、`building_ids`、`entity_ids`、`population_ids`、`resource_patch_ids`、`nav_portals`、`revision`、`last_simulated_tick`。世界坐标负数使用floor，防止`int(-0.2)==0`造成负区块错位。

**流送状态机**：UNLOADED → REQUESTED → DATA_READY → INSTANTIATING → ACTIVE → COOLING → SERIALIZING → UNLOADED。每次异步请求带`request_version`；玩家驶离后收到的旧请求不得再次加入场景。第一次进入时需要先有地面碰撞再装饰，防止车辆落地前坠落。

**强制依赖关系**：Chunk数据→碰撞→导航区块/门户→人口池激活→场景敌人。顺序反过来会导致怪物卡地底或越界。先可见环境、后敌人；同一帧实例化数量受预算限制。

## 2. 世界人口模型
每个区域一次性确定基线人口规模N，具体敌人`entity_id`由稳定种子/存档记录决定。实体有`active`/`hibernating`/`killed`状态。生成器只是把休眠实体转换为活动场景实体，**不是凭空创造N+1**。迁移发生时，唯一实例从源PopulationCell转移到目标Cell；杀死后触发一次尸体和一次掉落。

候选生成点要求：距离在Min/Max间、非玩家视锥可见区域、射线遮挡有效、非安全屋禁入、已完成导航区块加载、世界层匹配、区域预算允许、无可重现死亡ID。支持房屋房间的固定锚点，首次探访才能激活但不能因二次进入重新抽取。

### 三级模拟
- A近距：完整节点AI、动画、物理与感知，基准0—70m。
- B中距：低频意图与路径更新，基准70—220m，不做逐帧动画细算。
- C远距：只保留人口组ID、位置区块、最后移动方向与目标；抽象分钟级更新。

边界使用滞回区避免AI在70m反复创建/删除。高速车辆根据预测位置增加前向预取并推迟危险激活。

## 3. 感知与寻路
感知评分`vision_confidence = exposure * (1 - cover) * (1 - fog_penalty) * time_factor`；听觉在声源半径内随距离平方衰减，再乘墙壁/雨声遮挡系数。丧尸根据视线+听觉+少数气味；克苏鲁默认不处理普通声音，而按视线、光源、异常感知和仇恨独立运行。

跨城先在区块门户图求粗路线，再对近端可见区段使用局部NavMesh和NavigationAgent3D。建筑门窗、楼梯分别登记Portal；关闭门路径成本可增加，撞门成功时更新局部门连接状态；窗户翻越可独立加上跳跃动作。

NavigationAgent设置target后应在物理帧取`get_next_path_position()`；不要每帧重新写target导致频繁重寻路。碰撞避免(RVO)并不保证始终沿NavMesh，需要角色物理碰撞和失败重规划。

**防卡死阶梯**：检测位移不足→转向等待→局部重寻路→尝试可破坏障碍→返回最后有效门户；禁止敌人瞬移到玩家背后。门外队友/丧尸保持视野和实体的真实连续性。

## 4. 多世界
两世界共享静态块数据及玩家修改差量；克苏鲁/丧尸实例集合和局部音效、特殊光照单独依世界层加载。车辆携带`active_world_layer`不能复制。主世界旧块卸载时与颠倒世界块更新共用同一持久物体状态。

## 5. 假数据测试用例
同一seed的居民区Chunk(3,-2)创建200个可复现休眠ID；连续进入/离开十次人口总数不增加。玩家在建筑中开枪：最近三个区块调度迁移；玩家从后门撤离、AI保留最后已知位置、搜索后恢复游荡。移动到无NavMesh区块，应拒绝激活敌人并记录nav_unready日志。
