# 共享数据接口契约 v1（所有模块强制遵守）

## 一、规范性约定
| 主题 | 固定规则 |
|---|---|
| 坐标 | Godot Y向上、水平XZ；1单位1米；区块网格使用floor而非截断；游戏场景的世界坐标只存一套 |
| 时间 | `world_tick` 单调递增；`world_minutes` 由它换算；生存、疾病、制作、天气按上次结算tick一次性推进 |
| 身份 | 每个物理物品、NPC、敌人、车辆、门窗、矿脉、掉落物都有不可复用 `entity_id` |
| 静态定义 | `definition_id`仅描述物品/建筑/车型参数，允许多实例共享，不得写入运行时数量和耐久 |
| 动态状态 | `instance_id/entity_id`拥有真实存放位置、耐久、数量、玩家归属和世界层运行态 |
| 世界层 | `MAIN_WORLD` 和 `INVERTED_WORLD`；静态地图/门窗/家具/物资共享，丧尸、克苏鲁AI按层独立；车辆只在一个active layer |
| 事务 | `event_id`去重；检查→预留→执行→一次提交→UI刷新→写WAL/快照；失败回滚 |
| 所有权 | 一个物品实例只能同时属于一个容器/装备槽/地面实体；不得在不同系统中重复缓存为有效所有者 |
| 事件格式 | `{event_id, type, world_tick, source_id, target_id, world_layer, payload}` |
| 保存 | `schema_version, world_seed, world_tick, player, shared_world, entities_by_layer, chunks, transactions` |
| 输入 | 背包及轮盘不暂停；WASD+Shift始终有效；鼠标操作UI不穿透攻击；允许右键暂控镜头 |
| 准确度 | 所有CSV数值为首轮平衡测试值，不是成品数值；输出测试数据及回归seed |

```gdscript
# Interface names, not a complete runnable API

```

## 三、模块间稳定边界
- `M00` 独占全局事件/实体ID和时间体系；`M23` 独占磁盘保存与迁移；其他模块不独立写`user://save.json`。
- `M10` 独占区块加载生命周期；`M11`独占导航区块/门户信息；`M08`独占人口池总数、实体迁移与激活；`M09/M19`拥有AI行为而不偷偷生成敌人。
- `M06`独占物品定义与掉落表；`M04`独占玩家装备槽及容器坐标、交互权限；`M15`只通过M04库存事务扣料。
- `M12`独占建筑生成定义/房间ID；`M13`拥有家具实例摆放与容器定义；建造改造必须写共享建筑差量。
- `M16`独占能量分配、储电、接电；M49原规划的哨塔业务可在M16调用负载接口而不再复制电网逻辑。
- `M20`独占世界层事务；M18只返回载具/乘员/拖车实体组，不可自行复制或删除其他层的车。

## 四、变更流程
公共结构变更先在主对话框创建RFC：需求原因→影响模块→新增字段→迁移方式→兼容适配→测试。稳定字段不能无审查删除或重命名。依赖模块尚未合并时，使用接口桩/Mock，而不是自己复制一套服务。
