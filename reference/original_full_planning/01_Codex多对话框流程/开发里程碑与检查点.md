# 里程碑与交付检查点

| 里程碑 | 核心成果 | 可观察的验收 |
|---|---|---|
| M0 基础工程 | 事件、时钟、ID、输入 | 多次输入和重复事件不重复结算 |
| M1 世界读写 | 区块与持久化 | 进入/离开区块十次物资数量不变 |
| M2 角色背包 | 七状态、实时UI、装备位 | 移动疾跑开背包，三武器槽、六分类正常 |
| M3 导航声源 | 门窗楼梯、NavPortal、声音 | 枪声吸怪、破门、上楼、失视搜索 |
| M4 早期战斗 | 丧尸、武器、医疗 | 射击引怪、伤势处理后撤离 |
| M5 第一批建筑 | 住宅+商店+车库及家具 | 房间逐一可进、物资按房间用途出现 |
| M6 制造资源 | 矿木/冶炼/配方 | 从煤与铁矿生产工具和建材 |
| M7 据点 | 生活、能量、NPC | 照明/冷藏/哨塔按负载扣能量 |
| M8 车辆远征 | 车辆与车库存档 | 开车跨10块、维修、载物、存档 |
| M9 异常生态 | SAN与T1—T4，仇恨 | 丢失视线后减速搜索、进污染区 |
| M10 裂隙 | 角色/载具转层 | 车和NPC只出现在一个世界层且可返回 |
| M11 内容扩充 | 更多建筑、装备、NPC任务 | 数据配置导入、内容索引完整 |
| M12 性能与回归 | 30分钟负载稳定 | FPS、内存、读档与ID完整性合格 |

每个M必须附：可运行演示场景、截图或录屏、实体数和日志、自动测试、失败与修复记录。数值与性能目标是初始设计预算，需实测调优。
