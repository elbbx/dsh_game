# 现实原型建筑重制原则

这次重制不再把所有建筑默认做成标准长方形/长方体，而是按**现实世界常见建筑原型**重新组织：

## 1. 住宅
- 单层住宅：强调“公区在前、私区在后或侧翼”。
- 两层住宅：一层以客餐厨、洗衣、车库、泥房为主；二层以卧室、卫浴、家庭厅为主。
- 车库、门廊、后院厨房翼、泥房等作为真实住宅高频附属空间。

## 2. 多户住宅与旅馆
- 公寓：楼梯厅、电梯厅、公共洗衣房、双侧住户或双翼住户，单元内部为客餐厅+厨房+卧室+卫生间。
- 汽车旅馆：U形围合庭院停车；客房沿外廊展开。
- 小旅馆/酒店：客房翼+中央大堂/电梯核，而不是整栋均匀切块。

## 3. 医疗、学校、警消和行政
- 诊所和医院：挂号、候诊、门诊、药房、病房、护士站、连廊、楼梯电梯核按真实流程组织。
- 学校：翼楼+连廊+行政入口。
- 消防站：高跨车辆库 + 办公/宿舍翼。
- 派出所和行政楼：报案大厅、办公室、证物/档案、拘留/后勤等分区。

## 4. 商业与工业
- 便利店/超市/五金店：卖场前场 + 收银 + 后仓/冷库/员工区。
- 仓库/物流/维修厂/工厂：大空间主体 + 办公附楼 + 机修/配电/更衣/装卸月台。

## 5. 特殊建筑
- 教堂采用中殿+横臂+祭坛端的十字布局。
- 地下避难所采用中央主廊 + 成组功能房的掩体式布局。
- 实验所和污水处理站采用设备核心、实验室翼和控制室等现实功能关系。

## 6. 不直接照抄受版权保护的特定房屋图纸
文档中的图纸是**原创、现实导向的概念方案**，参考现实世界常见平面逻辑、功能分区和建筑原型，但不直接复制某个具体商品化户型图或受版权保护的房屋图纸。
