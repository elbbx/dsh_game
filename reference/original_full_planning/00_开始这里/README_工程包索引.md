# Way to Home｜Codex 多模块游戏开发工程包

这是依据你现有的106章完整规划，拆分出**27个模块**并扩充可执行内容的数据与参考工程包。它不是完整制作好的Godot游戏。你可以直接让独立Codex对话框读取各模块要求，逐步在你的项目中实施。

## 本包包含
- **原始完整规划**：`00_开始这里/原始完整规划_106章.md`，规范性源文保留。
- **模块规格**：`02_模块独立规格/`，27份每份继承原规划对应章节，并附工作范围、接口、开发步骤和验收。
- **Codex多窗口完整流程**：`01_Codex多对话框流程/`、每模块提示词`06_对话框可复制提示词/`。
- **可编辑数据资产**：物品578种、制作配方146条、敌人25型、载具22型、房间掉落552条、家具摆放35条、天气14种；均有CSV/JSON索引。
- **建筑可视化**：40栋建筑，共75张逐层平面图、40张外观体量图，每张具有SVG源文件及PNG预览，浏览器打开`04_建筑可视化/打开建筑图库.html`查看。
- **底层参考代码**：11个Godot 4 GDScript参考脚本，覆盖区块流送、人口生成、导航、AI、网格、供电、事务和裂隙。
- **验收体系**：跨模块用例、性能预算、测试清单、自动化数据校验。
- **过往版本归档**：`08_历史规划文档`供追溯，开发以106章当前版为准。

## 首先做什么
1. 用浏览器打开建筑图库，确认你想做的游戏风格、真实比例、楼层和房间分布。
2. 阅读`01_Codex多对话框流程/Codex分模块完整操作手册.md`。
3. 把设计包放在当前Godot项目的 `docs/design-kit/` 下，检查并适配 `AGENTS.md`。
4. 在Codex新建一个主架构对话框，粘贴`06_对话框可复制提示词/主架构对话框.md`。
5. 先完成`M00 架构与数据契约`，然后创建不同Git worktree，把每个模块交给独立对话框。
6. 用`07_验收与性能测试`中的用例逐项验证，绝不按“AI说做完了”判定完成。

## 重要设计边界
- 用户的7核心状态、10技能25级、主世界/颠倒世界、3武器槽、6分类快捷栏、UI打开仍可移动疾跑、治疗机制、天气和电网等规则全部继承。
- 建筑图为**原创游戏设计级平面/体量示意图**，配备尺寸与家具，不是建筑师审定的真实住宅施工图；建筑现实性仍要通过实际游戏测试校核房间动线/门窗及结构。
- 所有新增的内容表数值属于首轮可测平衡参数，并非游戏原作内部数据。
- GDScript样例没有在用户的真实Godot工程运行过，需由对应模块Codex接线、版本检查和测试。
