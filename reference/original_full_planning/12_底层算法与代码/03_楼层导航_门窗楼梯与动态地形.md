# 三维分层寻路：门户图、NavMesh、门窗楼梯和失效恢复

## 1. 两级路径
大图先在`ChunkPortalGraph`上做A*，节点是区块、道路连接、桥梁、建筑门口、楼梯上下锚点及可翻窗；每条边携带高度差、可通行族群、状态和预估成本。局部使用每chunk+每楼层`NavigationRegion3D`的NavMesh，主体可导航角色具备agent radius/height参数。动态物体不能每次移动就全图重烘焙。

## 2. 门与窗
门状态`OPEN/CLOSED/LOCKED/BROKEN/BARRICADED`映射门户成本。普通丧尸对CLOSED执行开门或撞门行动，LOCKED门可消耗时间破坏，玩家权限允许时直接开；翻窗要检测窗高、玻璃/栅栏以及角色当前身体状态。门变更发`navigation_edge_changed`，低频合并更新局部图边。

## 3. 楼梯真实连接
一段楼梯连接`floor=n`的低锚点和`floor=n+1`的高锚点，楼梯宽度和坡度必须有可导航结构。即使楼层的NavMesh暂未激活，高层路径也能先给粗粒度Portal route；局部加载后才允许真实移动，不允许敌人瞬移。断开楼梯时更新Portal边，转为搜索最近可达点。

## 4. Godot同步屏障
NavigationServer区域变更通常在物理帧同步后才可查询正确路径；向导航服务器添加region后至少等待physics frame。官方说明：https://docs.godotengine.org/en/stable/tutorials/navigation/navigation_using_navigationservers.html

```gdscript
extends Node
class_name NavigationSyncGate

func query_after_sync(start: Vector3, target: Vector3, map_rid: RID) -> PackedVector3Array:
    await get_tree().physics_frame
    if not NavigationServer3D.map_get_iteration_id(map_rid) > 0:
        return PackedVector3Array()
    return NavigationServer3D.map_get_path(map_rid, start, target, true)
```

## 5. 失败策略
错误必须分清：`PATH_WAITING_FOR_REGION`（加载中），`PORTAL_BLOCKED`（门被封/楼梯断开），`TERRAIN_DIRTY`（挖掘刷新中），`TARGET_OUTSIDE_TERRITORY`（克苏鲁领地约束），`NO_PATH`（真正不可达）。最多重试几次，避免每帧为同一怪物做长距离A*。打开墙、拆建家具、挖坑后只标记受影响region。

## 6. 验收
自一层街道进入住宅二层卧室；关门改路；破门回路；挖矿开洞后地表怪物不能隔空落入矿坑；100个丧尸在同一栋楼周围寻路不能每帧全员求路径。
