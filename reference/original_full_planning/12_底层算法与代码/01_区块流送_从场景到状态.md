# 区块流送：64m网格、异步资源准备、实体持久化

## 1. 系统目标
世界在任何时候都只有一套权威数据仓库。场景中可见实体是权威数据的临时视图，不能通过`queue_free()`作为删除世界物品的逻辑。建议以64m×64m地表块作为首轮配置，但室内、地形挖掘和地下世界的导航分块可更细。

## 2. 查询与观察者
兴趣源包括玩家、正在驾驶的汽车及重要持续模拟事件。每个观察者提供当前位置、速度、前向矢量和优先级。分为`VISUAL`、`PHYSICS`、`AI_ACTIVE`、`AI_SLEEP`和`PREFETCH`五种预算层：主视野周围若干块完整加载，外圈仅低LOD，远圈仅持久化摘要。车辆速度80km/h约22.2m/s，预取距离必须至少包括预计加载时间×最大速度+安全裕量，不能只靠固定两格。

## 3. 状态机及队列
`UNLOADED→REQUESTED→DATA_READY→ASSEMBLING→ACTIVE→SUSPENDED→SAVING→UNLOADED`。请求必须携带chunk_id和generation_token；若玩家在资源加载期间高速驶离，该请求可取消或以更低优先级延迟。后台只解析和准备纯数据，场景节点在主线程创建。每帧设置实例数上限，避免连续加载几栋大建筑时卡住主线程。

```gdscript
extends Node
class_name ChunkInterestPlanner

@export var chunk_size_m: float = 64.0
@export var preload_seconds: float = 3.0
@export var base_margin_m: float = 96.0

func chunk_of(pos: Vector3) -> Vector2i:
    return Vector2i(floori(pos.x / chunk_size_m), floori(pos.z / chunk_size_m))

func desired_chunks(pos: Vector3, velocity: Vector3) -> Dictionary:
    var lookahead := maxf(base_margin_m, velocity.length() * preload_seconds + 64.0)
    var center := chunk_of(pos)
    var count := ceili(lookahead / chunk_size_m)
    var result := {}
    for dz in range(-count, count + 1):
        for dx in range(-count, count + 1):
            var c := center + Vector2i(dx, dz)
            var world_center := Vector3((c.x + 0.5) * chunk_size_m, pos.y, (c.y + 0.5) * chunk_size_m)
            var dist := pos.distance_to(world_center)
            if dist <= lookahead + chunk_size_m:
                result[c] = dist
    return result
```

## 4. 区块激活/卸载伪流程

```text
每个流送tick：
  1. 收集所有观察者兴趣区块/优先级
  2. 生成missing_requests，去重排序并过滤过时token
  3. 异步读取静态种子资源+差异存档
  4. 主线程限额实例化几何、碰撞、交互实体
  5. 注册导航region/portal；等待物理帧完成同步
  6. 根据PopulationCell激活少量敌人，不重复创建已死亡ID
  7. 设置chunk ACTIVE；重新验证附近交互目标引用
  8. 对远区先冻结事务、保存delta、注销导航、释放Nodes
```

## 5. 存档格式
每块写 `{chunk_id,seed,version,shared_deltas,layer_deltas,entities[],furniture_changes,resource_changes,nav_dirty_stamp,population_state}`。实体变化只记与初始seed差异；远距人口群体摘要可以定期低频结算。车辆横跨块边界应由车辆实例的world position和owner chunk迁移事务维护，不允许两块各自创建一辆车。

## 6. 验收与性能分析
- 站立/步行/疾跑/高速载具沿同一线路往返20次，地面永远可碰撞；不存在0.5秒无碰撞地面。
- 在两个区块边界放50件物品，跨区回收不丢失、不重复。
- 记录`active_chunks`,`pending_requests`,`instantiation_ms`,`io_queue`,`chunk_save_ms`,`memory_mb`，不得仅凭主观体验宣称无卡顿。
