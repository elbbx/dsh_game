# Godot 4.7.2 · OvercastVeil 纯2D等距原型

Godot 编辑器：导入此文件夹下 `project.godot`，点击运行；Windows 可直接选择 `.godot` 文件打开项目，**不是独立 exe**。此项目是早期功能样板，不能替代完整游戏。

WASD 在屏幕方向移动；E 在门附近切换房屋，靠近黄色物品时 E 拾取；Space 近战；H 用绷带；F5 存档；F9 读档。室外完整等距房屋，进门时淡出/切成单独等距室内、返回恢复外面坐标；脚底深度排序、敌人跟随、生命/饥饿与基础战斗可见。使用 `game/art/` **原创新建**的低复杂度像素占位图，不包含任何下载的第三方美术。

局限：未做真正 TileMapLayer 关卡、复杂墙碰撞、完整版存档事务、正式贴图、全部原始物品/配方。这些已列为 AI 下一步工作。
